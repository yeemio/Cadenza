# trace —— 追溯与身份域（骨架占位）

职责（对齐 DOMAIN_MODEL §3.2，规则等 L2 冻结合同后实现）：

- 六层身份语义：批次（不可覆盖历史）→ 库存单元（可拆分/消耗/转移）→ 轴段（区间或独立段）→ 载具（带生效时间绑定）→ 客户轴段（合同版本调整、保留原分配）→ 标签（补打引用原对象、作废重印留记录）。
- 解析链 barcode → binding → inventory_unit；条码格式校验按版本表配置，不作主键。
- 谱系边 append-only；倒轴守恒（原量=子段合计+留存量+损耗）。

边界：只依赖 `@cadenza/contracts`。
