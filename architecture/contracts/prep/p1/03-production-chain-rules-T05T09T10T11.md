# A. 规则要点（实施规则底册）

## A1 订单状态轴与开工前置（T09）
- PRD 状态轴：已核准→允许开工→进行中→已结束；已作废独立、挂起独立、工序设置未配置→已配置（PO §1.1/§1.2）。DM §5 增补「完工待核」且 ERP 商业关闭与 MOM 执行完成分开（显式新增，见 C10）。
- 开工前置（全部满足才可开工）：状态=允许开工；已配置工序且存在工序行（PO §2.1 开工）；工艺路线已确认（01 §3.1 开工）；开工时间必填、默认当前时间（PO §2.1）。DM §5 追加：缺工艺、映射或授权不能开工。开工后记实际开工时间、变进行中、向 ERP 推送（01 §2.1）。
- 工序设置变更锁：已有报工（含未提交报工单）后不可新增/调序/删行/改工序名；工序备注、芯倍数、绞合、下线数量仍可改（01 §2.1 逻辑）——目标口径改覆盖为 S04 变更版本（见 B1）。
- 工序主数据：已被订单排产引用的工序编辑时工作中心/所属部门不可改（GX §2.1）；删除拦截顺序=模板引用→已排产→订单工序引用（GX §2.1）。模板无状态流转、逻辑删除不查引用（GS §1.1，弱口径照记）。

## A2 工序需求推导（T05）
- 公式（PO §2.1 工序设置 + DM §4.1）：末道下线数量 = 订单产量 × 芯倍数 × 绞合系数；非末道 = 下一道下线量 × 本道芯倍数 × 绞合；芯倍数正整数必填、绞合选填、未填该行跳过重算；新增行默认下线量=订单产量、芯倍数1、绞合1；下线数量必填最多 4 位小数。变更后自末道向上游递推。
- DM §4.1 约束：公式只在适用工艺与同一计算口径内使用；结果仅用于备料/排程，不生成库存账（1000m×3×1.02=3060m 样例）；损耗/余量必须独立命名、受版本控制，不得并入绞合系数。
- 订单下达时冻结快照：BOM、路线、系数、预计速度、换算、检验规范、客户分段（DM §4.1；ROADMAP T05「订单引用已发布版本」）。已有报工后改系数/下线量 → 形成变更版本 + 仅调整未执行任务，已完成实绩保留原版本（S04 裁定，PI §2）。
- 套用来源：工序模板（按名单选套明细）；历史工序（同料品+同生产部门、排除本单，整单拷贝）（PO §2.1）。缺分段同步信息：列表行标黄、工序设置弹窗红字提示（PO §2.1 + PA §1.1）。

## A3 订单/设备双视图一致（T09）
- 排产槽位唯一键：同订单+同订单工序+同标准工序+同设备+同生产日期至多一条有效排产；计划量改 0 保存=删槽（OS §1.1、ES §1.1）。
- 三个编辑入口共用同一提交能力：订单排程详情矩阵（仅改已有槽位，空白格不可新建，OS §2.2）、设备排程看板（有排产或空白格均可点开添加，ES §2.1）、生产订单「设备排产」弹窗（按设备填报，PO §2.1）。
- 回写链：槽位→工序已排数量/是否排完→订单排产状态（未排产/部分排产/已排产=各工序计划合计≥下线数量）（OS §1.2/§2.2）。同一排产事实投影到订单和设备视图（DM §2 订单与调度域）。
- 校验分层（S10 裁定，PI §2）：工序计划合计（本槽按替换旧值计）≤ 该工序下线数量 = 服务端强校验，超则禁止保存；超设备日产能 = 二次确认后可提交的弱提醒，产能未配置（空）不比较（OS §2.2、ES §2.1）。
- 设备状态约束：维修且无槽位→不可新建正数排产；已有槽位可改正数或改 0 删槽（OS §1.1/§2.2、ES §2.1）。订单排程进详情前校验各工序均已配置工作中心（OS §2.1）。设备看板不展示已结束订单排产；日期列=今日起 30 天∪已有排产日（ES §2.1）。PDA 排产计划只读（PP §3.2）。

## A4 班次跨日（T09）
- PRD 现状：仅系统参数「白班开始时间」，当前时间早于它则班次日期取前一天；未配置不能扫设备码（03 §3.1）。设备当天无排产时清空列表，不残留上一台设备信息（03 待确认3 的目标行为）。
- DM §5 目标：班次日期=工厂日历+时区+白班起点计算；同时保存实际时间与业务班次；跨午夜、补录、时钟偏差、订单开工时间不同都可解释；不得把订单开工时间当作每张报工的开工时间（=K01）。

## A5 计划数量硬限与超产（T09/T10）
- 排程硬限：工序槽位计划合计 ≤ 下线数量（A3）。
- 报工硬限：末道非质检工序全部报工（含未提交）合计 ≤ 订单计划数 × 超额系数；自动审核时末道累计报工 ≤ 生产数量 × 超额系数（01 §3.3 提交报工、03 §3.2）。物流入口不校验订单状态和超额（01 §3.3）。
- DM §4.2：超产比例在服务端按同单位检查，不仅界面提示；件数/盘数与长度/重量不可互相覆盖。
- 隐患口径：PRD「工序完成数量」在提交时重算且不看提交/审核状态（把未提交产出也计入，01 §3.3）；目标口径=草稿数/提交数/审核数/合格数/入库数分别展示（S02、DM §5）。

## A6 三入口共享报工规则（T10）
- 三入口与来源：实绩录入→来源「订单报工」（订单列表→工作台→实绩录入）；工作台→来源「工作台报工」（车间→工序宫格，工序固定）；扫码报工→来源「扫码报工」（扫设备码→按班次日期带任务单→工序默认=该设备当天排产工序、设备默认=扫到的设备）（01/02/03 §1.1）。ROADMAP T10 要求「同工序规则不分叉」，ReportContext=来源/工序/设备显式绑定（DM §2 execution_session；K13）。
- 草稿隔离键：同操作工+同订单+同来源至多一张未提交报工单；工作台报工再细分到工序（01 §1.2）。跨来源互斥：有其它来源未提交单时不允许进入（01 §3.1、03 §3.1）。草稿续作：再次进入带出产出/托码/库位/备注并锁工序；主页「N条报工待提交」直达最早草稿（01 §3.3）。本机暂存仅体验层，不能当最终依据（DM §6；P1 README 关键规格 2/3）。
- 工序可开工判定（现状三口径，目标统一）：实绩录入=首道或前道有已提交报工（01 §1.2 工序标签）；工作台=前道（跳过质检工序+系统参数「报工跳过工序」）存在已提交且有产出的报工单（02 §3.3）；扫码=同实绩且工序限定设备工作中心（03 §3.2）。DM §5 目标：按前置工序、物料、设备与质量规则就绪，不能只判断「前道出现过一张报工单」。质检工序、非本部门工序、未设生产部门工序一律不可选（01 §3.3）。
- 审核轴：以订单末道非质检工序为准（末道为质检时往前取最近非质检；全质检不自动审核）；报非末道→自动审核通过；报末道且该工序生产部门在「末道自动审核车间」配置→自动，否则待审核（01 §1.1）。物流报工：保存产出即审核通过、提交生成入库单、不走审核后回写（01 §1.1；DM §5 物流入口连入库任务，不制造第二份产出、自动审核不绕过校验）。
- 自动/人工审核通过后统一动作：产出转所选线边库（车间线边库，末道用成品线边库、其余半成品线边库，01 §3.3 选择载体/仓库）；回写订单已完成数量、排产完成数量；发起成品质检；写工时日志；末道且非样品订单推 ERP、末道非质检另推上架任务（04 §2.2）。草稿不能审核；一张报工单只存一道工序（K15）。
- 修正/撤销（04 §2）：编辑只改工序/人员/产出数量、不改审核状态，有产出时工序不可改；人工审核通过后不可编辑；删除须报工单待审核且产出码未被改动/未入库，自动通过单删除时扣回库存与质检；取消审核撤回入库/完成数量/排产完成/质检，产出已入库、被消耗、质检完成任一命中即拦截（目标=检查对象关系而非全入库标记，K18）。生效事实走冲销不做数量改 0 隐式删除（K17）；产出已入库/消耗/转换/发运后不可直接取消原审核（DM §8）。
- 数量口径：保存界面选择的合法实际时间与生产人员，编辑不重置事实、越界时间拒绝（K01）；单位从业务对象读取随数量展示（K08）；空码不能提交（K07）；撤审/审核失败只显一条主错误（K19）。

## A7 领投料（T11）
- 单独投料定位：不依附报工单，扫码后直接提交即扣减（05 §1.1）；投料工序栏单选、质检工序不可选、已有投料行不能换工序；本机暂存按「订单+入口」不区分用户不过期（05 §3.1——目标仍以服务端为准，DM §6）。
- 码准入：只接受产品轴码（10 位载具码第 2 位 E/F/M）；托码/原料码拒绝。校验链（05 §3.1 扫码投料）：码存在于二维码档案→有销售单号+行号→已审批或质检完成→在库→所在仓库存→必须在线边库→成品/原料不可消耗→非本工序产出→本订单半成品必须是投料工序之前任一道（不限于紧邻前道）产出→可投数量>0。同一码按销售单号+行号拆多行；任一销售行可投为 0 整码拒绝。
- 跨订单：非本订单半成品弹确认后可投并标记（05 §3.1）——目标升级为核对物料规格、质量、客户限制和授权，形成谱系与成本归属，不把一次确认当充分授权（S11；DM §4.3）。
- 扣减与记录：提交事务内实时校验余量并扣减，记扣前/扣后余额，扫码快照仅界面参考（K05；DM §6 单独投料事务边界=锁库存单元→校验→扣减→消耗记录→谱系→事件→Outbox）；按销售行汇总本次投料≤剩余；记录投料类型（报工投料/单独投料）、一次提交一批、投料前/数量/后、发料仓库、工序、人、时间（05 §3.1）。PRD「扣到 0 删码档案」改为零余额关闭活动余额、身份谱系保留（DM §4.2，见 B6）。
- 外传：写 SAP 投料日志、发库存变动消息；消息必须包含真实被消费库存单元、与流水原子提交、统计投影可重建（K04；DM §6）。
- 原料侧（PRD 无原件，S12 显式补强，DM §4.3）：领用、退料、投料、辅料消耗、余料回仓、废料回收各有去向；自动倒冲仅在工艺明确允许时使用并标估算/实耗；替料/混批按工艺/质量授权形成偏离记录，保留批准范围、原配方与实际投料。

12. **工序就绪判定**：三入口三种判定（A6 第 3 条）vs DM §5 统一就绪规则（前置+物料+设备+质量）——实施须收敛为单一服务端判定，K13。
13. **DM 新增能力无 PRD 原件**：完工待核状态、开工缺映射/授权拦截、原料领退耗全链、替料/混批授权——按 S12 作显式补强进入合同，不按文字提及宣称覆盖。

# D. 对底座合同的依赖点（阶段 3 对齐清单）

**D1 库存/追溯内核（T06，DM §2/§6）**
- 命令：线边库扣减（单独投料，按稳定次序锁库存单元）、产出转仓（报工审核生效点）、撤回入库（取消审核）、扣回库存+撤质检（删除自动通过单）；均须可加入上层命令同一 Unit of Work。
- 校验：实时可用量（质量+预留条件形成可用量）；余量竞争并发保护（唯一约束/预期版本/行锁，§9 样例 1：100m 对 70m/50m 不出负数、重试不重复扣）；同一码不能多任务同时消费（§5）。
- 记录：stock_transaction 必含扣前/扣后余额；零余额关闭活动余额保留身份与谱系（替代删码档案）。
- 谱系：投料消费边、报工产出单元、客户轴号绑定（同订单一轴号一绑）。

**D2 幂等命令（T07，P1 关键规格 2/3）**
