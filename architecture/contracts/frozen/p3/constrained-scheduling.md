## 2. 约束种类与强度分级

| 编号 | 规则（可判定） | 溯源 |
| --- | --- | --- |
| CS-04 | 约束强度二分：**硬约束**（违反即拒绝排产/开工命令）与**软约束**（违反须填写理由与责任人后方可提交）；任何排程输出（人工或系统建议）不得绕过硬约束。 | PI S10；PC §4（计划员行）；P3README §4（计划与维护行） |
| CS-05 | 首期硬约束清单：①工序计划合计≤下线数量（CS-02 原文强校验）；②维修中设备禁新建正数槽位（CS-01 原文）；③校准过期/失准设备禁新建正数槽位（PE-13/17 联动）；④冻结窗口内槽位对重排只读（CS-11）；⑤前置工序/物料/设备/质量就绪条件不满足不得开工（就绪规则 CS-07）。 | 原件 两排程 PRD；DM §5；**[合同新造]**（清单化③④） |
| CS-06 | 首期软约束清单：①超设备日产能（原文二次确认）；②交期冲突（建议完工晚于计划完成时间）；③换型时间非最优；④设备/班次负荷不均衡。软约束违反记录 操作者、理由、影响范围。 | 原件 两排程 PRD；PC §4；**[合同新造]**（②③④） |
| CS-07 | 就绪规则：工序任务按 前置工序完成、物料齐套、设备可用、质量规则 判定就绪；不能只以"前道出现过一张报工单"判定就绪。 | DM §5（工序任务行） |
| CS-08 | 物料齐套口径：默认＝该工序计划需求的可用量（满足质量与预留条件的余额，IT-14 语义）覆盖；"计入在途/预留"的扩展口径为配置项（取值 → GAP-E12）。 | DM §5；IT-14；**[合同新造]**（默认口径） |
| CS-09 | 维护约束：计划保养与已发生维护停机（downtime_event，T19）占用设备可用能力；维修关闭触发受影响排程的计划评估（提示计划员，不自动重排）。 | DM §5（维修工单行）、§2（维护行）；RM T19 行 |
| CS-10 | 校准约束：校准过期/失准设备的**新建**正数槽位拒绝（硬约束）；**已排**槽位不自动删除，标记提示由计划员决定转移或保留（处置 → CA-11 待裁）。 | RM T23 行；PE-17；**[合同新造]** |

## 3. 有限能力与可解释性（非黑盒）

| 编号 | 规则（可判定） | 溯源 |
| --- | --- | --- |
| CS-11 | 冻结窗口：冻结对象为 设备×生产日期 的槽位集合（可细至单槽位）；窗口内槽位对自动重排只读；解冻须具名权限＋理由并留痕。冻结期默认长度与解冻角色 → GAP-E9（现场）＋建议默认 1 个生产日。 | P3README §2 T22 行（"冻结"一词的落地）；**[合同新造]**（机制） |
| CS-12 | 可解释性：排程建议/重排输出必须逐任务给出 命中约束清单（为何移至此设备/此日期、被拒原因）；不使用无解释的黑盒数学优化输出直接落账。 | SA §2（排程先做可解释的能力与约束规则）；P3README §4 |
| CS-13 | 回放比较：每次重排生成排程版本快照；系统建议与人工最终版本、以及前后版本可并排回放比较；人工对建议的每次覆盖记录 操作者、理由、影响任务清单。 | P3README §4（计划与维护行）；PC §4 |
| CS-14 | 插单/重排影响呈现：重排执行前先输出受影响任务清单（含被移动的已派工/已开工任务说明）；已开工任务不被自动移动，须人工决策。 | P3README §2 T22 行；DM §5；**[合同新造]** |
| CS-15 | 无解呈现：约束冲突无可行解时，不静默丢弃任务，呈现冲突集与可选建议（放开工期/换设备/外协），由计划员决策。 | **[合同新造]**（依据 CS-12 可解释原则） |
| CS-16 | 换型时间：换型矩阵（工序/产品属性维度 → 换型时长）为版本化配置，换型时间计入设备日历占用；矩阵数据来源须现场工艺提供（原件无换型概念， → GAP-E8）。 | P3README §2 T22 行；**[合同新造]** |
| CS-17 | 交期权重：订单交期权重默认取计划完成时间紧迫度；建议排序默认 交期优先 → 换型最少 → 负荷均衡，权重可配置并随排程版本留存；权重取值 → GAP-E11。 | P3README §2 T22 行；PC §6（订单准交率口径）；**[合同新造]** |
| CS-18 | 求解范围：有限能力计算窗口为 当日起至多 N 个生产日（默认 7，可配置）；窗口外任务不参与优化、仅列示。 | **[合同新造]** |
