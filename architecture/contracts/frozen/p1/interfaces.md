# T02 冻结合同 — 外部接口（interfaces）

版本：L2 冻结合同候选 v1｜2026-10-28｜WorkItem：`L2-T01-T02-CONTRACTS`（RunKit，里程碑 P1）
状态：**待 PM 签发**。标记约定同 `org-auth.md`：**[合同新造]** 为原文与规划正文均未定义、由本合同提出的语义，随 PM 签发生效。

**总裁决（承接底稿02）**：13 个接口族全部无真实报文样例/协议文档（PRD 仅页面级行为线索，系统名多为"文档名称级"提及，与 PI S07 判定一致）。因此全部接口的"内部账务＋Outbox 任务＋模拟适配器"合同先行；被样例阻塞的仅是"真实适配器联调＋字段级映射＋外部错误语义"这一层，不阻塞 P1 内部实现。真实 URL、账号、凭据一律不填造（GAP-B1）。

**溯源标记**：（原件）= `requirements/source/PRD文档/…`；（底稿02 §X-n）= `architecture/contracts/prep/p1/02-external-interface-facts-T02.md`；（SA §5）集成矩阵；（DM §6/§7）事务与恢复。
