## 5. 流水 / 余额 / 预留 / 幂等记账

| 编号 | 规则（可判定） | 溯源 |
| --- | --- | --- |
| IT-18 | 库存域是数量/库位/所有权/预留的唯一维护方；其它域经库存命令进入同一 Unit of Work，禁止其它模块直接更新 stock_balance。 | DM §6；底稿01 §A③-45 |
| IT-19 | stock_transaction 幂等唯一键 `(command_receipt_id, line_no)`；每条流水必含扣前余额与扣后余额。 | 底稿01 §D-9；DM §6；PI K05 |
| IT-20 | 余额唯一键 `(unit, location, owner)`；交易决策用的余额与可用性在主事务内实时更新；统计/看板/导出投影异步并显示延迟，不得以异步报表余额批准发货。 | 底稿01 §D-9；SA §4.2 |
| IT-21 | 幂等键按企业、命令种类、operationId 唯一；相同键＋相同载荷返回原结果；相同键＋不同载荷拒绝；断响应后终端查询原 operationId，不得换新键重发。 | SA §4.1 |
| IT-22 | 命令响应至少区分五种：成功已入账 / 保存草稿 / 业务校验失败 / 版本冲突 / 结果未知待查询；批量操作明确全成全败或逐行结果。 | SA §4.1 |
| IT-23 | 作业预留四要素：所有者、占用对象、有效期、释放记录；过期后旧终端提交必须重新校验（不得凭过期预留直接入账）。锁定类冲突（原文锁定无有效期）→ CA-5 待裁，内核侧冻结"预留必须含有效期"机制本身。 | DM §6；底稿01 §A③-46、§D-9；CA-5 |
| IT-24 | Redis/本地缓存不作库存最终依据；本机暂存仅体验层。 | DM §6；PI（P1 README 关键规格，经底稿03 §A6） |

## 7. 守恒、不可逆与谱系

| 编号 | 规则（可判定） | 溯源 |
| --- | --- | --- |
| IT-28 | 分盘/倒轴守恒式：`原量 = 子段量合计 + 留存量 + 已记录损耗量`；任一分录不满足即拒绝提交。 | DM §4.2、§9 样例2；底稿01 §A③-39 |
| IT-29 | 数量为零的库存单元：关闭活动余额，身份与谱系节点保留，不删除档案。（原文"扣完移除/扣到 0 删码档案" → 投料侧冲突登记 CA-1 待裁；内核侧冻结零余额关闭语义。） | DM §4.2、§8；底稿01 §A③-39、§B-3；CA-1 |
| IT-30 | 贯穿验证样例三则（验收合同直接引用）：① 余量竞争——单元剩余 100 m，并发提交 70 m 与 50 m，最多一个按原量成功，另一得到可解释冲突，账上不得出现 -20 m，重试不重复扣减；② 分盘与修正——1,000 m 分为 600 m＋390 m＋10 m 损耗合计一致，600 m 子轴已发运时回撤原倒轴必须受阻；③ 接口半成功——U9 已批准库存形态转换、MOM 写入前进程退出，恢复只应用同一转换的本地事务，外部单据不新增第二张，最终可对账。 | DM §9 |
| IT-31 | 不可逆事实：任一产出已入库、被消耗、被转换、已发运或已形成生效质量结果的，不可直接取消原审核；纠正走逆序冲销或质量处置流程；盘点/截取/成品异常扣数必须记录原因与去向。 | DM §8；PI K18、S05 方向 |
| IT-32 | 冲销命令语义：校验下游引用与对象版本→写反向流水→新建纠正事实→更新影响结果→审计；对外冲销事件异步（Outbox），不阻塞本地冲销入账。 | DM §6 |
| IT-33 | 生效事实不得以数量改 0 隐式删除；显式删除仅限普通草稿（保留操作记录）。 | DM §8；PI K17 |
| IT-34 | 谱系边类型（首期）：采购批次明细→库存单元（正向起点）、投料消费边、报工产出单元、客户轴号绑定（同订单一轴号一绑）。 | DM §2、§8；底稿03 §D-1 |
| IT-35 | 追溯语义：正向="这批原料去了哪些在制、轴段、客户交付"；反向="这根交付轴由什么料、哪些工序、设备、人员和质量结果产生"；追溯精度按证据分级（批次/库存单元/轴段区间），无连续计长证据不承诺任意一米定位。 | DM §8 |
| IT-36 | 轴号修正目标口径：不自动解绑他人已占用客户轴号；冲突先展示占用与影响，核权后执行显式重新分配；截取单位随物料，不固定米。 | PI S15；DM §8；底稿01 §A③-48 |
| IT-37 | 时间双轨：实际时间与系统时间分列；班次日期按工厂日历＋时区＋白班起点单独计算（细则 GAP-A3/GAP-C4 待现场）；不得把订单开工时间当作每张报工的开工时间。 | DM §5；PI K01；底稿01 §D-11 |
