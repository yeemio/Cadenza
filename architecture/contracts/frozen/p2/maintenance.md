## 2. 维修工单闭环（**[合同新造]**——S12 显式新增，原件无工单概念）

| 编号 | 规则（可判定） | 溯源 |
| --- | --- | --- |
| MT-07 | 维修工单状态机：已报修→分派→处理中→待复机→关闭；取消另记（独立状态）；合法迁移集封闭，越级/逆向迁移拒绝；关闭必须记录结果与责任人（任一为空不可关闭）。 | DM §5（维修工单行）、§116 |
| MT-08 | 状态是投影：设备状态（正常/维修）由工单事件驱动——受理报修建单置"维修"、复机关闭置"正常"；直接改状态命令（Web 行内/异常上报）保留（原文行为），每次变更记流水；置"维修"建议关联在单工单（是否强制关联 → GAP-F23 同批裁定）；维护事实源=工单，状态≠事实。 | DM §2（设备维护行：设备状态是投影）；MT-02/03 |
| MT-09 | 停机事件：downtime_event 记录停机起止、原因（停机原因分类字典 → GAP-F22）、关联工单；置"维修"即开停机事件、复机关闭即闭停机事件；起止时间原子记录，同设备停机区间不重叠、无负时长（复机与排程竞态下可解释）。 | DM §2（设备维护行）；A10；GAP-F22 |
| MT-10 | 复机与能力恢复：复机执行 = 工单关闭（结果=复机正常＋责任人）＋置设备状态正常＋闭停机事件＋向排程（T09 schedule_slot/capacity_calendar）发布能力变化事件（Outbox，含停机起止与原因）触发计划评估；一次事务完成，复机失败不改变工单状态。仅"待复机"状态可执行复机。 | DM §5（维修工单行）、§116；A10 |
| MT-11 | 备件消耗：备件作为物料走同一库存域（IT-18 唯一记账方）；备件动用与工单关闭同事务写消耗记录＋库存流水（扣减走 stock_transaction，含扣前/扣后余额）；消耗数量 > 0 且 ≤ 实时可用量；备件物料清单来源/存放仓库/安全库存/单价 → GAP-F21。 | DM §2（设备维护行）；IT-18/IT-19；GAP-F21 |
| MT-12 | 点检/保养计划（**[合同新造·框架]**）：maintenance_plan 版本化（周期＋检查项模板）；inspection_round 记执行结果（实际时间＋业务班次双存，IT-37）；超期未执行提示、不自动阻断生产（默认口径，现场流程 → GAP-F19）；计划配置变更不回写已执行记录（引用计划版本快照）；点检不合格产生异常记录并建议关联报修（是否自动建单 → GAP-F19）。 | DM §2（设备维护行）；IT-37；GAP-F19 |
| MT-13 | 报修入口与分派（**[合同新造]**）：工单创建入口首期 = 异常上报（置"维修"时可关联建单）＋Web 手工报修；分派 = 已报修→分派（记录分派人与被派人）；分派角色与通知方式 → GAP-F20。 | DM §5（维修工单行）；GAP-F20 |
| MT-14 | 取消语义（**[合同新造]**）：已报修/已分派/处理中可取消（取消原因必填）；待复机/已关闭不可取消；取消不删除已产生的停机事件与状态流水（停机事实保留）；关闭后工单结果不可再改。 | DM §5（维修工单行：取消另记） |
| MT-15 | 维护与排产解耦（**[合同新造]**）：停机/复机只发布能力变化事件（含起止与原因），不直接改排程结果；排程重评估由调度域（T09）消费事件执行；事件与停机事件可对齐（工单→停机→能力事件链可追溯）。 | DM §2（设备维护行：维护停机与生产运行共同形成可用能力）；A10 |
