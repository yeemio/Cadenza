# Cadenza 线缆行业 MOM 产品建设规划

版本：规划 v0.1｜日期：2026-10-27｜状态：规划交付，尚未启动产品开发

**Cadenza 建设为覆盖生产、质量、库存物流、设备维护的线缆行业 MOM。以订单为业务起点，以批次、轴段和载具为现场对象，以工艺版本、库存流水和全过程追溯为共同基础，连接计划、车间、质量、仓储、设备和经营管理。**

建设范围包含现有 PRD 的全部业务能力，也包含完整 MOM 必需、但原包尚未系统定义的工艺工程、过程质量、设备维护、原料消耗、盘点、生产绩效、能源和制造成本分析。先贯通生产经营事实，再扩展自动采集和优化；每期均交付可运行、可对账的业务链。

### 1.2 产品与行业边界

MOM 的基本业务范围按生产、质量、维护、库存四类运营组织。这一划分可参照 [NIST 对 ISA-95 四类运营的说明](https://www.nist.gov/publications/integrated-operations-management-distributed-manufacturing)。本方案对具体模块、数据模型和交付顺序作独立设计。

原文足以支持“按米／重量／件计量、按轴与批次流转、具有多工序及绞合关系、按客户段长和装箱要求交付”的产品定位；不足以认定只生产某一种电压等级或所有工厂采用同一工艺。系统以产品族管理工艺路线，拉丝、绞合、绝缘、成缆、护套、检验、分盘等作为可配置工序示例。具体是否需要退火、交联、铠装或其他工序，由获准工艺版本定义，不能全厂写死一条路线。

| 系统或角色 | 拥有的主要事实 | Cadenza 的责任 |
| --- | --- | --- |
| ERP／U9／SAP | 销售、采购、财务、上游生产指令及其商业关闭状态；具体字段按组织绑定主系统 | 接收有效版本；维护生产现场事实；回传收货、领耗、产出、发运结果并对账 |
| DC／国贸业务系统 | 合同装箱、客户分段、发货指令等外部商业要求 | 将要求落实到具体轴段、托箱、装载与实际发运，不自行改合同 |
| Cadenza | 工序执行、现场库存、质量隔离与放行、轴段谱系、设备维护、现场绩效 | 统一操作与追溯；向上游提供有来源、可修正的结果 |
| PLC／SCADA／检测仪器 | 设备控制和原始测量 | 通过边缘适配读取；关联设备、工序、批次和时间；不承担 PLC 实时控制或安全联锁 |
| 人员与岗位 | 实际操作、检验判定、维修确认、异常原因 | 按权限记录和审核；不得用设备采集值自动冒充人工质量放行 |

财务总账、税务、合同报价、工资结算和设备安全控制不由 MOM 重建。制造成本提供可核对的数量、工时、能耗和成本归集依据，财务定价与记账仍归授权财务系统。

## 3. 线缆行业必须先建好的模型

1. **批次、产品库存单元与轴盘载具分开。** 载具可以重复使用，物料身份与历史不能被“清空轴码”抹去。一个码对应多个物料／批次时先展开库存明细，不能只拿码值直接扣数。
2. **长度、重量、件数分别管理。** 米与千米可按固定比例换算；重量与长度要区分理论米重、实际称重和校准来源。芯倍数和绞合系数用于工序需求推导，不是库存凭空增减依据。
3. **工艺和订单执行快照绑定。** 产品 BOM、路线、参数、检验规范、客户分段和换算规则都有版本。已生产事实不随模板编辑重算；计划变化有新版本及在制处置。
4. **倒轴、分盘和多芯汇合形成谱系。** 分盘保留来源段和损耗；多根芯线进入成缆应记录多输入到输出的关联。不能把所有工序的米数简单相加作为最终产量。
5. **库存、审核、质量、位置、业务锁各自独立。** 待审核产出可以现场暂存，但不能自动成为可领用／可发运库存；同一实物在两个工厂或两个业务任务中不能重复使用。
6. **客户轴号与内部唯一身份分开。** 客户编号、段长和合同归属可经过业务修正，内部追溯 ID 永远不变。修改客户归属不冒充物理加工或库存增减。

详细实体、状态与事务边界见 [领域与数据模型](DOMAIN_MODEL.md)。

## 4. 岗位与工作入口

| 岗位 | 默认工作入口与日常任务 | 必须控制的边界 |
| --- | --- | --- |
| 生产管理／计划员 | 交期与缺料工作台、订单工序、设备负荷、下达／改排 | 不能越权改质量结论；超能力排产有明确理由和责任 |
| 工艺工程师 | BOM／路线／参数／检验规范发布、变更影响、作业文件 | 已执行版本保留；生产中变更不能静默覆盖 |
| 班组长 | 班次任务、人员分配、待审核报工、异常协调、交接 | 审核权限与本人报工的职责分离按工厂规则落实 |
| 操作工 | PDA／工位终端的订单、工序或扫码入口；投料、报工、倒轴和异常 | 按工厂／车间／工序授权；明确草稿、已提交和已入账 |
| 质检员／质量负责人 | 待检、实测、判定、隔离、复检、放行与质量证明 | 普通操作员不能解除质量隔离；结论修正保留原记录 |
| 仓管员 | 收货、扫码上架、调拨、移库、盘点、备货、装箱及出库 | 对库存和位置负责；不得直接编辑库存统计结果 |
| 采购／国贸协同人员 | 采购批次复核、外部订单差异、分段装箱与实际发运核对 | 不在 MOM 篡改上游财务及商业合同主数据 |
| 设备维修／计量人员 | 点检保养、维修、停机分类、工具寿命、校准 | 维修关单须有结果与复机确认；计划同步停机约束 |
| 厂长／经营管理 | 交期、在制、良率、损耗、设备、能源和成本趋势 | 每个指标能钻取原始事实；未知分母不显示假百分比 |
| 系统与集成管理员 | 用户、配置、接口异常、打印任务、备份恢复 | 管理权限不等于任意删除已入账业务事实 |

Web 面向计划、审核、工程、分析和运维；PDA 面向扫码作业；工位终端面向当前机台与班次；大屏面向只读趋势。四者共享命令与权限规则。页面需要同时展示“业务结果”和“外部同步结果”，不能只用一个绿点代表全部成功。

## 5. 端到端业务验收场景

以下 A 编号是稳定业务场景编号，各阶段复用其适用部分。真实交付必须由相应岗位完成，自动化测试只支持其中的技术保证。

| 编号 | 贯通场景 | 可观察结果与关键反例 |
| --- | --- | --- |
| A01 | 组织／物料／工艺与订单准备 | 两个组织相同外部编码正确隔离；订单绑定已发布路线及单位版本；缺失映射隔离待处理，不能自动认错工厂 |
| A02 | 采购订单→分批收货→来料检验→上架／退货 | 订单行、批次、单码、实物与库存数量一致；免检有依据；不合格批次不能投产；价格复核不擅自改变质检或库存 |
| A03 | 订单工序展开→设备排程→班次执行 | 工序需求按芯倍数和绞合规则形成；订单／设备视图一致；跨日班次正确；挂起、缺映射及不可用设备阻止不合法开工 |
| A04 | 领料／投料→工序产出→审核→流转 | 同一单据从三个入口进入结果一致；草稿不计正式产量；重复提交只入账一次；两台 PDA 争用同一余量不会扣成负数 |
| A05 | 倒轴／分盘→组托解绑→客户轴段修正 | 同物料分盘前后数量守恒，损耗有去向；客户段长限制生效；可追溯所有来源和去向；后续已消费时拒绝直接回撤 |
| A06 | 过程检验→隔离→处置→成品检验→放行 | 不合格和存疑产品被拦截；复检保留历史；返工走批准路线；让步批准不伪装成原始检验合格 |
| A07 | 待入库→成品入库→移库→调拨在途→收货 | 两个入库入口共用同一业务记账；在途不会被两仓重复统计；跨厂接收具备真实收货证据；盘点差异以调整单处理 |
| A08 | 合同分段／PL→打包备货→确认出库→外部回传 | 件数、长度、客户轴号与装箱要求对应；质量锁和库存预留生效；实际轴回传与发运状态回传独立恢复 |
| A09 | 订单归属转换及库存归属转换 | 前者按本地执行后同步；后者按外部批准后本地执行；在任一步超时重试均不重复改码／改账，项目号字段按合同处理 |
| A10 | 点检／故障→维修→复机→排产恢复 | 停机、维修、备件和复机事实串联；维修时间与生产占用冲突可解释；设备指标可追溯到停机分类 |
| A11 | 撤销、纠错、接口故障与弱网恢复 | 草稿可续作；未知提交结果可查询；任一产出已被下游使用时不能直接取消审核；恢复后业务账、接口账、统计投影一致 |
| A12 | 正反向追溯、班次统计、能耗与成本 | 指定交付轴能找到原料、过程、人员、设备、质量和修正；原料异常能圈出受影响在制／成品／发货；指标有明确分母与单位 |
| A13 | 干净安装、迁移对账、恢复与岗位试点 | 非开发者按手册安装；期初库存对账；恢复后单据和库存一致；真实岗位完成约定业务，保留失败及人工绕行记录 |
| A14 | 多组织／多工厂运行及权限验证 | 搜索、导出、附件、后台任务、扫码和接口均不能越过授权范围；跨厂调拨保留双方事实；集团只读汇总不变更工厂原账 |

## 6. 指标与业务价值

先采集基线，再设改善目标。规划不承诺未经测量的降本比例。

| 指标 | 口径与使用条件 | 责任岗位 |
| --- | --- | --- |
| 订单准交率 | 约定截止日期内完成交付的到期订单行／全部到期订单行；原承诺日与修改后承诺日分开保留 | 计划／交付 |
| 工序计划达成 | 同工序、同单位的合格或审核产出／冻结计划；二者口径明确，不能把各工序长度相加 | 生产 |
| 首次合格率 | 首次检验通过数量／首次受检数量；按产品与检验方案确定按轴、长度或批次统计 | 质量 |
| 材料损耗 | 相同材料、相同计量维度的投入、在制、成品、废料与回收差额；理论与实测分别列示 | 工艺／生产 |
| 库存准确性 | 盘点范围内账实一致的库存单元及数量差异；单位／质量／库位均参与核对 | 仓储 |
| 设备绩效 | 可用率、性能、质量率的时间窗和分母齐备后计算 OEE；未采集停机或标准速度时展示缺项 | 设备／生产 |
| 能源单耗 | 明确计量表、采样覆盖和分摊版本后，按产品族或工序计算；订单估算与实测分开 | 能源／工艺 |
