# 配置清单与密钥管理（DO-01 第 4 项 / DO-04）

版本：2026-10-28

## 1. 配置隔离（演示 / 测试 / 生产）

| 环境 | 配置来源 | 隔离要求 |
| --- | --- | --- |
| 演示 | 安装时 `--with-demo`（装载 demo-bootstrap.sql + demo-dataset） | 演示库与真实业务库物理分开；演示数据永不进入生产库（DO-03） |
| 测试 | 各线独立测试库（cadenza_&lt;线名&gt;，每轮 DROP+CREATE） | 与共享 dev 库互不影响 |
| 生产 | 现场 `.env` / 密钥管理系统 | 交付物**不携带真实凭据**（本目录全部文件无任何真实口令） |

## 2. 配置项清单（随 `.env.example`，只读引用不重复维护）

- `DATABASE_URL`：生产必须显式提供（应用回落 dev 默认会告警，安装自检拦截）。
- `PORT` / `WORKER_INTERVAL_MS` / `WORKER_BATCH_LIMIT`：运行参数。
- `AUTH_SESSION_TTL_MINUTES` / `AUTH_MAX_LOGIN_FAILURES` / `AUTH_LOCK_MINUTES` / `ACCOUNT_INIT_PASSWORD`：认证与账号参数。

## 3. 密钥生成、保管与失效替换（点名历史坑：重启后签名密钥失效、空模块配置破坏运行）

1. **生成**：现场部署时以密钥管理系统生成（口令/密钥不得写入仓库与发行包）；会话凭据依赖库内 scrypt 散列与系统参数，无长期签名密钥文件。
2. **保管**：密钥清单随备份独立保管（备份件不含明文密码，DO-15）；保管责任人现场指定并登记。
3. **失效替换**：疑似泄露立即轮换——数据库口令经 `ALTER ROLE` + 现场环境变量同步更新后滚动重启；账号口令走产品内重置（散列重写）。
4. **安装后重启自检（必做）**：`deploy/install/selfcheck.sh` 覆盖 数据库连通、迁移版本完备、健康端点、关键配置非空——历史坑「空模块配置/密钥失效在重启后才暴露」由该步骤拦截（DO-04）。

## 4. 交付物凭据核查

- 交付目录内任何文件不得含真实口令/密钥/证书私钥；发行前以密钥扫描复核（现场工具自选，核查项登记入发行检查记录）。
