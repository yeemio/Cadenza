# 旅程剧本 A12：正反向追溯、班次统计、能耗与成本（多岗位合用）

- 服务格：P01-A12（生产计划）、P02-A12（工艺）、P03-A12（班组长）、P05-A12（质检）、P08-A12（维修计量）。同旅程岗位样例：pb-P09-A12.md（厂长：指标钻取与分母）。
- 前置条件：已有完整业务数据（A02–A10 至少一轮）；报表域权限（reporting.read 等）。
- 现场占位参数：【占位：交付轴样本号（追溯演练用）】【占位：原料异常样本批次】【占位：能源单价版本与抄表周期】【占位：成本分摊版本】【占位：班次统计口径定版（白班起点）】。

## 步骤
按岗位分节执行；入口均为系统真实页面路由（Web 侧导航或 PDA 底部导航，路由见各步）。

### P01 生产计划（口径与班次统计视角）
1. Web「报表与指标→报工口径汇总」（/p2/reporting/summary）：按五量口径逐列核对（RP-16：草稿/提交/审核/合格/入库各自有口径，不混成一个完成量；勾选汇总按基本单位分组累加 4 位小数，RP-05；总量为服务端全量聚合，RP-17）。
2. 「生产管理」订单五量分栏与汇总口径交叉核对一致；英尺数＝基本单位数量÷0.3048 截取 4 位（不四舍五入），非米单位显示"-"（RP-03）。
3. 班次快照核对（reporting/shift-snapshots；班次日期按 A4-2 双轨口径），与【占位：班次统计口径定版】一致。

### P02 工艺（SPC 与变更影响视角）
1. Web「工艺与计量→SPC 控制图」（/spc/charts）：选控制项查看控制图与样本；控制限重算走 recalc（留版本）。
2. 「工艺变更」（/spc/changes）核对变更影响范围：变更前后控制项/参数对照；超差任务（ooc-tasks）处置留痕（ooc/dispose、confirm-recontrol）。
3. 样本口径抽查（ot/samples、spc/sample/record）：实测样本与控制图点位一致。

### P03 班组长（班次指标视角）
1. Web「报表与指标→指标与追溯」（/p2/reporting/metrics）：按班次/工序列指标；未知分母不显示假百分比（分母缺失保留缺失标记与原因，不以 0 冒充，RP-21）。
2. PDA「P2 作业→累计」（/p2/cumulative）：核对当班累计口径（reporting/pda/cumulative）与 Web 班次快照一致。
3. 成品入库状态口径核对：库存状态=正常且报工仓库类型为仓库→已入库；线边仓→未入库（RP-04）。

### P05 质检（正反向追溯视角）
1. Web「报表与指标→轴查询」（/p2/reporting/axis-query，只读投影：只查询/导出，无增改删，RP-08）：输入【占位：交付轴样本号】正向追原料、过程、人员、设备、质量和修正记录（A12 场景；追溯明细 reporting/trace/:unitNo）。
2. 反向圈影响：对【占位：原料异常样本批次】用前向影响查询（disposition/qc/batches/:batchNo/forward-impact）圈出受影响在制/成品/发货。
3. 采购来源轴口径：报工状态固定"-"，按报工状态筛选时不包含采购来源轴（RP-09）。

### P08 维修计量（能耗与设备效率视角）
1. Web「成本与能源→能源单耗」（/cost/energy）：按【占位：抄表周期】录入/核对抄表读数（cost/meters/readings）；能源单耗分母为对应产量口径。
2. 「成本报表」（/cost/reports）：成本核算运行（runs）与订单成本汇总（orders/:id/summary）核对；分摊与单价按版本（allocation-versions/price-versions，【占位：版本号】）。
3. OEE 核对（/cost/oee）：可用率×表现×质量三因子分母明确；停机损失追溯到停机分类（csw/downtimes 与 maintenance downtime-events，A10 串联）。
4. 工具寿命与计量（/spc/tools、/spc/calibration）：工具消耗/调整留版本（tool/consume、tool/config-revise）；失准圆环（miscalibration/circle）处置留痕。

## 预期反馈
含关键数字与状态文案（取自系统实际展示与冻结合同规则口径），按岗位核对。

### P01
- 五量各列可分别核对且与订单详情一致；混口径"完成数量"不存在（A5-3/RP-16）。
- 班次统计跨零点归班正确（A4-2）；汇总值与明细逐行累加一致。

### P02
- 控制图点位与样本一一对应；控制限变更留版本；变更影响可对照。

### P03
- 指标页无假百分比：分母缺失显示缺失标记与原因（RP-21）；PDA 累计与 Web 快照一致。

### P05
- 指定交付轴完整链路可追（原料→过程→人员→设备→质量→修正，A12）；原料异常圈出的受影响清单覆盖在制/成品/发货三类。

### P08
- 能源单耗与成本报表数值可追溯到抄表读数与版本化单价；OEE 三因子可展开到停机分类；工具寿命消耗可追到具体工单/工序。

## 失败恢复路径
错误码/规则码中文文案引自系统集中错误映射（packages/ui），处置动作按岗分节。

### 通用（错误码→处置）
- NOT_FOUND→「请求的对象不存在或已被删除」：核对轴号/单元号拼写（含前导零）；退役码追溯查询仍可查（RS-36）。
- FORBIDDEN_SCOPE→「没有该操作的数据范围权限，请联系管理员调整授权」：报表按厂范围授权；跨厂汇总走厂长只读口径（A14）。

### P01 专项
- 汇总与明细不一致：核对筛选口径（勾选汇总 RP-05 与服务端全量聚合 RP-17 的差别）；仍不一致按库存差异告警处置（DO-21）并转 P10。
- 班次归属争议：以 shift-date 双轨口径解释（A4-2），不改历史快照。

### P02 专项
- 控制限重算失败：核对样本量是否满足规则集要求；重算失败不覆盖旧限（版本化）。
- 样本缺失：先补采（ot/samples/ingest 或 spc/sample/record），投影页刷新；缺失以标记呈现（RP-21）不造 0。

### P03 专项
- 指标分母缺失：按缺失标记找上游事实（报工未审核/入库未完成），补齐上游后重建快照（shift-snapshot/rebuild），不手工填数。

### P05 专项
- 追溯断链（某环节无记录）：按环节回上游旅程核对（投料 A04/检验 A06/发运 A08）；断链事实登记绕行（DO-27），不拼假链。
- 影响圈选漏项：核对批次汇总口径（RP-01：采购收货码按"轴号+入库批次+厂家批次+牌号/线径"汇总）后重查。

### P08 专项
- 抄表缺失/异常：补录读数后重算（acquisition/recalc）；能源单耗分母缺产量时不显示比率（同 RP-21 纪律）。
- 成本对账差异（recon-items）：按差异清单处置（recon/resolve）；ERP 侧差异不本地改账（recon/erp-import 重导）。
- 失准处置：按 miscalibration/action 处置受影响样本；不删失准记录。
