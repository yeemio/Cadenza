# 剧本：工艺 × A01 组织／物料／工艺与订单准备

- 前置条件：已登录 Web 工程工作台；料品主档已同步；具备 BOM／路线／检验规范发布权限。
- 边界提醒：已执行版本保留；生产中变更不能静默覆盖。

## 步骤
1. 为新料品编制 BOM 与工艺路线，选择计量单位版本。
2. 发布路线版本；系统记录版本号与发布人。
3. 在一张生产中订单上发起工艺变更（新版路线），查看影响提示。
4. 回看旧版本路线：确认仍可查询且历史订单仍指向旧版。

## 预期反馈
- 发布成功后版本号递增、状态为已发布；订单绑定的是已发布版本及单位版本。
- 生产中变更触发影响提示（受影响在制清单），不静默覆盖。
- 旧版本只读保留，历史订单展开仍按旧版执行。

## 失败恢复路径
- 发布被拒（单位/料品缺版本）：补齐主数据版本后重发；拒绝原因带规则码。
- 误发布新版本且尚无订单使用：作废该版本并登记原因。
- 生产中变更影响面比预期大：暂停变更、按影响清单逐单确认后再继续；已执行部分不可回退，走纠错流程（A11）。
