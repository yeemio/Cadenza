# 旅程剧本 A09：订单归属转换及库存归属转换（多岗位合用）

- 服务格：P01-A09（生产计划）、P07-A09（采购协同）。
- 前置条件：订单转换持 conversion 域权限（Web /p2/conversion/order；PDA /p2/conversion-scan）；库存转换源库存满足选源限定（FC-17：成品、库存>0、在库、仓库类型=仓库、存储状态正常）。
- 现场占位参数：【占位：外部 U9/ERP 转换接口端点与超时阈值】【占位：项目号字段处理口径（按合同：MES 改码不改项目号，FC-16）】【占位：转换后新轴号/批次规则】。

## 步骤
按岗位分节执行；入口均为系统真实页面路由（Web 侧导航或 PDA 底部导航，路由见各步）。

### P01 生产计划（订单归属转换：本地执行后同步）
1. Web「形态转换→订单转换」（/p2/conversion/order）：新建转换单，明细仅可选生产订单行；转换后订单须同料品且非同一订单；同一"销售单号+行号"不可重复加入（FC-05）。
2. 扫码（PDA「P2 作业→转换扫码」/p2/conversion-scan 或 Web 入口）：载具码（E/F/M/P）且属于转换前订单对应库存；已用段长/客户轴号不可再选（FC-07）。
3. 完成转换：每条明细已扫轴数>0，轴号/虚拟轴号校验通过（FC-08）；本地执行完成后向外部同步。
4. 同步失败时：仅"已完成且同步失败"可重试，按完成转换时点快照重推（FC-09）；本地已执行事实保留不回滚（FC-10）。

### P07 采购协同（库存归属转换：外部批准后本地执行）
1. Web「形态转换→库存转换」（/p2/conversion/stock）：按选源限定挑选源库存（FC-17），右侧至少 1 条明细，销售单号/行号/批次号必填、每行段长必填（≥0.0001，FC-18）。
2. 提交外部（U9）：等待外部成功后再本地改码与库存统计（FC-13）。
3. 外部结果未知时：先查询外部流水再决定重试，不换键盲发（FC-03，避免 U9 侧两张单）。
4. 本地执行核对：MES 改码回写销售单号/行号/批次号/段长/客户轴号并清空虚拟轴号，不改项目号（FC-16）；推送结果（stock/push-result）与本地落账（local-apply）分离可见。
5. 转换失败单可重新转换；重新同步只做 MES 改码与库存统计，不再推 U9（FC-15）。

## 预期反馈
含关键数字与状态文案（取自系统实际展示与冻结合同规则口径），按岗位核对。

### P01
- 转换单状态推进（待转换→已完成）；编辑/删除仅限"待转换且尚无任何扫码"（FC-06）。
- 超时重试不重复改码/改账（A09：任一步超时重试均不重复改码／改账）；重复提交幂等。

### P07
- 外部成功→本地改码成功，库存统计同步更新；外部失败→本地不动（FC-13）。
- 转换前后归属可追溯；【占位：项目号字段】按合同口径不被改写（FC-16）。

## 失败恢复路径
错误码/规则码中文文案引自系统集中错误映射（packages/ui），处置动作按岗分节。

### 通用（错误码→处置）
- FC-03→「外部结果未知：先查询外部流水再决定重试，不换键盲发」：先查外部流水；确认未成单再原键重试，已成单则接续本地步骤。
- IDEMPOTENT_PAYLOAD_MISMATCH→「该操作号已提交过且内容不一致，请勿用同一操作号重复提交不同内容」：换新操作号；同内容重试幂等返回。
- IT-01→「库存对象身份不可覆盖历史：单元号/批次绑定唯一，标签补打须引用原标签」：改码冲突时按新码规则生成，不覆盖历史身份。

### P01 专项
- FC-06→「仅待转换且尚无任何扫码的转换单可编辑或删除」：已扫码的单走完成或作废流程，不强行改。
- FC-08 完成校验失败：补扫或移除空明细行后重试；轴号校验失败按提示修正（不可用的轴号已被占用/已用段长）。
- U9 同步失败（FC-10）：本地事实保留；用 sync-retry 按快照重推，直至成功；差异在外部对账中解释。

### P07 专项
- FC-20→「该码已被其它转换锁定或存在未转换成功的单据，不可再次添加」：先完成/清理在途转换单再添加该码。
- FC-18 提交前校验未通过：补齐必填字段与段长（最小 0.0001）后重提交。
- 外部已批但本地改码失败：以 stock/push-result 核对外部流水号后重跑 local-apply（重新同步口径，FC-15），不重推 U9。
