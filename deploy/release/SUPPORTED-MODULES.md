## 3. 运行环境（DO-05 版本锚）

- 容器运行时：Docker（数据库镜像 `postgres:17-alpine`，PostgreSQL 主版本 17）
- 应用运行时：Node.js ≥ 24（pnpm workspace 11.x）；应用交付物身份=dist 清单 digest（`APP-DELIVERABLE-DIGEST.json`，无独立应用容器镜像）
- 部署形态：`web/pda + api + worker + PostgreSQL + 对象存储`（DO-06；本仓库形态为开发单机，正式形态见运维手册）
- 配置锚：`.env.example`（关键项 DATABASE_URL/PORT/WORKER_*/VITE_API_BASE_URL/AUTH_*，sha256 已入发行锚）
