# 轴号修正模块 PRD 文档

---

## 1. 基本说明

### 1.1. 业务理解

本模块用于修正产品轴上的客户轴号、段长，并可截取数量。现场在 PDA 扫产品轴号，选择新客户轴号（有可选列表时）、填写截取数量后确认；系统生成一条已完成的修正记录，更新码上的客户轴号、段长、虚拟轴号，并按截取数量扣减码数量。若所选客户轴号已被其它码占用，确认后会先解绑原占用码上的轴号信息。Web 只做查询，以及对已完成记录执行「回撤数量」：把截取数量加回码上，并恢复修正前的客户轴号、段长、虚拟轴号，记录状态改为已撤销。

两端页面名称不同，业务同一套：

| 端 | 页面名称 |
| -- | -------- |
| Web | 轴码修正（菜单名） |
| PDA | 段/号修正 |

```text
PDA 扫产品轴号 →（可选）选新客户轴号 → 填截取数量 → 确认修改
        ↓
生成修正记录（状态 = 已完成）
码更新客户轴号/段长/虚拟轴号，数量按截取数量扣减
（若新轴号已被占用 → 先解绑占用码上的轴号信息）
        ↓
Web「轴码修正」点「回撤数量」→ 状态 = 已撤销
码恢复修正前轴号信息，数量加回截取数量
```

**两端分工：**

- **Web**：按产品轴号、生产单号、销售单号、修正人员、状态查询修正记录；对已完成记录回撤数量。本页不允许新增、编辑、删除。
- **PDA**：扫产品轴号查看料品与订单信息，选择新客户轴号、填写截取数量并确认修改。

### 1.2. 字典说明

#### 修正状态

Web 列表「状态」使用。文字颜色取该字典项备注里配置的颜色。

| 类型值 / 状态值 | 说明 |
| --------------- | ---- |
| 已完成 | PDA 确认修改后的状态。Web 操作栏显示「回撤数量」。 |
| 已撤销 | Web 回撤数量后的状态。 |

  - 回撤数量：有回撤权限，且状态为已完成时显示

#### 回撤数量

##### 页面元素

确认框，内容「确认回撤?」，按钮：确定、取消。

##### 交互

- 点「回撤数量」弹出确认框。
- 点确定：成功提示「操作成功!」，刷新列表；失败时由全局请求处理提示系统返回的原因。
- 点取消关闭确认框，不回撤。

##### 逻辑

- 可执行条件：记录存在且状态为已完成；已撤销时提示「已经撤回,无法重复撤回」。
- 按产品轴号 + 料品查找对应码；找不到提示「二维码为空」。
- 回撤前按「扫码」同类规则校验码（物流部仓库、已销售、质检/报工未完成、异常未处理、已锁定、无订单等），不通过时提示系统返回的原因。
- 执行后：
  - 记录状态改为已撤销
  - 数量最大的那条码：客户轴号、段长、虚拟轴号恢复为修正前；数量加上本次截取数量
  - 触发库存统计

## 3. PDA 端

> 字典见 1.2。
>
> 设计图没有侧边硬件键，需要扫码的页面或弹层都放一个「扫码」按钮，点它等同于源码里按一次侧边键。源码里「侧边按钮扫码」这类文案，设计图统一写成「点扫码」，其余文案与源码一致。设计图不播放扫码提示音。
>
> 系统返回键（侧滑、物理返回）不生效，只能点导航栏左侧返回。接口返回失败时，由全局请求处理提示系统返回的原因。

### 3.1. 段/号修正页面

**入口：**主页「质量管理」分类下的「段/号修正」。

#### 列表页面

##### 页面元素

**导航栏标题：**段/号修正；左侧「BACK」。

**未扫码时：**页面中间红字「(请点扫码扫描需要修改的产品轴号)」。

**扫码后：**白底信息区，每行左标签右内容。

| 字段 | 说明 |
| ---- | ---- |
| 产品轴号 | 标签与值蓝色；值为本次扫到的码 |
| 料品名称 | |
| 生产单号 | |
| 销售单号 | |
| 规格 | 无值显示 `N/A` |
| 颜色 | |
| 客户轴号（段长） | 有客户轴号且有段长，或两者皆空时显示，格式「客户轴号（段长）」 |
| 段长 | 仅当无客户轴号、有段长时显示 |
| 数量（单位） | 无值显示 `0` |

**选择区标题：**请选择新客户轴号

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| 新客户轴号（段长） | 点选打开底部弹层 | 有客户轴号场景，或两者皆空时显示；未选时提示「请选择」 |
| 段长 | 只读展示 | 仅当无客户轴号、有段长时显示；不可点开选择 |
| 截取数量（米） | 数字 | 提示「请输入数量」；扫码成功后默认 `0` |
| 截取后数量（米） | 只读 | 当前数量 − 截取数量 |

**页面按钮：**底部贴边整宽蓝色「确认修改」，始终显示；页面有「扫码」。

##### 交互

- 信息区无值显示 `-`（规格无值显示 `N/A`；数量无值显示 `0`）。
- 点「新客户轴号（段长）」打开选择轴号弹层（见下）。
- 截取数量：
  - 输入负数或含 `-`：清空，提示「截取数量不能为负数」
  - 大于当前数量：提示「截取数量不能大于当前数量」，并改回当前数量
  - 截取后数量随截取数量重算
- 点「BACK」回到主页。
- 本页不分页，没有下拉刷新和上拉加载。
- 点「确认修改」先做前端校验，通过后打开确认弹框（见「确认修改」）。

##### 逻辑

- 数据范围：本次扫到的产品轴号对应的码信息（一码多料品时不允许扫入，见「扫码」）。

#### 扫码

##### 页面元素

无（使用页面「扫码」）。

##### 交互

- 点「扫码」按扫到的码处理：
  - 载具码（第 2 位为 E、F、M、P）：查询该码；成功后展示信息区，截取数量默认 `0`，并拉取可选客户轴号列表；有原客户轴号时预填「新客户轴号（段长）」为当前轴号；仅有段长时预填为当前段长；再扫会覆盖上一次结果
  - 其它码：提示「请扫描正确的二维码」
- 查询失败时由全局请求处理提示系统返回的原因。

##### 逻辑

- 查询时校验，不通过时提示括号内文案：
  - 未传二维码（「请传入二维码」）
  - 扫的是托码（「不可扫托」）
  - 码不存在（「二维码不存在」）
  - 一码多物（「不可扫描一码多物的码」）
  - 码所在仓库属于物流部（「存在已经入了物流部的仓库」）
  - 已销售（「存在已经销售」）
  - 质检尚未完成（「二维码:{码}质检尚未完成」）
  - 报工未审核（「二维码:{码}报工未审核，请先完成报工审核」）
  - 异常未处理（「存在异常未处理」）
  - 已锁定（「存在已经锁定」）
  - 没有订单（「存在没有订单id」）
  - 中转轴存在未审核的成品轴（「当前中转轴存在未审核的成品轴信息」）
- 扫码只查询，不改数据。
- 原码「无客户轴号、仅有段长」时，可选客户轴号列表为空，页面不提供点选入口。

#### 选择轴号

##### 页面元素

底部弹层，高约 77% 画布，标题「选择轴号」，右上角关闭。顶部搜索框提示「搜索客户轴号」，右侧搜索图标。

列表一行一个可选轴号：

| 展示 | 说明 |
| ---- | ---- |
| 轴号（段长） | 轴号、段长都有 |
| 仅轴号 | 有轴号、无段长 |
| 仅段长 | 无轴号、有段长 |
| 已使用 | 该项已被占用时右侧显示「已使用」 |

##### 交互

- 点搜索图标按当前关键词重新拉取列表。
- 点某一项写入「新客户轴号（段长）」并关闭弹层；已使用项仍可选中，但选中勾仅未使用项显示。
- 点关闭或遮罩关闭弹层，不改已选项以外的数据。

##### 逻辑

- 可选范围：与该码销售订单行相关的订单分段明细；若原码已有段长，只保留同段长项。
- 已使用：同订单范围内已有码占用相同「段长 + 虚拟轴号」。
- 无客户轴号、仅有段长的原码：列表为空。

#### 确认修改

##### 页面元素

居中确认框，标题「确认修改」。

正文：

| 条件 | 文案 |
| ---- | ---- |
| 未选到客户轴号（如仅段长场景） | 确定执行轴号修正操作吗？ |
| 所选轴号已使用 | 该客户轴号已被使用，修改将解绑原轴号确定执行轴号修正操作吗？ |
| 其它 | 确定执行轴号修正操作吗？ |

按钮：取消、确定。

##### 交互

- 点「确认修改」前校验：
  - 有可选列表却未选：提示「请选择新客户轴号」
  - 截取数量为空：提示「请输入截取数量」
  - 截取数量小于 0：提示「截取数量不能小于0」
- 点取消关闭确认框。
- 点确定：成功提示「操作成功」，回到主页；失败时由全局请求处理提示系统返回的原因。

##### 逻辑

- 提交时按「扫码」规则重新校验该产品轴号；并校验：
  - 未传截断数量（「请传入截断数量」）
  - 截断数量小于 0（「截断数量不可小于0」）
  - 码没有订单（「存在二维码订单id为空」）
  - 仅段长/无可选列表时仍传入了新客户轴号、段长或虚拟轴号（「不可选择客户轴号」「不可选择段长」「不可选择虚拟轴号」）
  - 仅段长/无可选列表且截取数量为 0（「数据无变化,无法提交」）
  - 有客户轴号须传修正后客户轴号（「请传入修正后的客户轴号」）
  - 有段长须传修正后段长（「请传入修正后的段长」）
  - 仅有段长场景待分配虚拟轴号不足（「该订单下待分配的虚拟轴号不足」）
  - 须传修正后虚拟轴号（「请传入修正后的虚拟轴号」）
  - 传入的轴号信息不在可选列表（「无法获取修正的,客户轴号,段长,虚拟轴号」）
  - 客户轴号、段长、虚拟轴号均未变且截取数量为 0（「数据无变化,无法提交」）
  - 截取数量超出码的最大单次报工数量（「截取数量超出码的最大单次报工数量」）
  - 解绑占用码时：占用码已入非线边仓（「客户轴号存在已经入库」）、已销售（「客户轴号存在已经销售」）、已锁定（「客户轴号存在已经锁定」）
- 执行后：
  - 生成一条修正记录：产品轴号、生产单号、销售单号、料品、原/新客户轴号（段长）、原数量、截取数量、新数量、单位等；状态为已完成；修正人员、修正时间为本次确认人和时间
  - 若新客户轴号原被其它码占用：先清空那些码的客户轴号、段长、虚拟轴号
  - 本码：客户轴号、段长、虚拟轴号改为新值；数量最大的那条码数量减去截取数量
