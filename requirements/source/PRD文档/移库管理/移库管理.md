# 移库管理模块 PRD 文档

---

## 1. 基本说明

### 1.1. 业务理解

移库用于把同一仓库内在库的料品码从原库位移到另一个库位。现场在 PDA「移库」先选移入库位，再逐个扫料品码或托码，最后点「确定」提交：系统生成一条移库记录，记下移入库位、库位类型、仓库、料品名称和每个码的原库位、现库位，并把这些码移到新库位。Web 只查询移库记录和查看明细。

```text
PDA 移库
├─ 选移入库位（只列仓库类型的仓库），或扫货架码后选层数
├─ 扫料品码 / 托码 → 后端校验后返回码信息，暂存在本机，按料品汇总
├─ 扫码删除 → 只删本机暂存的码
└─ 确定 → 提交：生成移库记录，码移到新库位
        ↓
Web「移库管理」查询、查看移库详情
```

**两端分工：**

- **Web**：查询移库记录，查看移库详情（基础信息和料品列表）。
- **PDA**：选移入库位、扫码、扫码删除、确定提交；点料品卡片查看该料品已扫的码。

### 1.2. 字典说明

#### 库位类型

| 类型值 / 状态值 | 说明 |
| --------------- | ---- |
| 仓位 | 移入库位是仓库下的库位。 |
| 货架 | 移入库位是货架上的库位。 |

页头下方红色加粗提示「请使用侧边按钮扫料品码」。

**卡片展示字段：**按料品汇总，一个料品一张卡片。

| 字段 | 说明 |
| ---- | ---- |
| 料品名称 | 过长省略 |
| 料品编号 | |
| 二维码数量 | |
| 料品总量 | 蓝色 |
| 料品单位 | |

**卡片上的按钮：**无

**页面按钮：**底部整宽按钮「确定」；右下角红色圆形「扫码删除」（文字分两行「扫码」「删除」）。

##### 交互

- 料品名称、料品编号、二维码数量、料品单位无值显示 `-`。
- 从主页进入时清空页面和暂存数据；从移库详情（3.2）返回时恢复移入库位、货架层数和已扫的码。
- 点卡片进入移库详情（见 3.2）。
- 点「BACK」清除暂存数据，回到主页。
- 本页不分页，没有下拉刷新和上拉加载。

##### 逻辑

- 数据范围：本次在本机暂存的已扫码，按料品编号汇总；料品总量为该料品已扫码数量之和，二维码数量为各码的子码数之和。

#### 选择移入库位 / 货架层数

##### 页面元素

**库位选择：**底部弹层，高约 80% 画布。顶部圆角搜索框，提示「搜索单号库位」，右侧搜索图标；下方一排可横向滑动的仓库页签，选中项高亮；再下方为库位列表，一行一个，有备注时库位与备注左右各占一半。

**货架层数：**底部弹层，一行一个层数。

##### 交互

- 点「库位编码」：读取当前登录人部门下的仓库，只保留仓库类型的仓库，默认选中第一个并列出它的库位。没有仓库类型的仓库时提示「当前没有可用的仓库」；读取结果为空时提示「当前返回为空」。打开弹层时页面上的料品卡片被清空，再次扫码后重新显示。
- 点仓库页签切换仓库；输入库位号后点搜索图标，按库位号过滤。
- 点库位：写回库位编码、仓库名称，隐藏货架层数，关闭弹层。
- 点「货架层数」打开层数弹层，点某层写回并关闭。
- 切换仓库、点库位时，所选仓库与已扫码的仓库不一致，提示「请选择当前仓库下的仓位」。

##### 逻辑

无

#### 扫码

##### 页面元素

无（使用侧边扫码键）。

##### 交互

- 扫到的码分类处理：
  - 货架码（8 位数字）：查询货架。成功后库位编码显示扫到的货架码，带出仓库名称，出现「货架层数」（层数为空），播放成功提示音；失败播放失败提示音，并由全局请求处理提示系统返回的原因
  - 载具码（第 2 位为 E、F、M、P）：未选库位提示「请选择库位」；出现货架层数但没选提示「请选择货架层数」；否则查询该码。成功播放成功提示音并加入本机暂存；失败播放失败提示音，并由全局请求处理提示系统返回的原因
  - 其它码：提示「请扫描正确的二维码」
- 本次已扫过同一个码，提示「扫描二维码重复」，不加入。
- 加入后卡片按料品编号合并，料品总量、二维码数量累加。

##### 逻辑

- 扫码只查询、校验并返回码信息，不改码的位置，也不锁定。
- 查询时校验，不通过不加入（文案中 `{码}` `{仓库名}` `{仓库编码}` 为实际值）：
  - 码所在仓库与所选仓库不同（「二维码的仓库不是同一个仓库,无法移动」）
  - 所选仓库被锁定（「存在仓库:{仓库名}({仓库编码})被锁定」）
  - 码或托下有码已被锁定（「存在二维码:{码}已经锁定」）
  - 码不在库中（「二维码{码}不在库」）
  - 扫的是托下的单个码（「二维码{码}不可扫描托中的单品码,只能整托」）
- 扫托码时，返回托码及托下所有码。

#### 扫码删除弹框

点页面「扫码删除」打开。

##### 页面元素

底部弹层，高约 65% 画布，顶部灰底圆角标题「当前扫码信息」。字段一行一个，无值显示 `-`。底部整宽红色按钮「完成删除」。

| 字段 | 说明 |
| ---- | ---- |
| 产品轴号 | 本次扫到的码 |
| 料品名称 | 过长省略 |
| 料品编号 | |
| 料品单位 | 无值显示 `N/A` |
| 料品数量 | |
| 仓位编码 | 该码的原库位 |
| 仓库名称 | |

##### 交互

- 每次打开都清空上次内容。弹层打开期间，扫到的码只用于删除。
- 扫码时在本机暂存里查找：还没有暂存数据，提示「暂无入库数据」；找到则带出上表字段；找不到提示「未找到该二维码对应的记录」。
- 点「完成删除」：还没扫，提示「请先扫描要删除的二维码」；否则从暂存中删掉该码，关闭弹层，卡片重新汇总，提示「删除成功」。
- 点遮罩关闭弹层，不删除。

##### 逻辑

- 只删本机暂存的数据，不请求后端。扫的是托码时，连同托下的码一起删掉。

#### 确定

##### 页面元素

无确认框，点「确定」直接提交。

##### 交互

- 未选库位，提示「请扫描仓位编码」。
- 没有已扫的码，提示「请扫描二维码」。
- 暂存数据异常，提示「数据异常，请重新扫码」。
- 成功：清除暂存数据，回到主页，提示「操作成功」。
- 失败：由全局请求处理提示系统返回的原因，停留在本页。

##### 逻辑

- 提交的库位：选库位为库位编码；有货架层数时为「货架码 + 两位层数」。同一个码只提交一次。
- 可执行条件，不满足时失败：
  - 库位为空（「请传入库位」）、仓库为空（「请传入仓库」）
  - 库位在所选仓库下不存在（「库位不存在」）
  - 码重复（「二维码存在重复」）
  - 码所在仓库不同、仓库被锁定、码被锁定、码不在库、托下单码：同「扫码」的校验
  - 码的原库位等于新库位（「存在二维码:{码}原库位等于新的库位」）
- 执行后：
  - 生成一条移库记录：仓库、移入库位、库位类型取所选库位；料品名称为本次各料品名称去重后用逗号拼接；移库人员、移库时间为本次提交人和时间
  - 按码保存原库位、现库位、数量（同一码同一料品合并）
  - 这些码移到新库位
  - 库存统计按本次的码重新统计
