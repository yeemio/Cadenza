# 成品入库模块 PRD 文档

---

## 1. 基本说明

### 1.1. 业务理解

成品入库把已具备入库条件的成品轴/托扫入指定仓库库位，生成成品入库单（含料品汇总与码明细），记下入库人员、入库时间，并更新码的在库位置。

单据由 **PDA「成品入库」** 扫码组单并确认入库后落库。**Web 只做查询与下钻查看**，不做扫码、不提交入库、不增删改单据。

```text
PDA 成品入库
  选/扫库位（可先扫货架再选层）→ 扫产品轴号或托码 → 确认装入明细
        ↓
  确定入库 → 生成成品入库单（已完成）
        ↓
  记下入库人员、入库时间；码入目标库位
        └─ Web 列表可查到该单，并可查看料品与库位码
```

**两端分工：**

- **Web**：列表查询；查看基础信息、料品料表、库位/码明细。无新增、编辑、删除、确认入库、扫码。
- **PDA**：从主页进入。列表查已完成入库单；「新增入库」选库位并扫码确认入库；有进行中任务时可续做。

### 1.2. 字典说明

#### 码类型

| 类型值 / 状态值 | 说明 | 颜色 |
| --------------- | ---- | ---- |
| 轴 | 单轴成品码，卡片展示产品轴号及相关轴字段。 | |
| 托 | 托盘码，卡片展示托码及托下二维码数量。 | |

## 3. PDA 端

> 字典见 1.2。列表默认下拉刷新、上拉加载；没有更多时提示「数据加载完毕！」。
>
> 需要扫码的页面或弹层都有按钮「扫码」，点它完成本次扫码。设计图没有侧边硬件键，也不播放扫码提示音。同一页有多处扫码时，每一处各有一个「扫码」。

##### 交互

- 须先有库位：可手选，或扫货架后再选层数；货架模式未选层数时提示「请选择货架层数」。
- 未选库位点确认，提示「请选择库位/侧边按钮扫码」。
- 扫产品轴号或托码：仅成品；成功打开本弹窗并带出明细；格式不符提示「请扫描正确的二维码」；未命中提示「未找到该二维码对应的料品信息」；本任务已扫过同一码提示「该轴码已存在，请勿重复扫描」。
- 扫货架码：带出仓库，并出现货架层数可选；跨仓失败时提示获取仓库失败类文案。
- 点库位编码打开「选择库位」：可按关键字搜库位，横向切换仓库；选中后写回库位/仓名，并关闭货架层数展示（非货架点选）。
- 点货架层数从列表选择层数。
- 确认后按料品合并数量与码数写入本机任务；库位保留，可继续扫；关闭弹窗并清空当前待确认明细。

##### 逻辑

- 可选库位范围：成品类、实体仓。
- 确认装入后仅更新本机进行中任务，不生成 Web 单据。

#### 当前扫码信息（删除）

##### 页面元素

弹窗标题「当前扫码信息」。打开后用「扫码」匹配本机已扫码。底部按钮「完成删除」。

展示字段与扫码入库明细类似：库位编码、仓库名称；托码或产品轴号；轴时含生产单号、销售单号、合同号、轴具尺寸/类型、客户轴号（段长）/段长；生产部门、料品名称/编码/规格/颜色、调入数量；托时二维码数量。

##### 交互

- 未扫到待删目标点「完成删除」，提示「请扫描产品轴号」。
- 扫到本机任务中的码后点「完成删除」：从本机任务移除该码并按料品重算汇总，提示「删除成功」。
- 找不到码提示「未找到该二维码对应的料品信息」或「暂无数据」。

##### 逻辑

- 仅删除本机未提交明细，不影响已落库历史单。

#### 确定入库

##### 页面元素

确认框标题「成品入库」，内容「确认成品入库」。

##### 交互

- 取消关闭；确定提交。提交中按钮不可再点。

##### 逻辑

- 可执行条件：本机已有至少一条已确认装入的明细。
- 执行后生成成品入库单（已完成），记下入库人员、入库时间；清空本机进行中任务；提示「操作成功」并回列表。
- Web 成品入库列表随后可查到该单。
