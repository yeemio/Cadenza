# 排产计划模块 PRD 文档

---

## 1. 基本说明

### 1.1. 业务理解

排产计划供现场按工作中心查看已排好的生产计划，只读，不能在本模块改排产。进入后先选工作中心，再按排产日期分组查看各单的设备、料品、排产数量、累计生产与备注；可按生产单号、设备、排产日期筛选，查询条件按账号 + 工作中心记忆。

Web 侧「订单排程」「设备排程」是另一套可编辑排产功能，不在本文范围。

```text
主页「排产计划」
        ↓
工作中心列表 → 点某一工作中心
        ↓
按排产日期分组的计划列表（当天默认展开）
        ├─ 查询（生产单号 / 设备 / 排产日期）
        └─ 有备注时可查看备注详情
```

**两端分工：**

- **Web**：本模块无独立页面（订单排程、设备排程见各自文档）。
- **PDA**：选工作中心、查看排产计划、查询筛选、查看备注。

无。

## 3. PDA 端

> 本模块无扫码。系统返回键（侧滑、物理返回）不生效，只能点导航栏左侧返回。接口返回失败时，由全局请求处理提示系统返回的原因（无原因时提示「操作失败」）。

### 3.1. 排产计划（工作中心）页面

**入口：**主页「生产管理」分类下的「排产计划」。

#### 列表页面

##### 页面元素

**导航栏标题：**排产计划；左侧「BACK」。

**卡片展示字段：**工作中心名称（整卡可点）。

**卡片上的按钮：**无

**空状态：**暂无工作中心

##### 交互

- 点工作中心卡片进入该工作中心的排产计划详情（见 3.2）。
- 点「BACK」回到主页。
- 本页不分页，没有下拉刷新。

##### 逻辑

- 数据范围：当前登录人可进入的工作中心。
- 用户未关联部门等信息导致加载失败时，提示系统返回的原因（如「用户信息查询失败」「用户未关联部门信息」），列表为空。

### 3.2. 排产计划详情页面

从 3.1 工作中心卡片进入。

#### 列表页面

##### 页面元素

**导航栏标题：**排产计划；左侧「BACK」。

**列表上方：**蓝色「查询」按钮；其下展示「工作中心：名称」（无值显示 `-`）。

**分组：**按排产日期（`yyyy.MM.dd`）升序。组头为日期，右侧折叠箭头；展开后显示该日卡片。

**卡片展示字段：**

| 字段 | 说明 |
| ---- | ---- |
| 生产单号 | 无值显示 `-` |
| 设备名称 | 无值显示 `-` |
| 销售单号 | 无值显示 `-` |
| 物料描述 | 料品名称、规格、颜色用 ` / ` 拼接；都空时显示 `-`；过长省略 |
| 项目号 | 无值显示 `-` |
| 排产数量 | 数量后跟单位 |
| 累计生产 | 数量后跟单位 |
| 备注 | 无值显示 `-`；有备注时同行右侧显示「查看详情」 |

**空状态：**暂无排产数据

**卡片上的按钮：**无

##### 交互

- 当天日期的分组默认展开，其它日期默认折叠；点组头切换展开/折叠。
- 点「查看详情」打开备注详情弹框（见下）。
- 下拉刷新重新加载当前工作中心的排产数据；没有上拉分页（一次展示全部）。
- 点「BACK」回到工作中心列表（见 3.1）。

##### 逻辑

- 数据范围：所选工作中心的排产计划。未选排产日期时，默认含当天及往前 7 天起的计划；选了排产日期则只查该日。
- 排产数量优先取汇总排产数量，否则取排产数量；累计生产优先取汇总完成数量，否则取完成数量。

#### 查询

##### 页面元素

居中弹层。字段左标签右输入。

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| 生产单号 | 文本 | 提示「请输入生产单号」 |
| 设备名称 | 选择 | 未选时提示「请选择设备」；选项为当前工作中心下状态正常的设备名称 |
| 排产日期 | 日期 | 未选时提示「请选择计划开始时间」；展示格式 `yyyy.MM.dd` |

弹层按钮：左红色「重置」，右蓝色「查询」。弹层外有关闭「✕」。

##### 交互

- 点「查询」打开弹层，带出上次已生效的条件。
- 点设备名称：有设备选项时从底部选择；没有设备时不打开选择器。
- 点排产日期：从底部选日期，确认后写入。
- 点「查询」：按条件重新加载列表，关闭弹层，并记住该账号在该工作中心下的条件。
- 点「重置」：清空全部条件，立即按空条件重新加载，关闭弹层，并更新记忆。
- 点「✕」或遮罩关闭弹层，不改已生效条件。
- 再次进入同一工作中心时，带出记忆的查询条件。

##### 逻辑

- 生产单号模糊匹配；设备名称精确匹配；排产日期精确匹配。
- 记忆的设备名若已不在当前工作中心正常设备列表中，则清空该设备条件后再查询。

#### 备注详情

##### 页面元素

居中弹框，标题「备注详情」，右上角关闭。正文为完整备注。无其它按钮。

##### 交互

- 点关闭关闭弹框。
- 点遮罩不关闭。

##### 逻辑

无
