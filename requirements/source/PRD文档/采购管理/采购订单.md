# 采购订单模块 PRD 文档

---

## 1. 基本说明

### 1.1. 业务理解

采购订单维护 ERP 推送至 MES 的 **采购订单行**（采购单号 + 行项目号）：物料、供应商、计划采购数量、采购上限、计划收货日期、已收货数量及订单状态等。Web 本页只做行维度查询与状态汇总，不提供手工新增/编辑/删除；点「批次详情」或采购单号进入 **采购批次**（另文）查看该行下的收货批次。PDA「采购入库」列表按订单状态 Tab 展示待收货的订单行，点卡片进入扫码收货页（见《采购批次》§3）；收货完成后回写已收数量与订单状态。**ERP 已同步为「已完成」的行**订单状态不因收货、退货、MES 重算而变更。

**两端分工：**

- **Web**：订单行列表；按订单状态汇总条数（不含已完成）；跳转采购批次（带采购单号、行项目号）。
- **PDA**：采购入库列表（本篇 §3）；查询、按订单状态 Tab 查看，点卡片进入扫码收货页（《采购批次》§3）。

### 1.2. 字典说明

#### 订单状态

| 类型值 / 状态值 | 说明 | 颜色 |
| --------------- | ---- | ---- |
| 0 | 已开立 | 黑 |
| 1 | 待收货 | 红 |
| 2 | 部分收货 | 黄 |
| 3 | 完全收货 | 蓝 |
| 4 | 超额收货 | 紫 |
| 5 | 已完成 | 绿 |

PDA 采购入库 Tab 只用 1～4，不含「已开立」「已完成」。

##### 交互

- 订单状态着色见字典「订单状态」。
- 列表左上汇总：当前搜索条件下各订单状态条数，形如「已开立：n，待收货：n，…」；**不含「已完成」**。
- 排序：已完成置底；其余按计划收货日期升序（无计划收货日期的排在最后）；日期相同按主键升序。
- 点击采购单号或「批次详情」：跳转采购批次页，并带入采购单号、行项目号作为默认筛选。

##### 逻辑

- 数据范围：由 ERP 同步的采购订单行；本页不允许手工新增、编辑、删除。
- 未完结行的订单状态由 MES 按计划采购数量、已收货数量、采购上限重算（已开立 / 待收货 / 部分收货 / 完全收货 / 超额收货）；已完成行恒为已完成，不因收货、退货、重算变更。
- 已收货数量为该行关联有效入库批次数量汇总（退货批次从汇总中剔除）。

## 3. PDA 端

> 字典见 1.2。列表默认下拉刷新、上拉加载；没有更多时提示「数据加载完毕！」。
>
> 设计图没有侧边硬件键，需要扫码的页面或弹层都放一个「扫码」按钮，点它等同于按一次侧边键。本页无扫码。

### 3.1. 采购入库页面

**入口：**主页「采购入库」。

#### 列表页面

##### 页面元素

**导航栏标题：**采购入库；左侧「BACK」。

**列表上方：**

- 整宽「查询」栏，点开查询弹框。
- 订单状态 Tab：待收货、部分收货、完全收货、超额收货，每项格式「状态名 (条数)」；不含「已开立」「已完成」。

**卡片展示字段：**

| 字段 | 说明 |
| ---- | ---- |
| 采购单号 | 格式「采购单号-行项目号」 |
| 合同号 | |
| 物料名称 | |
| 物料编码 | |
| 规格型号 | 规格/型号拼接，如「规格/型号」；只有一项时只显示该项 |
| 颜色 | |
| 供应商 | |
| 请购行规格 | |
| 收货数量 | 格式「已收货数量/计划采购数量」 |

**卡片上的按钮：**无

**页面按钮：**无

##### 交互

- 点卡片：进入采购入库扫码页（见《采购批次》§3）。
- 合同号、颜色、请购行规格无值显示 `—`；规格型号两项均无值显示 `—`；收货数量任一侧无值显示 `—`。
- 默认进入第一个 Tab；点 Tab 切换，列表回到第一页。
- Tab 条数随查询条件变化，但不受「计划收货日期」影响。
- 排序：按计划收货日期升序，无计划收货日期的排在最后；日期相同按主键升序。
- 每次从扫码页返回本页，刷新 Tab 条数与列表。
- 查询条件与所在 Tab 需记忆：进入扫码页再返回，保留上次查询条件与 Tab。
- 无数据时显示「暂无数据」。

##### 逻辑

- 数据范围：采购订单行中订单状态为待收货、部分收货、完全收货、超额收货的行；ERP 已完成、已开立的行不展示；仅展示当前登录账号所属机构（公司组织）下的订单行，取不到机构时不限制。
- 收货数量分母取计划采购数量，不是采购上限。

#### 查询

##### 页面元素

居中弹框，底部下方有圆形关闭「×」。

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| 采购单号 | 文本 | 模糊；提示「请输入采购单号」 |
| 合同号 | 文本 | 模糊；提示「请输入合同号」 |
| 物料名称 | 文本 | 模糊；提示「请输入物料名称」 |
| 物料编码 | 文本 | 模糊；提示「请输入物料编码」 |
| 供应商 | 文本 | 按供应商名称模糊；提示「请输入供应商」 |
| 计划收货日期 | 日期 | 精确到天；提示「请选择计划收货日期」 |

弹框按钮：重置、查询。

##### 交互

- 点「查询」栏打开弹框，回显当前已生效的条件。
- 点「重置」只清空弹框内输入，不关闭、不刷新列表；再点「查询」后才按空条件生效。
- 点「查询」：关闭弹框，条件生效，Tab 回到第一个，刷新 Tab 条数与列表。
- 点遮罩或「×」关闭弹框，不改变已生效条件。

##### 逻辑

无
