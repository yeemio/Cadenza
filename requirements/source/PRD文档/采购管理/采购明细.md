# 采购明细模块 PRD 文档

---

## 1. 基本说明

### 1.1. 业务理解

采购明细按 **物料二维码** 展示采购收货结果：PDA 采购入库扫码页确认收货后（见《采购批次》§3），每个二维码一条明细，挂在对应采购订单行与入库批次下。Web 端不手工新增、不提供单码删除（删收货数据在采购批次整批删除）；本页做查询、勾选合计，以及对已质检明细的「撤销质检」。质检结论来自质检记录聚合，非明细表落库字段。

**两端分工：**

- **Web**：二维码明细列表查询；勾选合计；撤销质检；支持从采购批次带入批次/单号条件进入。
- **PDA**：无（收货在 PDA 采购入库扫码页完成，见《采购批次》§3）。

### 1.2. 字典说明

#### 单码质检状态

| 类型值 / 状态值 | 说明 | 颜色 |
| --------------- | ---- | ---- |
| 1 | 免检 | 蓝 |
| 2 | 待质检 | 黑 |
| 3 | 合格 | 绿 |
| 4 | 不合格 | 红 |

#### 入库状态

| 类型值 / 状态值 | 说明 | 颜色 |
| --------------- | ---- | ---- |
| 1 | 已入库 | 绿 |
| 2 | 已退货 | 橙 |

##### 交互

- 点击数据行可勾选或取消勾选。
- 选中合计：按单位分组累加入库数量，保留 4 位小数；无单位按「未知单位」。
- 质检状态、入库状态着色见对应字典。
- 排序：按明细创建时间（收货确认生成时间）倒序；创建时间相同按主键升序。
- 从采购批次点「明细」或批号进入时，带入批次 id、批号、采购单号、行项目号作为默认筛选；其中批次 id 为隐藏条件。用户点「清空」或主动搜索后，去掉隐藏批次 id，并清掉地址栏跳转参数。
- 操作栏按钮显隐：
  - 撤销质检：单码质检状态为合格或不合格，且所属批次入库状态非已退货时显示

##### 逻辑

- 数据范围：PDA 确认收货后按二维码自动生成；已退货批次下的明细仍展示，可用入库状态筛选。本页不允许手工新增，不提供单码删除。
- 列表质检状态 / 质检时间 / 质检人员：取该码当前有效质检记录（复检优先）。

#### 撤销质检

##### 页面元素

无（确认框：标题「提示」，正文「确认撤销该条质检？」）。

##### 交互

无

##### 逻辑

- 可执行条件：单码质检状态为合格或不合格，且所属批次未退货。
- 执行后本模块：该码有效质检结论回退为待质检，清空质检时间、质检人员；所属批次质检状态按本批各码有效结论重新汇总。
- 不影响采购订单行数量；已撤销后可再次质检。
