# 料品管理模块 PRD 文档

---

## 1. 基本说明

### 1.1. 业务理解

料品管理维护生产、仓储、质检、出入库等业务引用的 **料品主数据**（料品名称/编号、公司组织编码、物料组、物料描述、电压/标准/客户、料品类型、规格颜色、主计量单位、多单位换算、是否质检、备注等）。主数据主要由 **U9/ERP** 同步写入；Web 本页 **不提供新增、删除**，仅支持列表查询、查看、编辑换算公式。

编辑时主表业务字段与是否质检均不可改，仅可维护多单位换算行；已被采购收货引用的换算行不可改、不可删。启用多单位固定为开启，页面无开关。本页不维护库存预警。

**两端分工：**

- **Web**：列表查询、查看、编辑（仅换算公式）。
- **PDA**：无。

#### 编辑

##### 页面元素

与查看同一表单分区。

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| （基础信息各字段） | — | 全部置灰不可改 |
| 是否需要质检 | 单选 | 置灰不可改 |
| 料品类型 | 单选 | 置灰不可改 |
| 主计量单位 | 下拉 | 置灰不可改 |
| 换算公式 | 多行可编 | 可添加行、删除行；换算单位名最长 100；数量最长 12 |
| 备注 | 多行文本 | 置灰不可改 |

##### 交互

- 启用多单位写死为开启，页面无开关；换算公式区始终展示。
- 换算公式允许为空；有换算行时须填换算单位名与数量。
- 数量格式：整数位最多 9 位、小数位最多 4 位，须为非负数字。
- 已被采购收货引用的换算行（`referenced=true`）：换算单位名、数量不可改，且不显示该行删除。
- 打开编辑须拉详情后再展示表单，不以列表行直接当表单数据。

##### 逻辑

- 保存时仅同步多单位换算子表（有 id 更新、无 id 新增、未提交的已有行逻辑删除）；主表业务字段与是否质检不因本页编辑而变更。
- 已被采购收货引用的换算行：禁止修改、禁止删除。
- 同组织下料品编号不能重复（本页不可改编号，仅作主数据约束说明）。
