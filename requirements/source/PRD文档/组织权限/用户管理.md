# 用户管理模块 PRD 文档

---

## 1. 基本说明

### 1.1. 业务理解

用户管理维护组织权限下的 **系统用户账号**（用户名、登录账号、所属部门/岗位/角色、登录平台、账号状态、绑定工序等），供登录鉴权、菜单权限、车间/工序业务分工等引用。数据以本页人工维护为主；支持批量启用/禁用、角色配置、密码重置、账号解封及导入导出。

账号状态区分启用与禁用；禁用后不可登录。所属部门含「需关联车间」类型（`deptCategory === 2`）时，表单条件显示车间部门（前端未强制必填）。登录账号全局唯一。账号解封解除的是登录失败锁定（按用户手机号清锁定缓存），与账号启用/禁用无关。

**两端分工：**

- **Web**：列表查询、新增、编辑、查看、删除/批量删除、启用/禁用（含行内切换）、角色配置、密码重置、账号解封、导入、导出。
- **PDA**：无。

#### 新增/编辑

##### 页面元素

表单分两组。

**基础信息**

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| 用户名 | 文本 | 必填；最长 10 |
| 用户全名 | 文本 | 非必填；最长 255 |
| 用户编号 | 文本 | 非必填；最长 20 |
| 所属部门 | 树选（多选） | 必填；父子不强制联动 |
| 车间部门 | 树选（单选） | 条件显示；非必填；选项为车间部门树 |
| 绑定工序 | 树选（多选） | 非必填；选项随所属部门变化 |
| 所属岗位 | 树选（多选） | 非必填 |
| 所属角色 | 树选（多选） | 必填；父子不强制联动 |
| 手机号码 | 文本 | 非必填；最长 20 |
| 邮箱 | 文本 | 非必填；最长 50 |
| 身份证号 | 文本 | 非必填；最长 18 |

**详细信息**

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| 登录账号 | 文本 | 必填；最长 20；仅字母与数字 |
| 登录平台 | 树选（多选） | 必填；选项见字典「登录平台」 |
| 密码 | 密码 | 仅新增；必填；最长 16 |
| 确认密码 | 密码 | 仅新增；必填；须与密码一致 |
| 账号状态 | 单选 | 必填；选项见字典「账号状态」；新增默认启用 |

##### 交互

- 所属部门与车间部门、绑定工序联动：
  - 所选部门中存在 `deptCategory === 2` 时显示车间部门；否则隐藏并清空车间部门。
  - 绑定工序选项随所属部门刷新；变更部门时按新部门重载可选工序并清空已选工序。
- 密码规则：`8-16位，数字+字母的组合，字母需要区分大小写。`（须同时含数字与字母，仅允许字母与数字）。
- 确认密码须与密码一致，否则提示。
- 编辑时不展示密码、确认密码。
- 查看与新增/编辑同一表单区域，全部只读。

##### 逻辑

- 登录账号不能重复。
- 保存时所属部门、所属角色、登录平台、账号状态必填。
- 不可删除当前登录账号自身（提示「不能删除本账号!」）。

#### 删除/批量删除

##### 页面元素

无（确认框）。

##### 交互

- 批量删除需先勾选行；未勾选时提示「请选择至少一条数据」。
- 确认文案：「确定将选择数据删除?」。

##### 逻辑

- 可执行条件：不可删除当前登录账号自身（「不能删除本账号!」）。
- 执行后本模块逻辑删除对应用户。

#### 启用/禁用

##### 页面元素

无（确认框；列表行内开关无额外字段）。

##### 交互

- 批量启用/禁用需先勾选行；未勾选时提示「请选择至少一条数据」。
- 批量确认文案：「确认启用」「确认禁用」。
- 列表账号状态开关切换后立即生效（与批量启用/禁用同一套状态）。

##### 逻辑

- 执行后账号状态变为启用或禁用（见字典「账号状态」：`0` 启用 / `1` 禁用）。

#### 角色配置

##### 页面元素

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| 角色 | 树勾选 | 父子不强制联动；默认展开 |

弹窗标题：用户角色配置。

##### 交互

- 需先勾选行；未勾选时提示「请选择至少一条数据」。
- 仅勾选 1 人时，弹窗回显该用户当前角色；勾选多人时不预勾选，提交后覆盖所选用户的角色。

##### 逻辑

- 执行后所选用户所属角色更新为勾选结果。

#### 密码重置

##### 页面元素

无（确认框）。

##### 交互

- 需先勾选行；未勾选时提示「请选择至少一条数据」。
- 确认文案：「确认重置」。

##### 逻辑

- 执行后将所选用户密码重置为系统参数 `account.initPassword`；未配置时为 `123456`。

#### 账号解封

##### 页面元素

无（确认框）。

##### 交互

- 确认文案：「确认解封？」；前端不校验是否已勾选行（与现网一致）。
- 确定后对当前勾选用户执行解封。

##### 逻辑

- 按用户手机号清除登录失败锁定缓存；不改变账号启用/禁用状态。

#### 导入

##### 页面元素

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| 模版上传 | 文件上传 | 必填；拖拽/点击；accept `.xlsx,.xlx`；提示文案「请上传 .xls,.xlsx 标准格式文件」；单文件；≤50MB |
| 下载模版 | 按钮 | 文案「点击下载」；下载导入模板 |

弹窗标题：用户数据导入。无「数据覆盖」开关（现网已关闭，默认不覆盖）。

##### 交互

- 支持拖拽或点击上传；上传成功后关闭弹窗并刷新列表。

##### 逻辑

- 模板列（顺序）：用户名(必填)、用户编号(非必填)、所属部门(必填)、所属岗位(非必填)、所属角色(必填)、登录账户(必填)、登录平台(必填)、手机号码(非必填)、邮箱(非必填)、身份证(非必填)、语言(非必填)、用户全名(非必填)。
- 部门/角色/登录平台须与系统已有数据匹配（名称；部门/角色/平台可逗号多值）。
- 登录账号已存在时不允许导入为新用户（默认不覆盖）。
- 新导入用户密码取系统参数 `account.initPassword`（导入路径无 `123456` 兜底；密码重置有兜底）；导入不写绑定工序。

#### 导出

##### 页面元素

无（确认框）。

##### 交互

- 确认文案：「确定导出选择的数据」。
- 确认后按当前搜索条件中的用户名、登录账号导出（不含所属部门、账号状态）。

##### 逻辑

无
