# 角色管理模块 PRD 文档

---

## 1. 基本说明

### 1.1. 业务理解

角色管理维护组织权限下的 **角色档案**（角色名称、角色别名、角色排序）及角色的 **菜单权限 / PDA端菜单权限**，供用户绑定角色后控制 Web 菜单与 PDA 菜单可见与可操作范围。数据以本页人工维护为主。列表为树表（按 `parentId` 展示上下级）。

本模块无启用/停用等业务状态流转；增删改与权限保存后即生效。内置角色（`isSystem === 2`）不可删除、不可改角色别名；已关联用户的角色不可删除；存在下级角色时须先删除下级。权限设置按勾选覆盖该角色的菜单授权；勾选菜单树时父子联动；保存时会递归收回下级角色中超出本次授权范围的菜单。

**两端分工：**

- **Web**：列表查询、新增、编辑、查看、删除/批量删除、权限设置（菜单权限、PDA端菜单权限）。
- **PDA**：无。

## 2. Web 端

### 2.1. 角色管理页面

#### 列表页面

##### 页面元素

**列表上的搜索条件**

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| 角色名称 | 文本 | 模糊 |
| 角色别名 | 文本 | 模糊 |

**列表上面的按钮：**新 增、删 除、权限设置。

**列表展示字段：**

| 列名 | 说明 |
| ---- | ---- |
| # | 序号 |
| 角色名称 | 树表展示上下级 |
| 角色别名 | |
| 角色排序 | |
| 操作 | |

**列表操作栏的按钮：**查 看、编 辑、删 除。

##### 交互

- 当前页记录按角色排序升序。
- 点击数据行可勾选或取消勾选。
- 树表展开/收起下级角色。

##### 逻辑

无

#### 新增/编辑

##### 页面元素

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| 角色名称 | 文本 | 必填；最长 20 |
| 角色别名 | 文本 | 必填；最长 20 |
| 角色排序 | 数字 | 必填 |

父角色字段前端已下线；新增默认 `parentId = 0`。

##### 交互

- 查看与新增/编辑同一表单区域，全部只读。

##### 逻辑

- 同一租户及上级下，角色名称、角色别名、角色排序与其它角色不能重复（三者任一相同即冲突；提示「同一租户及上级下存在相同的角色名称或别称或排序号!」）。
- 内置角色（`isSystem === 2`）不允许修改角色别名（提示「无权限修改角色别名」）。

#### 删除/批量删除

##### 页面元素

无（确认框）。

##### 交互

- 批量删除需先勾选行；未勾选时提示「请选择至少一条数据」。
- 确认文案：「确定将选择数据删除?」。

##### 逻辑

- 可执行条件：非内置角色；未关联用户；无下级角色。
  - 内置角色：`存在无权限删除的角色`
  - 已关联用户：`该角色已关联的用户!`
  - 有下级：`请先删除子节点!`
- 执行后本模块逻辑删除该角色。

#### 权限设置

##### 页面元素

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| 菜单权限 | 树勾选 | 必有；展示 Web 菜单树 |
| PDA端菜单权限 | 树勾选 | 必有；展示 PDA 菜单树 |

弹窗标题：角色权限配置。

##### 交互

- 须且仅勾选 1 条角色后点「权限设置」；未勾选或多选时提示「只能选择一条数据」。
- 打开后回显该角色已授权的菜单与 PDA 菜单勾选。
- 勾选某节点时：同步勾选其全部下级，并勾选其上级；取消勾选某节点时：同步取消其全部下级（上级不因取消而自动取消）。
- 确定后按当前勾选覆盖保存该角色的菜单权限与 PDA端菜单权限。

##### 逻辑

- 非管理员不可配置别名为 `admin` 的角色（提示「无权配置管理员角色!」）；管理员可配置。
- 执行后覆盖该角色的 Web 菜单授权与 PDA端菜单授权；若该角色下还有下级角色，下级角色中超出本次授权范围的菜单一并收回（递归）。
