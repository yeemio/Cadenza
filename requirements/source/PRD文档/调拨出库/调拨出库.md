# 调拨出库模块 PRD 文档

---

## 1. 基本说明

### 1.1. 业务理解

调拨出库用于把料品从一个仓库调到另一个仓库，并留下出库记录；出库完成后自动生成对应的调拨入库单。按调拨目的分两类：**生产调拨**把原材料、半成品调到车间线边仓；**仓库调拨**在仓库之间调动，任何料品都可以。

单据有三个来源：

- **Web 新增（有任务）**：在 Web 先建调拨单，写明调出仓库、调入仓库（可预先指定库位）和要调的料品、数量，再到 PDA 按单扫码出库。
- **PDA 新增出库（无任务）**：现场在 PDA 直接选调入仓库并扫码，系统按扫到的码自动生成调拨单和明细。仅仓库调拨。
- **其它模块自动生成**：成品入库、采购入库时需要转仓的，系统自动生成仓库调拨单，生成即为已出库。

```text
Web 新增生产调拨 / 仓库调拨（有任务，待出库）
        ↓（仓库调拨在 PDA「调拨出库」扫码；生产调拨不在本模块 PDA 执行）
PDA 扫码 → 出库中（码被锁定，明细累计调出数量）
        ↓
PDA 完成出库 → 已出库（出库人员、完成时间）
        ├─ 选了调入库位：料品码直接移到调入仓库库位，生成「已完成」的调拨入库单
        └─ 没选调入库位：料品码变为已出库（在途），生成「待入库」的调拨入库单，到调拨入库扫码上架

PDA 新增出库（无任务）：首次扫码自动建单（出库中，Web 暂不显示）→ 完成出库后同上，并在 Web 显示
```

**两端分工：**

- **Web**：查询调拨单；新增生产调拨、新增仓库调拨；编辑、删除待出库且未扫码的单据；查看单据详情和每个料品的出库码。Web 不扫码、不完成出库。
- **PDA**：只处理仓库调拨。按状态查看调拨单，对有任务的单据扫码、删码、选调入库位、完成出库；也可以「新增出库」走无任务调拨。

**仓库类型规则**（新增、完成出库时都会校验）：调入仓库不能与调出仓库相同；调出仓库是线边仓时，调入仓库只能是线边仓；生产调拨的调入仓库只能是线边仓。

### 1.2. 字典说明

#### 调出状态

| 类型值 / 状态值 | 说明 | 颜色 |
| --------------- | ---- | ---- |
| 待出库 | 已建单，还没有扫码；或扫过的码全部删掉。只有待出库可以编辑、删除。 | `#E6A23C` |
| 出库中 | 已扫码，还没有完成出库。 | `#409EFF` |
| 已出库 | 已完成出库，记下出库人员、完成时间。 | `#67C23A` |

Web 列表「调出状态」着色见本字典；PDA 列表按本字典分段。

#### 创建类型

| 类型值 / 状态值 | 说明 |
| --------------- | ---- |
| 有任务 | Web 新增，或其它模块自动生成。PDA 按单扫码，明细有计划调出数量。 |
| 无任务 | PDA「新增出库」扫码自动生成，明细只有实际调出数量。Web 不能编辑。 |

#### 调拨类型

| 类型值 / 状态值 | 说明 |
| --------------- | ---- |
| 生产调拨 | 调入仓库只能是线边仓；只能调原材料、半成品。新增时有「调拨来源」可关联订单。 |
| 仓库调拨 | 调入仓库不限；料品不限。PDA 只处理本类型。 |

#### 库位类型

| 类型值 / 状态值 | 说明 |
| --------------- | ---- |
| 仓库 | 调入库位直接选仓库下的库位。 |
| 货架 | 先选调入货架，再选该货架下的库位。 |

#### 料品类型

| 类型值 / 状态值 | 说明 |
| --------------- | ---- |
| 原材料 | |
| 半成品 | |
| 成品 | 生产调拨不能选、不能扫。 |

#### 仓库类型

| 类型值 / 状态值 | 说明 |
| --------------- | ---- |
| 仓库 | 可选调入库位。 |
| 线边仓 | 车间仓库，不选调入库位、库位类型、货架。 |

##### 交互

- 调入仓库的选项：生产调拨只列线边仓；仓库调拨列全部仓库。
- 调入仓库联动：
  - 选线边仓：隐藏库位类型、调入货架、调入库位，并清空调入库位、调入货架，库位类型复位为仓库
  - 选其它仓库：显示库位类型、调入库位；库位类型为货架时再显示调入货架
  - 选调入仓库之前，库位类型、调入库位不显示
- 调入货架的选项为所选调入仓库下的货架；调入库位的选项按调入仓库、调入货架、库位类型过滤。

- 明细删除：
  - 行内「删除」直接删掉该行，不确认
  - 上方「删除」：未勾选提示「请选择至少一条数据」；勾选后确认「确定将选择数据删除?」，确定后删掉勾选行
- 编辑：打开时带出原单的调出仓库、调入仓库、库位类型、调入货架、调入库位、订单编号和明细。
- 保存时调出仓库、调入仓库未选，表单提示「请选择调出仓库」「请选择调入仓库」，不提交。
- 保存成功提示「操作成功」，关闭弹窗。

##### 逻辑

- 可执行条件（编辑）：调出状态为待出库，且单据还没有扫过码；否则分别提示「存在状态为不是待入库的的无法编辑」「存在正在扫码的原料二维码,无法编辑」。
- 保存校验，不通过时提示括号内文案：
  - 调入仓库与调出仓库相同（「入库仓库不能等于出库仓库」）
  - 调出仓库是线边仓、调入仓库是仓库（「调出仓库是线边库时调入仓库不可以是仓库,只能是线边库」）
  - 调出仓库或调入仓库已锁定，如盘点中（「仓库已锁定」）
  - 没有明细（「请传入调拨明细」）
  - 某行没填调拨数量（「第N行明细请传入调拨数量」）
  - 所选订单不存在（「存在订单不存在」）
- 新增后：生成调出单号；调出状态为待出库，创建类型为有任务，调拨类型按入口为生产调拨或仓库调拨。
- 编辑后：按料品比对明细，新增的料品新建明细，已有的更新调拨数量，去掉的删除。
- 选了调入库位时，自动带出该库位所在的货架。

## 3. PDA 端

> 字典见 1.2。
>
> 设计图没有侧边硬件键，需要扫码的页面或弹层都放一个「扫码」按钮，点它等同于源码里按一次侧边键。源码里「侧边按钮扫码」这类文案，设计图统一写成「点扫码」，其余文案与源码一致。设计图不播放扫码提示音。
>
> 系统返回键（侧滑、物理返回）不生效，只能点导航栏左侧返回。列表默认下拉刷新、上拉加载；没有更多时提示「数据加载完毕！」。

| 扫码数量/调出数量（单位） | 有任务显示「已扫数量/计划数量」，已扫数量蓝色可点；无任务只显示已扫数量 |

**卡片上的按钮：**无

**页面按钮：**未出库时，底部贴边整宽蓝色「完成出库」，右下角红色圆形「扫码删除」（文字分两行），页面有「扫码」。已出库时这三个按钮都不显示。

##### 交互

- 页头、卡片无值显示 `-`；扫码数量、计划数量无值显示 `0`。
- 进入时调入库位带出单据上预先指定的库位。
- 点蓝色已扫数量，进入已扫码明细（见 3.3）。
- 点「返回」回到调拨出库列表。

##### 逻辑

- 数据范围：本单明细中有计划数量或已扫数量不为 0 的料品行。
- 已扫数量 = 该料品已扫码数量之和；计划数量 = Web 新增时填写的调拨数量。

#### 扫码

##### 页面元素

无（使用页面「扫码」）。

##### 交互

- 点「扫码」按扫到的码分类处理：
  - 货架码（8 位数字）：调入库位显示货架编码，出现「货架层数」（层数为空）；失败提示系统返回的原因或「查询货架层数失败」
  - 载具码（第 2 位为 E、F、M、P）：直接提交出库，成功后列表刷新，对应料品已扫数量增加；失败提示系统返回的原因（无原因时提示「出库扫码失败」），网络异常提示「扫码失败，请重试」
  - 其它码：提示「请扫描正确的二维码」
- 扫托码时，整托下的码一次装入。

##### 逻辑

- 不允许装入的情况，提示括号内文案：
  - 码或托下有码不在库中（「二维码或托码下有二维码未在库中」）
  - 码或托下有码质检未通过，且系统参数不允许质检未完成出库（「二维码或托码下有二维码质检未通过」）
  - 码或托下有码已被其它业务锁定（「二维码或托码下有二维码被锁定」）
  - 该码剩余数量为 0（「该二维码已出库」）
  - 有任务时，码的料品不在本单明细里（「二维码不属于该出库单料品」）
  - 码所在仓库不是本单的调出仓库（「二维码不属于该出库单的仓库」）
  - 码所在仓库被锁定或已禁用（「仓库被锁定」「仓库已禁用」）
  - 本单调出仓库、调入仓库已锁定（「出库仓库已锁定」「入库仓库已锁定」）
- 装入成功后：按该码剩余数量整码调出，记下码、原库位、数量；码被锁定（锁定动作 = 调拨出库）；该料品已扫数量重新累计；单据状态变为出库中。

#### 选择调入库位 / 货架层数

##### 页面元素

**库位选择：**底部弹层，高约 80% 画布。顶部圆角搜索框，提示「搜索库位」，右侧搜索图标。下方左右两栏：左栏仓库，选中项蓝底白字；右栏库位，有备注时库位与备注左右各占一半。

**货架层数：**底部弹层，一行一个层数。

##### 交互

- 未出库时点「调入库位」方框打开库位选择，默认选中第一个仓库；读取仓库失败提示「获取仓库列表失败，请重试」。
- 点左栏切换仓库；输入库位号后点搜索图标，右栏按库位号过滤。
- 点右栏库位：写回调入库位，隐藏并清空货架层数，关闭弹层。
- 点「货架层数」：还没有调入库位时提示「请先选择调入库位」；否则重新读取该货架的层数（已选层数清空）后打开层数弹层，点某层写回并关闭。
- 点遮罩关闭弹层，不改。

##### 逻辑

- 左栏只列本单的调入仓库（已启用）。
- 选库位、选层数只改页面上的值，完成出库时才写入单据。

#### 扫码删除弹框

点页面「扫码删除」打开。

##### 页面元素

底部弹层，高约 75% 画布，标题「当前扫码信息」。底部整宽蓝色按钮「确认」。弹层内有「扫码」按钮。

未扫码时正文为空。扫码后按码展示，一个料品一组字段，无值显示 `-`：

| 字段 | 说明 |
| ---- | ---- |
| 托码 / 料品二维码 | 扫的是托码显示「托码」，否则显示「料品二维码」；值为本次扫到的码 |
| 料品名称 | 过长省略 |
| 料品编码 | |
| 规格 | 无值显示 `N/A` |
| 颜色 | |
| 仓库名称 | |
| 库位编码 | |
| 数量（单位） | 原数量 |
| 调出数量（单位） | 非托码才显示 |
| 二维码数量 | 托码才显示，托下码数 |

##### 交互

- 每次打开都清空上次内容。弹层打开期间，扫到的码只用于删除。
- 点「扫码」查询该码在本单的出库记录：成功用上表替换正文；失败正文不变，由全局请求处理提示系统返回的原因。
- 点「确认」：成功关闭弹层，列表刷新，提示「删除成功」；失败弹层保持打开，由全局请求处理提示系统返回的原因。
- 点遮罩关闭弹层，不删除。

##### 逻辑

- 扫码校验：码不在本单（「二维码不存在」）；扫的是托下的单个码（「该码需要扫描托码整托删除」）。
- 确认后：删除该码（托码则连同托下所有码）在本单的出库记录，解除锁定，重新累计该料品已扫数量；本单已没有码时状态回到待出库。

#### 完成出库

##### 页面元素

确认框，标题「完成出库」，内容「确定完成出库吗？」，按钮：取消、确认。

##### 交互

- 出现「货架层数」但没选层数时，点确认提示「请选择货架层数」。
- 成功：关闭确认框，提示「出库完成」，约 1.5 秒后回到调拨出库列表。
- 失败：提示系统返回的原因（无原因时提示「出库失败」），确认框保持打开。网络异常提示「操作失败，请重试」并关闭确认框。

##### 逻辑

- 提交的调入库位：选了库位为库位编码；选了货架层数为「货架编码 + 两位层数」，如货架 0203 第 3 层为 `020303`；没选为空。
- 可执行条件，不满足时提示括号内文案：
  - 调入库位不存在，或不属于调入仓库（「库位不存在」「库位不属于该入库仓库」）
  - 货架不存在，或不属于调入仓库（「货架不存在」「货架不属于该入库仓库」）
  - 本单没有扫过码（「出库失败:未有物料出库」）
  - 调出仓库、调入仓库已锁定（「出库仓库已锁定」「入库仓库已锁定」）
- 执行后：
  - 调出状态变为已出库，记下出库人员、完成时间、调入库位；有货架时库位类型为货架，否则为仓库
  - 只取了部分数量的原码，回写剩余数量并解除锁定
  - 选了调入库位：扫到的码移到调入仓库、货架、库位，变为在库中并解除锁定，托码关系保留；生成调拨入库单，状态直接为已完成，入库人员、入库时间为本次操作人和时间
  - 没选调入库位：扫到的码变为已出库（在途）并解除锁定；生成调拨入库单，状态为待入库，到调拨入库模块扫码上架
  - 库存统计按本单的码重新统计，并记录调拨日志

##### 页面元素

##### 交互

- 点「扫码」按扫到的码分类处理：

  - 载具码：未选调入仓库时提示「请先选择调入仓库」；出现货架层数但没选时提示「请选择货架层数」；否则直接提交，成功提示「出库扫码成功」，列表刷新；失败提示系统返回的原因（无原因时提示「出库扫码失败」）

- 首次扫码自动建单：生成无任务调拨单号，调出状态为出库中，创建类型为无任务，调拨类型为仓库调拨，调出仓库为该码所在仓库；完成出库前 Web 不显示。每人同时只能有一条进行中的无任务调拨。

- 装入成功后：同 3.2 的锁定与累计；扫到新料品时自动新增明细行，明细只有已扫数量。
