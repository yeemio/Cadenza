# 成品异常模块 PRD 文档

---

## 1. 基本说明

### 1.1. 业务理解

成品异常用于登记线边仓（或尚未入库）产品轴上的不合格数量，并走审核。现场在 PDA「成品异常」扫产品轴号，选料品、填质检结果和不合格数量后提交，生成一条未审核的成品异常记录，并把该码的异常状态改为异常未处理。Web 按条件查询记录，对待审核记录做审核：通过则扣减码上数量并清除异常状态；不通过则只清除异常状态、不扣数量。

```text
PDA 扫产品轴号 → 选料品 → 填质检结果、不合格数量 → 提交
        ↓
生成成品异常记录（审核状态 = 未审核），码的异常状态 = 异常未处理
        ↓
Web「成品异常」点「审核」
├─ 通过 → 审核状态 = 通过；码数量按异常数量扣减；码异常状态 = 无异常
└─ 不通过 → 审核状态 = 不通过；码异常状态 = 无异常（不扣数量）
```

**两端分工：**

- **Web**：按产品轴号、生产部门、不合格类型查询成品异常记录；对待审核记录执行审核。
- **PDA**：扫产品轴号查看关联料品，选择料品后填写质检结果和不合格数量并提交。本模块不允许手工新增单据。

### 1.2. 字典说明

#### 不合格类型

Web 列表、搜索与 PDA「质检结果」共用。页面上不着色。

| 类型值 / 状态值 | 说明 |
| --------------- | ---- |
| 返工 | 质检结果为返工。 |
| 报废 | 质检结果为报废。 |

#### 审核状态

Web 列表「审核状态」使用，页面上不着色。

| 类型值 / 状态值 | 说明 |
| --------------- | ---- |
| 未审核 | PDA 提交后的初始状态。Web 操作栏显示「审核」。 |
| 通过 | 审核通过。 |
| 不通过 | 审核不通过。 |

#### 审核结果

仅 Web 审核弹窗单选项使用，字典与列表「审核状态」不同（不含未审核）。页面上不着色。

| 类型值 / 状态值 | 说明 |
| --------------- | ---- |
| 通过 | 打开弹窗时的默认选中项。 |
| 不通过 | |

#### 码异常状态

码上字段，页面不直接展示，提交与审核时会改。

| 类型值 / 状态值 | 说明 |
| --------------- | ---- |
| 无异常 | 未登记，或已审核结束。 |
| 异常未处理 | PDA 已提交、Web 尚未审核。 |

## 2. Web 端

### 2.1. 成品异常页面

#### 列表页面

##### 页面元素

**列表上的搜索条件**

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| 产品轴号 | 文本 | 模糊 |
| 生产部门 | 树形下拉 | 部门树 |
| 不合格类型 | 下拉 | 见字典「不合格类型」 |

**列表上面的按钮：**无

**列表展示字段：**

| 列名 | 说明 |
| ---- | ---- |
| 勾选列 | |
| # | 序号 |
| 产品轴号 | |
| 料品名称 | |
| 料品规格 | |
| 料品颜色 | |
| 生产部门 | |
| 不合格类型 | 见字典「不合格类型」 |
| 异常数量 | |
| 单位 | |
| 发起人员 | |
| 发起时间 | |
| 审核状态 | 见字典「审核状态」 |
| 操作 | |

**列表操作栏的按钮：**审核

##### 交互

- 按发起时间倒序，同时间再按主键。
- 进入页面时，生产部门默认为当前登录人所属的第一个部门。
- 点「清空」清除全部搜索条件（包括生产部门），按空条件重新查询。
- 行可勾选，但本页没有按勾选执行的操作。
- 操作栏按钮显隐：
  - 审核：有审核权限，且审核状态为未审核时显示
- 点「审核」打开审核弹窗。

##### 逻辑

- 数据范围：PDA 提交后生成的成品异常记录。本页不允许新增、编辑、删除。
- 生产部门：按所选部门精确匹配，不含下级部门。
- 生产部门取产品轴号所属生产订单的生产部门；发起人员、发起时间为 PDA 提交人和提交时间。

#### 审核

##### 页面元素

弹窗标题「审核」，可全屏。表单项：

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| 审核结果 | 单选 | 见字典「审核结果」；打开时默认「通过」 |

底部按钮：主按钮文案「审核通过」，取消文案「取 消」。

##### 交互

- 点操作栏「审核」打开弹窗，审核结果重置为「通过」。
- 点「审核通过」提交当前所选审核结果；成功关闭弹窗、刷新列表，提示「操作成功!」；失败时由全局请求处理提示系统返回的原因。
- 点「取 消」关闭弹窗，不提交。

##### 逻辑

- 可执行条件：记录存在，且审核状态为未审核；否则提示「异常数据不存在」或「只有未审核的才能进行审核」。
- 须传入审核结果，否则提示「请传入审核结果」。
- 按产品轴号 + 料品查找对应码；找不到提示「二维码不存在」。
- 审核结果为「通过」时：
  - 记录审核状态改为通过
  - 按异常数量从该产品轴号、该料品的码上扣减数量（足减多码时依次扣）
  - 这些码的异常状态改为无异常
- 审核结果为「不通过」时：
  - 记录审核状态改为不通过
  - 这些码的异常状态改为无异常，不扣减数量

## 3. PDA 端

> 字典见 1.2。
>
> 设计图没有侧边硬件键，需要扫码的页面或弹层都放一个「扫码」按钮，点它等同于源码里按一次侧边键。源码里「侧边按钮扫码」这类文案，设计图统一写成「点扫码」，其余文案与源码一致。设计图不播放扫码提示音。
>
> 系统返回键（侧滑、物理返回）不生效，只能点导航栏左侧返回。接口返回失败时，由全局请求处理提示系统返回的原因。

### 3.1. 成品异常页面

**入口：**主页「质量管理」分类下的「成品异常」。

#### 列表页面

##### 页面元素

**导航栏标题：**成品异常处理；左侧「BACK」。

**未扫码时：**页面中间红字「(请点扫码扫产品轴号)」。

**扫码后页头：**白底，每行左标签右内容。

| 字段 | 说明 |
| ---- | ---- |
| 产品轴号 | 标签与值都是蓝色；值为本次扫到的码 |
| 客户轴号（段长) | 仅当客户轴号、段长都有值时显示，格式「客户轴号 (段长)」 |
| 段长 | 仅当客户轴号为空且段长有值时显示 |

**卡片展示字段：**按料品一张卡片，可点选；选中浅蓝底。

| 字段 | 说明 |
| ---- | ---- |
| 生产单号 | |
| 料品描述 | 料品名称、规格、颜色直接拼接，无分隔符；单项无值时该段显示 `-` |
| 数量（单位） | |

**卡片上的按钮：**无

**页面按钮：**底部贴边整宽蓝色「异常处理」，始终显示；页面有「扫码」。

##### 交互

- 页头、卡片无值显示 `-`。
- 点卡片：选中该料品，并把弹窗内不合格数量预填为该行数量。
- 点「BACK」回到主页。
- 本页不分页，没有下拉刷新和上拉加载。
- 点「异常处理」打开异常处理弹框；未扫码时也可打开。

##### 逻辑

- 数据范围：本次扫到的产品轴号下的料品（按产品轴号 + 料品合并，数量相加）；一码多料品时多张卡片。
- 生产单号、生产部门取自该码所属生产订单。

#### 扫码

##### 页面元素

无（使用页面「扫码」）。

##### 交互

- 点「扫码」按扫到的码处理：
  - 载具码（第 2 位为 E、F、M、P）：查询该码；成功后用页头和卡片替换未扫码提示，质检结果默认返工，不合格数量预填为首个料品数量；再扫会覆盖上一次结果
  - 其它码：提示「请扫描正确产品轴号」
- 查询失败时由全局请求处理提示系统返回的原因。

##### 逻辑

- 查询时校验，不通过时提示括号内文案：
  - 扫的是托码（「不可扫描拖码」）
  - 码已不在仓库（无仓库）（「存在二维码已经不在仓库了」）
  - 仓库不存在（「仓库不存在」）
  - 码已入库且所在仓库不是线边仓（「只能入线边仓」）
- 未入库的码允许查询；已在库的码仅线边仓允许。
- 扫码只查询，不改数据。

#### 异常处理

##### 页面元素

居中弹框，标题「异常处理」。

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| 质检结果 | 分段选项 | 返工、报废；打开前扫码成功时默认返工 |
| 数量（单位） | 数字 | 必填，大于 0，最多四位小数；提示「请输入大于0的数字（最多4位小数）」；单位取扫码后带出的主单位 |

按钮：左「取消」，右「确定」。

##### 交互

- 点「取消」关闭弹框，不提交。
- 输入时去掉负号和非数字字符，小数最多四位；小于等于 0 的值会被清掉。
- 点「确定」：
  - 数量为空或小于等于 0：提示「不合格数量必须大于0」，弹框保持打开
  - 成功且本次扫到多于一个料品：关闭弹框，提示「操作成功」，留在本页，列表不清空
  - 成功且本次只有一个料品：关闭弹框，清空页头和列表回到未扫码提示，不提示「操作成功」
  - 失败：由全局请求处理提示系统返回的原因，弹框保持打开

##### 逻辑

- 提交时按「扫码」规则重新校验该产品轴号；并校验：
  - 产品轴号为空（「请传入二维码」）
  - 未选料品（「请传入料品id」）
  - 所选料品不在本次扫码结果中（「无法根据传入的料品id获取具体信息」）
  - 该码上该料品已有异常未处理（「存在待审核的成品异常数据，请先审核」）
  - 未传不合格类型（「请传入不合格类型」）
  - 未传不合格数量（「请传入不合格数量」）
  - 不合格数量大于该料品总数（「不合格数量不能超出总数量」）
  - 不合格数量不大于 0（「不合格数量必须大于0」）
- 执行后：
  - 生成一条成品异常记录：产品轴号、料品、不合格类型、异常数量、单位、生产部门等；审核状态为未审核；发起人员、发起时间为本次提交人和时间
  - 该产品轴号下该料品对应码的异常状态改为异常未处理
