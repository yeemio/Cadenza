# 货架管理模块 PRD 文档

---

## 1. 基本说明

### 1.1. 业务理解

货架管理维护仓储主数据中的 **货架档案**（货架编号、所属仓库、区域数量、货架层数、启用状态、备注）。新增货架时按「区域数量 × 货架层数」自动生成 **货架库位** 与 **货架区域**；可在货架行进入弹窗维护货架库位，或查看区域二维码并下载。货架、货架库位、区域二维码供入库、出库、调拨、移库、扫码等业务选用。数据以本页人工维护为主；普通库位不在本模块范围（见《仓库管理》）。

**两端分工：**

- **Web**：货架列表查询、新增、编辑、删除/批量删除、行内启用/禁用；弹窗内货架库位列表查询、新增、编辑、查看、删除/批量删除；弹窗内区域二维码列表查看、单条/批量下载。
- **PDA**：无。

### 1.2. 字典说明

#### 启用状态

| 类型值 / 状态值 | 说明 | 颜色 |
| --------------- | ---- | ---- |
| 1 | 启用 | 绿 |
| 2 | 禁用 | 红 |

##### 逻辑

#### 新增/编辑

##### 页面元素

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| 货架编号 | 文本 | 必填；须为 2 位数字；最长 2 |
| 所属仓库 | 下拉 | 必填；选项为仓库（含未启用） |
| 区域数量 | 数字 | 必填；最大 99；仅新增展示，不出现在列表与编辑 |
| 货架层数 | 数字 | 必填；最大 99；编辑时不可改 |
| 备注 | 多行文本 | 非必填；最长 255；约 6 行 |

##### 交互

- 编辑时不展示区域数量；货架层数置灰不可改。
- 本页无独立「查看」表单；「查看」进入货架详情弹窗。

##### 逻辑

- 同一工厂下货架编号不能重复（工厂取自所属仓库的所属部门）。
- 新增成功后启用状态默认为启用；并按区域数量、货架层数自动生成货架区域与货架库位：
  - 区域编码 = 货架编号（2 位）+ 区域序号（2 位，从 01 起）。
  - 库位编号 = 货架编号（2 位）+ 区域序号（2 位）+ 层号（2 位，从 01 起）；层号对应货架层数。
- 编辑时：若该货架下已有货架库位，不允许修改货架编号。
- 编辑时：若该货架已被二维码占用，不允许修改区域数量、货架层数或所属仓库（编辑页不展示区域数量、货架层数只读，实际可改项仅为所属仓库）。
- 编辑时修改所属仓库后，同步更新其下全部货架库位的所属仓库。

#### 删除/批量删除

##### 页面元素

无（确认框）。

##### 交互

- 批量删除需先勾选行；未勾选时提示先选择数据。

##### 逻辑

- 可执行条件：所选货架未被二维码占用；已被占用时禁止删除。
- 执行后本模块删除所选货架，并级联删除其下全部货架库位与货架区域。

#### 启用/禁用

##### 页面元素

无（列表「启用状态」列开关）。

##### 交互

- 列表行内直接切换启用/禁用；开关着色见字典「启用状态」。

##### 逻辑

- 执行后更新该货架启用状态；无额外业务拦截。

**列表上的搜索条件**

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| 库位编号 | 文本 | 模糊 |

**列表上面的按钮：**新增、删除。

**列表展示字段：**

| 列名 | 说明 |
| ---- | ---- |
| # | 序号 |
| 库位编号 | |
| 货架层数 | |
| 备注 | |
| 操作 | |

**列表操作栏的按钮：**查看、编辑、删除。

##### 交互

- 点击货架行操作栏「查看」打开本弹窗，不离开货架列表页。
- 点击数据行可勾选或取消勾选。

##### 逻辑

- 数据范围：仅当前货架下的货架库位；本弹窗不允许维护普通库位。

#### 货架库位新增/编辑

##### 页面元素

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| 库位编号 | 文本 | 必填；校验须为 6 位数字（货架号 2 位 + 区域号 2 位 + 层号 2 位）；输入框最长 8 |
| 货架层数 | 文本 | 只读；由库位编号后两位自动带出 |
| 备注 | 文本 | 非必填；无字数上限 |

##### 交互

- 库位编号变更后，货架层数取库位编号后两位去前导零后回写，只读展示。
- 查看与新增/编辑同一表单区域，全部只读。

##### 逻辑

- 库位编号须以当前货架编号为前缀，且为 6 位数字。
- 货架层数不能大于该货架的货架层数。
- 同一工厂下库位编号不能重复。
- 新增时写入所属仓库、所属货架，库位类型为货架库位；并按库位编号前 4 位维护货架区域（不存在则新增）。
- 编辑时：若旧库位编号已被二维码占用，不允许修改库位编号。
- 编辑时若区域编码变化：原区域下已无库位则删除原区域；新区域不存在则新增。

#### 货架库位删除/批量删除

##### 页面元素

无（确认框）。

##### 交互

- 批量删除需先勾选行；未勾选时提示先选择数据。

##### 逻辑

- 可执行条件：所选库位编号未被二维码占用；已被占用时禁止删除。
- 执行后本模块删除所选货架库位；若某区域下已无库位，则同步删除该区域。

#### 货架二维码

##### 页面元素

弹窗标题为「货架二维码」，可全屏。弹窗内为当前货架的区域二维码列表。

**列表上面的按钮：**下载。

**列表展示字段：**

| 列名 | 说明 |
| ---- | ---- |
| # | 序号 |
| 货架编码 | 区域编码（货架号 2 位 + 区域号 2 位） |
| 二维码 | 展示二维码图及完整码值（工厂编码 + 区域编码） |
| 操作 | |

**列表操作栏的按钮：**查看、下载。

##### 交互

- 点击货架行操作栏「查看二维码」打开本弹窗，不离开货架列表页。
- 点击数据行可勾选或取消勾选。
- 列表上方「下载」：按勾选行批量下载二维码（打包）；未勾选时提示先选择数据。
- 操作栏「查看」：打开查看表单，展示货架编码（区域编码）与二维码字段（回填为区域编码文本，非完整码图）。
- 操作栏「下载」：下载当前行二维码图片。

##### 逻辑

- 数据范围：仅当前货架下的货架区域；区域随货架新增及货架库位增删自动维护，本弹窗不提供区域新增/编辑/删除。
- 列表「二维码」列展示完整码图与完整码值；完整码值 = 所属仓库工厂编码 + 区域编码。
