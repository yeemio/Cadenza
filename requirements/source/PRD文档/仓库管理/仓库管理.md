# 仓库管理模块 PRD 文档

---

## 1. 基本说明

### 1.1. 业务理解

仓库管理维护仓储主数据中的 **仓库档案**（仓库名称、仓库编码、所属部门、仓库类型、料品类型、仓库主管、联系电话、仓库地址、启用状态），并按仓维护 **普通库位**（库位编码、备注）。仓库与库位供入库、出库、调拨、移库、盘点、扫码等业务选用。数据以本页人工维护为主。

库位从仓库行「库位管理」进入弹窗维护，仅管理普通库位（不含货架库位）。货架及货架库位不在本模块范围。

**两端分工：**

- **Web**：仓库列表查询、新增、编辑、查看、删除/批量删除、行内启用/禁用；弹窗内库位列表查询、新增、编辑、查看、删除/批量删除。
- **PDA**：无。

#### 新增/编辑

##### 页面元素

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| 仓库名称 | 文本 | 必填；最长 20 |
| 仓库编码 | 文本 | 必填；须为 4 位数字 |
| 所属部门 | 树选（Avue tree） | 必填；与机构管理树同源 |
| 仓库类型 | 下拉 | 必填；选项见字典「仓库类型」，受所属部门联动限制 |
| 料品类型 | 单选 | 必填；选项见字典「料品类型」，受仓库类型联动限制；未选仓库类型时不展示 |
| 仓库主管 | 树选（Avue tree） | 必填；选项为用户列表 |
| 联系电话 | 文本 | 非必填；最长 20 |
| 仓库地址 | 文本 | 非必填；最长 50 |

##### 交互

- 所属部门与仓库类型联动（与正式 Web 一致）：
  - 所属部门机构类型为物流部时，仓库类型下拉仅可选「仓库」。
  - 其余机构类型：仓库类型下拉为全量（仓库、线边仓）。
  - 变更所属部门时清空已选仓库类型、料品类型（编辑/查看回填时除外）。
- 仓库类型与料品类型联动：
  - 仓库类型=仓库：料品类型可选原料、成品；展示料品类型。
  - 仓库类型=线边仓：料品类型可选原料、半成品、成品；展示料品类型。
  - 未选仓库类型：不展示料品类型。
  - 变更仓库类型后，若当前料品类型不在可选范围内则清空。
- 查看与新增/编辑同一表单区域，全部只读。

##### 逻辑

- 仓库名称全局不能重复。
- 同一工厂下仓库编码不能重复（工厂取自所属部门）。
- 所属部门机构类型为物流部时，仓库类型必须为仓库。
- 所属部门机构类型为车间时，仓库类型必须为线边仓（保存校验；前端下拉不据此过滤；失败提示文案为「车间,只能选择线边库」）。
- 料品类型须符合当前仓库类型允许范围（仓库：原料/成品；线边仓：原料/半成品/成品）。
- 新增成功后启用状态默认为启用。
- 编辑时：若该仓已有普通库位，不允许修改仓库编码。
- 编辑时：若该仓已被二维码占用，不允许修改仓库类型或料品类型。

#### 删除/批量删除

##### 页面元素

无（确认框）。

##### 交互

- 批量删除需先勾选行；未勾选时提示先选择数据。

##### 逻辑

- 可执行条件：所选仓库未被二维码占用；已被占用时禁止删除。
- 执行后本模块删除所选仓库，并级联删除其下全部普通库位（不含货架库位）。

#### 启用/禁用

##### 页面元素

无（列表「启用状态」列开关）。

##### 交互

- 列表行内直接切换启用/禁用；开关着色见字典「启用状态」。

##### 逻辑

- 执行后更新该仓启用状态；无额外业务拦截。

#### 库位管理

##### 页面元素

弹窗标题为当前仓库名称，可全屏。弹窗内为库位列表。

**列表上的搜索条件**

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| 库位编码 | 文本 | 模糊 |

**列表上面的按钮：**新增、删除。

**列表展示字段：**

| 列名 | 说明 |
| ---- | ---- |
| # | 序号 |
| 库位编码 | |
| 备注 | |
| 操作 | |

**列表操作栏的按钮：**查看、编辑、删除。

##### 交互

- 点击仓库行操作栏「库位管理」打开本弹窗，不离开仓库列表页。
- 点击数据行可勾选或取消勾选。

##### 逻辑

- 数据范围：仅当前仓库下的普通库位；本弹窗不允许维护货架库位。

#### 库位新增/编辑

##### 页面元素

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| 仓库名称 | 文本 | 只读；带出当前仓库名称；不出现在列表 |
| 库位编码 | 文本 | 必填；须为 8 位数字（前 4 位为所属仓库编码，后 4 位为库位码） |
| 备注 | 多行文本 | 非必填；最长 255；约 6 行；无字数统计 |

##### 交互

- 查看与新增/编辑同一表单区域，全部只读。

##### 逻辑

- 库位编码须以当前仓库编码为前缀，后缀 4 位数字。
- 同一工厂下库位编码不能重复。
- 编辑时：若旧库位编码已被二维码占用，不允许修改库位编码。

#### 库位删除/批量删除

##### 页面元素

无（确认框）。

##### 交互

- 批量删除需先勾选行；未勾选时提示先选择数据。

##### 逻辑

- 可执行条件：所选库位编码未被二维码占用；已被占用时禁止删除。
- 执行后本模块删除所选普通库位。
