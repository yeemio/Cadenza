# 工序管理模块 PRD 文档

---

## 1. 基本说明

### 1.1. 业务理解

工序管理维护 MES **工序主数据**（工序名称、工序编码、所属部门、工作中心、公司组织编码、备注），供工序模板、订单工序配置、派工排产等引用。数据以本页人工维护为主；ERP/U9 亦可同步同一主数据，但不走本页界面。

本模块无启用/停用等业务状态流转，增删改后即生效。删除前须确认未被工序模板、订单排产、订单工序占用；已被订单排产引用的工序，编辑时工作中心、所属部门均不可改。

**两端分工：**

- **Web**：列表查询、新增、编辑、查看、删除/批量删除。
- **PDA**：无。

## 2. Web 端

### 2.1. 工序管理页面

##### 逻辑

#### 新增/编辑

##### 页面元素

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| 所属部门 | 树选 | 非必填 |
| 工作中心 | 下拉 | 必填；可筛选 |
| 公司组织编码 | 文本 | 必填；只读；最长 50 |
| 工序名称 | 文本 | 必填；最长 20 |
| 工序编码 | 文本 | 必填；最长 20 |
| 备注 | 多行文本 | 非必填；最长 255 |

##### 交互

- 所属部门与工作中心、公司组织编码联动（细则以设计图为准）：
  - 未选所属部门时：工作中心下拉为全部工作中心。
  - 先选所属部门：工作中心下拉仅该部门下；公司组织编码带出该部门组织编码。变更所属部门时清空已选工作中心并重带组织编码。
  - 先选工作中心：回填所属部门且所属部门不可改；公司组织编码同步为该部门组织编码。工作中心未配置部门时提示并清空工作中心。
  - 清空工作中心：同步清空所属部门与公司组织编码。
- 工序名称首尾不允许空格，不符合时提示并清空。
- 编辑时若该工序已被订单排产引用：工作中心、所属部门均不可改。
- 查看与新增/编辑同一表单区域，全部只读；表单双列排布；查看时另展示创建时间、创建人（排在备注上方）。

##### 逻辑

- 同一所属部门下工序名称不能重复。
- 同一公司组织编码下工序编码不能重复。
- 保存时所属部门须与工作中心所属部门一致；工作中心须已配置所属部门。
- 已被订单排产引用的工序，不允许变更工作中心。

#### 删除/批量删除

##### 页面元素

无（确认框）。

##### 交互

- 批量删除需先勾选行；未勾选时提示先选择数据。

##### 逻辑

- 可执行条件：依次校验占用，先命中先提示并拦截——① 被工序模板明细引用 →「在模版中使用的工序不能删除」；② 被订单排产引用 →「已排产的工序不能删除」；③ 被订单工序引用 →「当前工序已经被使用,无法删除」。
- 执行后本模块逻辑删除该工序。
