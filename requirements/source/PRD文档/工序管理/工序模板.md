# 工序模板模块 PRD 文档

---

## 1. 基本说明

### 1.1. 业务理解

工序模板维护一组可复用的**工序顺序配置**（模版名称、所属车间、配置工序列、备注），供生产订单等业务「套用工序模板」时一次性带入工序明细。模板主数据与工序管理主数据配合使用：配置工序时从工序管理中选择工序。

本模块无启用/停用等业务状态流转，增删改后即生效。删除为逻辑删除，同步清理模板明细与车间关联；删除前不做「是否被订单引用」拦截（以当前实现为准）。

**两端分工：**

- **Web**：列表查询、新增、编辑、查看、删除/批量删除。
- **PDA**：无。

## 2. Web 端

### 2.1. 工序模板页面

#### 列表页面

##### 页面元素

**列表上的搜索条件**

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| 模版名称 | 文本 | 模糊 |
| 所属部门 | 树选 | 精确；按模板关联车间及该部门下级过滤 |

**列表上面的按钮：**新增、删除。

**列表展示字段：**

| 列名 | 说明 |
| ---- | ---- |
| # | 序号 |
| 模版名称 | 过长省略 |
| 所属部门 | 关联车间名称，多个以 `+` 拼接 |
| 工序详情 | 配置工序名称按顺序以 `+` 拼接 |
| 备注 | 过长省略 |
| 操作 | |

**列表操作栏的按钮：**编辑、查看、删除。

##### 交互

- 按创建时间正序。
- 点击数据行可勾选或取消勾选。
- 进入页面时「所属部门」默认带入当前登录人所属部门（取第一个）；点「清空」后去掉该默认，不再自动回填。

##### 逻辑

无

#### 新增/编辑

##### 页面元素

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| 模版名称 | 文本 | 必填；最长 50 |
| 所属车间 | 树多选 | 必填；父子不联动 |
| 配置工序 | 子表 | 必填；至少 1 行 |
| 备注 | 多行文本 | 非必填；最长 255 |

**配置工序子表列：**

| 列名 | 说明 |
| ---- | ---- |
| 顺序 | 行号 |
| 工序名称 | 下拉；可筛选；选项展示为「工序名称(所属部门)」 |
| 操作 | 上移、下移、删除；查看时不展示本列 |

##### 交互

- 配置工序子表上方有「新增」行按钮；查看时不展示。
- 行内可上移/下移调整顺序（首行不可上移、末行不可下移）。
- 空明细或存在未选工序的行时不允许保存。
- 查看与新增/编辑同一表单区域，全部只读；配置工序仅展示顺序与工序名称；查看不展示创建人、创建时间。

##### 逻辑

- 模版名称不能重复。
- 新增/编辑保存时至少保留 1 条配置工序，不允许空明细；每一行须选定工序。
- 保存时按子表当前顺序写入排序号；工序详情按工序名称以 `+` 拼接落库展示。

#### 删除/批量删除

##### 页面元素

无（确认框）。

##### 交互

- 批量删除需先勾选行；未勾选时提示先选择数据。

##### 逻辑

- 执行后本模块逻辑删除该模板，并同步删除其配置工序明细与所属车间关联。
