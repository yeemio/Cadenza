# 异常上报模块 PRD 文档

---

## 1. 基本说明

### 1.1. 业务理解

异常上报供现场用 PDA 扫描设备码后查看设备信息，并选择设备状态提交。提交后更新该设备的状态，并记一条状态变更记录（来源为 PDA）。与 Web 设备档案上的「修改设备状态」是同一套状态变更能力，本模块不另做列表与查询。

```text
主页「异常上报」
        ↓
扫设备码 → 带出设备信息、当前状态
        ↓
改选设备状态 → 提交 → 回主页，提示已上报
```

**两端分工：**

- **Web**：本模块无独立页面；设备状态在设备档案中修改（见设备管理相关能力），不在本文展开。
- **PDA**：扫码查设备、选状态、提交上报。

### 1.2. 字典说明

#### 设备状态

| 类型值 / 状态值 | 说明 | 颜色 |
| --------------- | ---- | ---- |
| 正常 | 设备可正常使用。 | |
| 维修 | 设备处于维修。 | |

字典编码：`equipment_status`。页面单选项按字典展示。

## 2. Web 端

本模块无独立 Web 页面。

## 3. PDA 端

> 接口返回失败时，由全局请求处理提示系统返回的原因（无原因时提示「操作失败」）。

### 3.1. 异常上报页面

**入口：**主页「设备管理」分类下的「异常上报」。

#### 详情页面

##### 页面元素

**导航栏标题：**异常上报；左侧返回。

**信息区（白底卡片，左标签右值）：**

| 字段 | 说明 |
| ---- | ---- |
| 设备编码 | 未扫码时右侧提示「请使用侧边扫码按钮扫描设备码」（设计图为点「扫码」）；扫码成功后显示编码 |
| 设备名称 | 无值显示 `-` |
| 工作中心 | 无值显示 `-` |
| 设备产能 | 无值显示 `-` |
| 所属部门 | 无值显示 `-` |
| 设备状态 | 单选，选项见字典「设备状态」；整组靠右，可换行 |

**页面按钮：**右下角悬浮「扫码」；底部整宽「提交」。

##### 交互

- 进入页时加载设备状态字典；未扫码前信息区除状态选项外为空提示或 `-`。
- 扫码成功后刷新信息区，并把「设备状态」单选切到该设备当前状态。
- 点「提交」：校验通过后提交；成功轻提示「设备异常已上报」，回到主页。
- 点返回回到主页。
- 本页无列表、不分页、无下拉刷新。

##### 逻辑

- 未扫到有效设备（无设备主键）时不可提交，轻提示「请先扫描设备码」。
- 未选设备状态时不可提交，轻提示「请选择设备状态」。
- 提交成功：更新该设备状态；若状态相对变更前有变化，记一条设备状态变更记录（来源 PDA）；Web 设备档案中该设备状态同步为新状态。
- 提交时状态与当前相同：仍算成功，不新增变更记录。

#### 扫码

##### 页面元素

无。

##### 交互

- 点右下角悬浮「扫码」完成本次扫码（设计图无侧边硬件键；真机为侧边扫码）。
- 扫码内容为空：轻提示「扫码内容为空」，页面不变。
- 扫设备码成功：带出设备编码、名称、工作中心、产能、部门，并选中当前设备状态。
- 获取设备失败：轻提示「获取设备信息失败」（或系统返回原因），页面不变。
- 码可带 `EQU-` / `equ-` 前缀，查询前去掉前缀再按设备编码匹配。

##### 逻辑

无
