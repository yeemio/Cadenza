# 二维码管理模块 PRD 文档

---

## 1. 基本说明

### 1.1. 业务理解

二维码管理（码包管理模块下）按 **产品类型** 与 **数量** 批量生成追溯二维码并归入码包；支持码包 ZIP 下载、标签打印（打印成功后码包变为已打印），以及按单条二维码 **条码补打**（新建数量为 1 的码包）。本页 **不提供删除、查看、编辑**。

**两端分工：**

- **Web**：列表查询、新增码包（批量生成）、下载、打印、条码补打。
- **PDA**：无。

### 1.2. 字典说明

| --------------- | ---- | ---- |
| 1 | 自制成品 | |

#### 码包状态

| 类型值 / 状态值 | 说明 | 颜色 |
| --------------- | ---- | ---- |

## 2. Web 端

### 2.1. 二维码管理页面

#### 列表页面

##### 页面元素

**列表上的搜索条件**

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| 产品类型 | 下拉 | 精确；选项见字典「产品类型」 |
| 码包状态 | 下拉 | 精确；选项见字典「码包状态」 |
| 创建人员 | 下拉 | 精确；可筛选 |

**列表上面的按钮：**新增码包、下载、条码补打。

**列表展示字段：**

| 列名 | 说明 |
| ---- | ---- |
| # | 序号 |
| 产品类型 | 字典「产品类型」 |
| 二维码数量 | |
| 首码 | |
| 尾码 | |
| 码包状态 | 着色见字典「码包状态」 |
| 创建人员 | |
| 创建日期 | |
| 操作 | |

**列表操作栏的按钮：**下载、打印。

##### 交互

- 按创建日期倒序。
- 点击数据行可勾选或取消勾选。
- 进入页面时，创建人员默认带入当前登录人；可清空或改选。
- 码包状态着色见字典「码包状态」。
- 操作栏按钮显隐和置灰：
  - 打印：仅未打印显示
  - 下载：始终显示

##### 逻辑

无

#### 新增码包

##### 页面元素

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| 产品类型 | 下拉 | 必填；字典「产品类型」 |
| 二维码数量 | 数字 | 必填；1～99999 |

##### 交互

无

##### 逻辑

- 执行后生成码包及对应数量的二维码明细；码包状态为未打印；首码、尾码由系统按编码规则写入。

#### 下载

##### 页面元素

无。

##### 交互

- 列表上方下载：须先勾选行；未勾选时提示先选择数据。
- 操作栏下载：下载当前行对应码包。

##### 逻辑

- 按所选码包导出 ZIP（内含各包二维码文本）；不改变码包状态。

#### 条码补打

##### 页面元素

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| 二维码编码 | 文本 | 必填；最长 32 |

##### 交互

无

##### 逻辑

- 执行后按二维码解析产品类型，新建数量为 1、状态为未打印的码包及一条明细。

#### 打印

##### 页面元素

弹窗标题「打印设置」；内容为打印设计器（非弹窗外层页脚按钮）。支持全屏。

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| 模板 | 下拉 | 业务字典打印模板 |
| 打印机 | 下拉 | 旁侧有「刷新」；选项来自本地打印服务 |
| 地址 | 文本 | 本地打印服务地址，默认 `http://127.0.0.1` |
| 端口 | 文本 | 本地打印服务端口，默认 `9100` |
| 左右偏移 | 数字 | -2000～2000 |

设计器底部按钮：打印（未取到码、未选模板/打印机、打印进行中时不可点）。

##### 交互

- 仅未打印行可打开本弹窗。
- 打开后拉取该码包全部二维码（用于拼标签内容，界面不展示码列表）。
- 改地址/端口后重新拉取打印机；点「刷新」立即重新拉取。
- 获取打印机失败时在打印机下方展示失败信息。
- 关闭弹窗后刷新列表。

##### 逻辑

- 按模板将每条二维码生成标签内容，提交本地打印服务；成功后码包状态变为已打印。
