# 调拨入库模块 PRD 文档

---

## 1. 基本说明

### 1.1. 业务理解

调拨入库承接调拨出库：调拨出库在 PDA 完成出库时，系统自动生成一张调拨入库单，记下调出仓库、调入仓库、每个料品的待入库数量和码。本模块负责把这些在途的码上架到调入仓库。单据不能在本模块手工新增、编辑或删除。

按出库时是否选了调入库位分两种入库方式：

- **固定库位**：出库时已选调入库位，码直接放到该库位。入库单生成即为已完成，入库人员、完成时间为出库操作人和出库时间。
- **自定义库位**：出库时没选库位，码处于已出库（在途）状态。入库单为待入库，需要在 PDA「调拨入库」逐个扫码、选库位后完成入库。

```text
调拨出库完成出库
├─ 选了调入库位 → 生成调拨入库单（固定库位，已完成），码直接在库
└─ 没选调入库位 → 生成调拨入库单（自定义库位，待入库），码在途
        ↓
PDA 调拨入库扫码上架（调入仓库为仓库时要选库位，线边仓不选）→ 入库中
        ↓
每个料品都扫满后，PDA 完成入库 → 已完成（入库人员、完成时间），码变为在库
```

**两端分工：**

- **Web**：查询调拨入库单，查看单据详情、每个料品的入库码和入库库位。只读。
- **PDA**：按状态查看调拨入库单，扫码上架、扫码删除、完成入库，查看每个料品已扫的码。

### 1.2. 字典说明

#### 入库单状态

PDA 列表分段使用，页面上不着色。

| 类型值 / 状态值 | 说明 |
| --------------- | ---- |
| 待入库 | 自定义库位的入库单刚生成，或扫过的码全部删掉。 |
| 入库中 | 已有码扫码上架，还没有完成入库。 |
| 已完成 | 已完成入库；固定库位的入库单生成即为本状态。 |

#### 入库方式

Web 列表叫「入库类型」，详情叫「入库方式」。

| 类型值 / 状态值 | 说明 |
| --------------- | ---- |
| 固定库位 | 调拨出库时已选调入库位，生成即已完成。 |
| 自定义库位 | 调拨出库时未选调入库位，需 PDA 扫码上架。 |

#### 码入库状态

PDA 已扫码明细使用，文字颜色取该字典项备注里配置的颜色。

| 类型值 / 状态值 | 说明 |
| --------------- | ---- |
| 未入库 | 该码还没扫码上架。 |
| 已入库 | 该码已扫码上架，记下入库库位。 |

#### 仓库类型

| 类型值 / 状态值 | 说明 |
| --------------- | ---- |
| 仓库 | PDA 扫码上架时必须选库位。 |
| 线边仓 | PDA 扫码直接上架，不选库位。 |

## 3. PDA 端

> 字典见 1.2。
>
> 设计图没有侧边硬件键，需要扫码的页面或弹层都放一个「扫码」按钮，点它等同于源码里按一次侧边键。源码里「侧边按钮扫码」这类文案，设计图统一写成「点扫码」，其余文案与源码一致。设计图不播放扫码提示音。

> 系统返回键（侧滑、物理返回）不生效，只能点导航栏左侧返回。列表默认下拉刷新、上拉加载；没有更多时提示「数据加载完毕！」。

#### 扫码

##### 页面元素

无（使用页面「扫码」）。

##### 交互

- 点「扫码」按扫到的码分类处理：
  - 载具码（第 2 位为 E、F、M、P）：查询该码在本单的待入库信息。调入仓库为仓库时，打开「扫码入库」弹层（见下）选库位；调入仓库为线边仓时，不弹层直接上架，成功提示「入库扫码成功」，列表刷新
  - 货架码（8 位数字）：在弹层外扫不生效；库位在「扫码入库」弹层里选择或扫描
  - 其它码：提示「请扫描正确的二维码」
- 查询失败提示系统返回的原因（无原因时提示「入库扫码失败」）；网络异常提示「扫码确认失败，请重试」。

##### 逻辑

- 不允许的情况，提示括号内文案：
  - 码不在本单，或已扫码入库（「二维码不存在」）
  - 扫的是托下的单个码（「该码需要扫描关联托码」）
  - 码已经在库中（「码已经入库,无法操作」）
  - 调入仓库已锁定（「入库仓库已锁定」）
- 扫托码时，整托下的码一起上架。

#### 扫码入库弹框

扫到载具码且调入仓库为仓库时打开。

##### 页面元素

底部弹层，高约 75% 画布，标题「扫码入库」，右上角「×」。底部整宽蓝色按钮「确认」。弹层内有「扫码」按钮。

**上方：**

| 字段 | 说明 |
| ---- | ---- |
| 库位编码 | 整行可点；未选时提示「请选择库位/点扫码」 |
| 货架层数 | 扫到货架码后才出现；右侧下箭头 |
| 仓库名称 | 选库位或扫货架码后带出；未带出时显示「暂无数据」 |

**下方：**本次扫到的码，按料品一组，无值显示 `-`。

| 字段 | 说明 |
| ---- | ---- |
| 拖码 / 产品轴号 | 扫的是托码显示「拖码」，否则显示「产品轴号」；值为本次扫到的码 |
| 料品名称 | 过长省略 |
| 料品编码 | |
| 规格 | 无值显示 `N/A` |
| 颜色 | |
| 调入数量（单位） | |
| 二维码数量 | 托码才显示 |

##### 交互

- 每次打开时库位编码、仓库名称为空。
- 弹层内点「扫码」：
  - 货架码：库位编码显示货架编码，带出仓库名称，出现「货架层数」（层数为空）
  - 载具码：重新查询并替换下方的码
  - 其它码：提示「请扫描正确的二维码」
- 点「库位编码」打开库位选择：底部弹层，高约 80% 画布，顶部圆角搜索框「搜索库位」和搜索图标；左栏仓库（只有本单调入仓库），右栏库位，有备注时库位与备注各占一半。输入库位号后点搜索图标过滤。点库位写回库位编码、仓库名称，清空并隐藏货架层数。
- 点「货架层数」：重新读取该货架层数（已选层数清空）后打开层数弹层，一行一个层数，点某层写回。
- 点「确认」：
  - 出现货架层数但没选：提示「请选择货架层数」
  - 成功：关闭弹层，列表刷新，提示「入库扫码成功」
  - 失败：提示系统返回的原因（无原因时提示「入库扫码失败」），弹层保持打开；网络异常提示「扫码确认失败，请重试」
- 点「×」或遮罩关闭弹层，不上架。

##### 逻辑

- 提交的库位：选库位为库位编码；选货架层数为「货架编码 + 两位层数」，如货架 0203 第 3 层为 `020303`。
- 可执行条件，不满足时提示括号内文案：
  - 调入仓库为仓库时必须有库位（「库位编号不能为空」）
  - 库位不存在或不属于调入仓库（「库位不存在」「库位不属于该入库仓库」）
  - 货架不存在或不属于调入仓库（「货架不存在」「货架不属于该入库仓库」）
- 确认后：该码（托码连同托下所有码）在本单变为已入库，记下仓库、货架、库位；码被锁定（锁定动作 = 调拨入库）；重新累计该料品已扫码数量、已入库数量；入库单状态变为入库中。

#### 扫码删除弹框

点页面「扫码删除」打开。

##### 页面元素

底部弹层，高约 75% 画布，标题「当前扫码信息」。底部整宽蓝色按钮「完成删除」。弹层内有「扫码」按钮。

**上方：**库位编码（未扫时提示「请选择库位/点扫码」）、仓库名称（未扫时显示「暂无数据」）。

**下方：**扫码后按码展示，字段同「扫码入库弹框」下方，托码 / 产品轴号的值为本次扫到的码。

##### 交互

- 每次打开都清空上次内容。弹层打开期间，扫到的码只用于删除。
- 点「扫码」查询该码在本单的已入库记录：成功带出库位编码、仓库名称和码信息；失败内容不变，由全局请求处理提示系统返回的原因。
- 点「完成删除」：成功关闭弹层，列表刷新，提示「删除成功」；失败弹层保持打开，由全局请求处理提示系统返回的原因。
- 点遮罩关闭弹层，不删除。

##### 逻辑

- 扫码校验：码不在本单或还没入库（「二维码不存在」）；托下的单个码（「该码需要扫描关联托码」）；码已经在库中（「码已经入库,无法操作」）。
- 删除后：该码（托码连同托下所有码）在本单退回未入库，清空库位，解除锁定；重新累计数量；本单已没有已入库的码时状态回到待入库。

#### 完成入库

##### 页面元素

确认框，标题「完成入库」，内容「确认成品入库」，按钮：取消、确认。

##### 交互

- 成功：关闭确认框，提示「入库完成」，约 1.5 秒后回到调拨入库列表，分段回到「待入库」。
- 失败：提示系统返回的原因（无原因时提示「入库失败」），确认框保持打开。网络异常提示「操作失败，请重试」并关闭确认框。

##### 逻辑

- 可执行条件，不满足时提示括号内文案：
  - 每个料品的已入库数量都不少于待入库数量（「入库失败:入库数量和待入库数量不符」）
  - 至少有一个码已入库（「入库失败:未有物料入库」）
  - 调入仓库已锁定（「入库仓库已锁定」）
  - 码已在库中、码不存在（「码已经入库,无法操作」「部分二维码不存在」）
- 执行后：
  - 入库单状态变为已完成，记下入库人员、完成时间
  - 已入库的码移到调入仓库及所选货架、库位，变为在库中并解除锁定
  - 库存统计按本单已入库的码重新统计
