# 成品出库模块 PRD 文档

---

## 1. 基本说明

### 1.1. 业务理解

成品出库承接外部下发的发货单（PL），仓库在 PDA 上完成打包、扫码备货并确认出库；Web 只做查询、查看明细，以及同步失败后的重试。单据不能在本模块手工新增。

一条出库单从 **待装箱** 开始。需要打包的单，先在 PDA「待打包」里完成打包任务，再进入备货扫码；不需要打包的单直接备货扫码。明细扫码件数都达到要求后，出库状态变为 **待出库**。PDA 在待出库单上确认出库后变为 **已出库**，记下出库人员、出库完成时间，库存状态更新为已发货，并分别尝试实发轴同步、发货状态同步。

```text
外部下发发货单
├─ 需要打包 → PDA 待打包（打包任务扫码、绑托）→ 待装箱备货
└─ 不需要打包 → PDA 待装箱备货扫码
        ↓
明细扫码件数满足 → 待出库
        ↓
PDA 确认出库 → 已出库（出库人员、出库完成时间）
        ├─ 实发轴同步（无轴号差异则无需同步）
        └─ 发货状态同步
```

**两端分工：**

- **Web**：列表查询、查看料品与库位、查看组成；待出库可「确认出库」，确认后变为已出库。实发轴同步失败可「dc重试」，发货状态同步失败可「发货状态重试」。不做出库扫码、打包，也不删除单据。
- **PDA**：从工作台进入。顶部分段为待打包、待装箱、待出库（不含已出库）。待打包进入打包出库；其余分段进入出库详情，扫码、删码、拍照，待出库可确认出库。

### 1.2. 字典说明

#### 出库状态

| 类型值 / 状态值 | 说明 | 颜色 |
| --------------- | ---- | ---- |
| 待装箱 | 单据已下发，备货或打包尚未完成到可出库。 | `#E6A23C` |
| 待出库 | 明细扫码件数已满足，可以确认出库。 | `#409EFF` |
| 已出库 | 已确认出库，记下出库人员、出库完成时间。PDA 列表分段不展示本状态。 | `#67C23A` |

Web 列表「出库状态」着色见本字典。

#### 实发轴同步状态

| 类型值 / 状态值 | 说明 | 颜色 |
| --------------- | ---- | ---- |
| 未同步 | 尚未把实发轴差异同步出去。 | `#909399` |
| 同步失败 | Web 操作栏显示「dc重试」。 | `#F56C6C` |
| 已同步 | 实发轴已同步成功。 | `#67C23A` |
| 无需同步 | 客户轴号与实发轴号没有差异，不需要同步。 | `#409EFF` |

#### 发货状态同步

| 类型值 / 状态值 | 说明 | 颜色 |
| --------------- | ---- | ---- |
| 未同步 | 出库完成后尚未同步发货状态。 | `#909399` |
| 同步失败 | Web 操作栏显示「发货状态重试」。 | `#F56C6C` |
| 已同步 | 发货状态已同步成功。 | `#67C23A` |

仅 **已出库** 且尚未同步成功的单据会参与发货状态同步。

#### 装箱状态

PDA 出库详情卡片使用。

| 类型值 / 状态值 | 说明 | 颜色 |
| --------------- | ---- | ---- |
| 待装箱 | 该托或该轴尚未装完。 | 卡片 `#FFE4E1`、边框 `#FFB3B3`，状态字 `#FF0000` |
| 已装箱 | 该托或该轴已装完。 | 卡片 `#E7F6E4`、边框 `#8FD19A`，状态字 `#008000` |

#### 打包状态

仅 PDA 打包任务使用。

| 类型值 / 状态值 | 说明 | 颜色 |
| --------------- | ---- | ---- |
| 待打包 | 打包任务未完成，可扫码、删码、绑托。 | 卡片 `#FDF6EC`，状态字 `#E6A23C` |
| 已打包 | 打包任务已完成，托码与库位只读。 | 卡片 `#F0F9EB`，状态字 `#67C23A` |

#### 扫码进度

PDA 打包任务内的轴码使用。

| 类型值 / 状态值 | 说明 | 颜色 |
| --------------- | ---- | ---- |
| 未扫 | 已扫件数 = 0。 | `#E54D42` |
| 部分扫码 | 已扫件数大于 0 且小于应扫件数。 | `#4050B3` |
| 已扫满 | 已扫件数 = 应扫件数。 | `#4CAF50` |

## 3. PDA 端

> 字典见 1.2。列表默认下拉刷新、上拉加载；没有更多时提示「数据加载完毕！」。

**卡片展示字段：**

##### 交互

- 无值显示 `-`。
- PL号蓝色加粗。
- 从首页进入时，装箱日期默认当天，并清掉上次的 PL号、客户轴号、PO号；从本模块其它页返回时，保留上次查询条件。
- 点待打包分段里的卡片，进入打包出库（见 3.2）。
- 点待装箱、待出库分段里的卡片，进入出库详情（见 3.4）。

- 数据范围：待打包只含「需要打包、打包未完成、出库状态仍为待装箱」的单据。待装箱、待出库按对应出库状态过滤。已出库不进本列表。
- 分段数量随当前查询条件一起统计。

#### 查询

##### 页面元素

本页居中弹窗，浅灰底大圆角。标题「查询条件」靠左，右侧关闭图标，标题下有分割线。每行左标签、右白色输入框。

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |

| PO号 | 文本 | 提示「请输入PO号」 |
| 发货日期 | 日期 | 提示「请选择发货日期」 |
| 装箱日期 | 日期 | 提示「请选择装箱日期」；从首页进入默认当天 |

##### 交互

- 点日期框，从画布底部弹出月历，可切换上下月；点某一天写入并关闭月历，点「清空」清除该日期，点「取消」不改。
- 查询条件需要记忆：点查询后记住条件；从首页再次进入时，只保留当天装箱日期，文本条件清空。
- 点遮罩不关闭弹窗，只能点关闭图标或查询。点关闭图标不改条件。
- 重置清空全部条件，并立刻按空条件刷新列表和分段数量。
- 查询后关闭弹窗，列表回到第一页，分段数量同步刷新。

##### 逻辑

- PL号、PO号、客户轴号为模糊条件。客户轴号在待打包分段按打包码匹配，在其它分段按出库码匹配。

#### 扫码

##### 页面元素

待打包时，页面右侧悬浮「扫码」。删除弹层打开后，「扫码」在红色按钮上方，底部整宽红色按钮为「完成删除」。

##### 交互

- 页头还没有托码时，点页面「扫码」写入托码。
- 已有托码时，点页面「扫码」按载具码装入当前打包任务，对应行已扫码件数增加。货架码则带出调入库位，并出现货架层数。
- 码不符合时提示「请扫描正确的二维码」。
- 上次扫码未处理完时，提示「上次扫码处理中，请勿继续扫码」。
- 点「扫码删除」打开扫码删除弹框（见下）。

##### 逻辑

- 扫码时：产品未审核、质量存疑、已被其它业务锁定、未关联销售订单行、没有段长，均不允许装入。
- 重复扫描已在本任务扫过的码，不允许再次装入。
