# 订单排程模块 PRD 文档

---

## 1. 基本说明

### 1.1. 业务理解

订单排程面向已下达的生产订单，在「订单 × 工序 × 设备 × 生产日期」维度维护计划产量。提交后汇总回写各工序已排数量与是否排完，并刷新订单整体排产状态（未排产 / 部分排产 / 已排产）。同一订单、同一订单工序、同一标准工序、同一设备、同一生产日期至多一条有效排产；将计划产量改为 0 并保存即删除该槽位。

主路径为 **订单排程列表 → 生产排程详情**（设备×日期矩阵点格修改）。另可从 **生产订单列表** 打开「设备排产」弹窗按设备填报，与详情共用同一套排产提交能力；该入口属生产订单模块，本文不展开。独立「设备排程」看板不在本文范围。

```text
订单排程列表筛选
├─ 工序设置 = 未配置 → 无「详情」
└─ 工序设置 = 已配置
       ↓
   校验各工序已配置工作中心
       ↓
   生产排程详情（按工序 Tab）
       ↓
   点击有计划量色块 → 修改排程
       ├─ 计划量改为 0 → 删除该槽位
       ├─ 正数：工序计划合计不得超过下线数量（强校验）
       └─ 正数：超设备日产能则二次确认后仍可提交（弱提醒）
```

**两端分工：**

- **Web**：列表查询、进入详情、矩阵改排程。
- **PDA**：无。

### 1.2. 字典说明

#### 排产状态

| 类型值 / 状态值 | 说明 | 颜色 |
| --------------- | ---- | ---- |
| 未排产 | 各工序尚无有效已排计划（或合计为 0）。 | `#909399` |
| 部分排产 | 已有计划，但并非全部工序均已排完。 | `#E6A23C` |
| 已排产 | 全部工序均已排完（各工序计划合计 ≥ 该工序下线数量）。 | `#67C23A` |

列表搜索「排产状态」、列表「排产状态」列着色见本字典。

#### 生产状态

| 类型值 / 状态值 | 说明 | 颜色 |
| --------------- | ---- | ---- |
| 允许开工 | 可开工前状态。 | `#E6A23C` |
| 进行中 | 已开工。 | `#409EFF` |
| 已结束 | 业务已结束。 | `#67C23A` |

本列表「生产状态」着色见本字典（与生产订单模块同一套订单状态字典）。

#### 工序设置

| 类型值 / 状态值 | 说明 | 颜色 |
| --------------- | ---- | ---- |
| 未配置 | 尚未配置工艺路线；列表不显示「详情」。 | `#fe0818` |
| 已配置 | 已配置工艺；满足工作中心校验后可进详情。 | `#828482` |

#### 设备状态

| 类型值 / 状态值 | 说明 | 颜色 |
| --------------- | ---- | ---- |
| 正常 | 可新建正数排产槽位。 | `#67C23A` |
| 维修 | 尚无槽位时不允许新建正数排产；已有槽位仍可改正数或改 0 删除。 | `#E6A23C` |

详情矩阵设备标签文字/边框色、计划色块背景/边框色见本字典。

## 2. Web 端

**列表操作栏的按钮：**详情

##### 交互

- 按创建时间倒序。
- 操作列固定在左侧，横向滚动时不变。
- 工序设置、生产状态、排产状态着色见对应字典。
- 生产状态、排产状态无值显示 `-`。
- 生产进度为绿色进度条；对下线数量 > 0 的工序，按与生产订单列表一致的加权方式计算整单完成占比，向下取整且不超过 100%。
- 当前进度：按工序列表顺序，跳过下线数量 ≤ 0 的工序，取第一道完成占比 < 100% 的工序名称；全部完成显示空；无工序列表显示 `-`。
- 工序进度：每道工序展示名称与完成占比进度条；悬停按该工序下排产汇总到设备，展示详情数量、完成数量、完成进度；无设备明细时提示「该工序暂无排产设备明细」；无工序列表时整列显示 `-`。
- 操作栏按钮显隐：
  - 详情：仅工序设置 = 已配置时显示

##### 逻辑

- 数据范围：生产订单排产视角列表；本页不手工新增订单。
- 待排产工序筛选：仅保留「存在所选工序且该工序排产尚未排完」的订单。

#### 详情

##### 页面元素

无（跳转二级页）。

##### 交互

- 点击「详情」：先校验该订单下所有工序均已配置工作中心；通过则跳转到生产排程详情页（见 2.2）；不通过则提示错误并留在本页。

##### 逻辑

- 可执行条件：工序设置 = 已配置，且各工序均已配置工作中心。

### 2.2. 生产排程详情页面

#### 列表页面

##### 页面元素

**页面标题：**生产单号：{单号}。

**基础信息（折叠，只读）：**

| 字段 | 说明 |
| ---- | ---- |
| 品名 | |
| 规格 | |
| 电压 | |
| 计划完成时间 | |
| 工艺文件 | 链接「查看详情」，新窗口打开 |
| 生产数量 | 有生产单位时标签为「生产数量（单位）」 |
| 颜色 | |
| 生产部门 | |
| 印字分段 | |
| 订单附件 | 链接「附件详情」，新窗口打开 |

**当前工序排产区标题行：**当前工序已排产 {已排产}{单位}、已报工 {已报工}{单位}、报工待审核 {待审核}{单位}（无生产单位则不带单位后缀）。

**工序 Tab：**标签为工序名称（含备注拼接展示名）；默认选中第一道。

**矩阵：**

| 列名 | 说明 |
| ---- | ---- |
| 设备（固定左列） | 设备名称 + 设备状态标签（见字典「设备状态」） |
| 动态日期列 | 表头为「月-日 周几」；仅汇总本单该日计划量 > 0 的日期 |

**列表上面的按钮：**无

**列表操作栏的按钮：**无（点色块改排程）

##### 交互

- 品名、规格、电压、计划完成时间、生产数量、颜色、生产部门、印字分段无值显示 `-`；页面标题无生产单号时显示 `-`。
- 切换工序 Tab：刷新标题汇总数、设备矩阵与日期列。
- 已排产 = 当前工序各槽位计划合计；已报工 = 该工序全部报工产量合计（与是否存在排产行无关）；报工待审核 = 未审核报工产量合计（与是否存在排产行无关）。
- 仅当某设备某日本单计划量 > 0 时渲染可点击色块（文案「计划产量」+ 数值）；色块颜色见字典「设备状态」。
- 点击色块打开「修改排程」（见下节）。空白格不可新建排产。

##### 逻辑

- 数据范围：当前订单及其工序、工作中心下设备与已有排产槽位。

#### 修改排程

##### 页面元素

弹窗。

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| 工序 | 只读 | 当前 Tab 工序名称（含备注） |
| 设备名称 | 只读 | |
| 生产日期 | 只读 | 展示为年.月.日 |
| 计划产量 | 数字 | 必填；≥0；最多 4 位小数；有生产单位时标签带单位 |
| 备注 | 多行文本 | 非必填；最长 255 |

##### 交互

- 打开时回显该槽位计划量与备注；若同槽位存在多条历史，计划量取合计（>0 时），备注取首条。
- 计划产量改为 0 并确定：删除该槽位，不弹超产能确认；成功后色块消失。
- 计划产量为正数：若设备已配置日产能（含配置为 0），且当日该设备累计排产（本槽位按替换旧值计）将超过产能，先确认「设备【设备名称】MM-DD 当天的累计排产 XXXX，超过设备产能。确定要继续排产吗？」；确认后再提交。产能未配置（空）不参与比较、不弹确认。
- 成功后提示提交成功，关闭弹窗，刷新当前工序汇总数与矩阵。

##### 逻辑

- 可执行条件：矩阵上该格已有本单计划量 > 0（仅改已有槽位）。
- 工序强校验：该订单工序下全部槽位计划合计（本槽位替换旧值后）不得超过该工序下线数量；不通过则禁止保存，且不进入超产能确认。
- 设备状态：本槽位尚无排产且计划量 > 0 时，设备须为正常；已有排产时可改正数；计划量 ≤ 0 删槽不要求设备正常。
- 执行后：写入或删除该槽位排产；回写工序已排数量与是否排完；按各工序情况回写订单排产状态（未排产 / 部分排产 / 已排产）。
