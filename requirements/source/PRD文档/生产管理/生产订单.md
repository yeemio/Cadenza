# 生产订单模块 PRD 文档

---

## 1. 基本说明

### 1.1. 业务理解

生产订单承接上游（如 U9）同步下来的生产任务，在 Web 上完成工序路线配置、开工、工序/订单报工、设备排产。单据不以本模块手工新增为主；列表是车间日常操作台，按工序完成情况汇总生产进度。

一条订单从 **已核准** 进入。上游放行后变为 **允许开工**；配置工序并开工后变为 **进行中**，通过报工推进完成量与进度；业务完成后变为 **已结束**。异常可 **已作废**。工序设置另有 **未配置 / 已配置**。缺分段同步信息时列表行底色标黄；上游有更新时生产单号旁提示。

```text
上游同步生产订单
├─ 已核准 →（上游放行）→ 允许开工
│              ↓
│         工序设置（未配置 → 已配置；可模版 / 历史工序）
│              ↓
│         开工 → 进行中（记实际开工时间）
│              ├─ 工序报工 / 批量报工
│              ├─ 订单报工
│              └─ 设备排产
│              ↓
└─ 已结束；异常可作废
```

**两端分工：**

- **Web**：列表查询、工序设置、开工、报工、订单报工、批量报工、设备排产、查看详情、导出、删除。
- **PDA**：本模块当前无独立 PDA 端（报工/任务等若存在，属其它菜单，不在本文展开）。

### 1.2. 字典说明

#### 生产状态

| 类型值 / 状态值 | 说明 | 颜色 |
| --------------- | ---- | ---- |
| 已核准 | 已同步入系统，尚未允许开工。 | `#909399` |
| 允许开工 | 可配置工序后开工。 | `#E6A23C` |
| 进行中 | 已开工，可报工、订单报工等。 | `#409EFF` |
| 已结束 | 业务已结束。 | `#67C23A` |
| 已作废 | 订单作废。列表默认筛选不含本状态。 | `#F56C6C` |

Web 列表「生产状态」着色见本字典。

#### 工序设置

| 类型值 / 状态值 | 说明 | 颜色 |
| --------------- | ---- | ---- |
| 未配置 | 尚未提交工序路线；不可工序报工、不可设备排产。 | `#F56C6C` |
| 已配置 | 已提交工序；满足其它条件时可报工、设备排产。 | `#67C23A` |

#### 是否挂起

| 类型值 / 状态值 | 说明 | 颜色 |
| --------------- | ---- | ---- |
| 是 | 订单挂起。 | `#E6A23C` |
| 否 | 未挂起。 | `#909399` |

##### 交互

- 生产状态默认多选：已核准、允许开工、进行中。
- 搜索条件与分页需记忆：离开本页再返回时保留上次条件与页码；点「清空」后恢复默认状态多选并清除记忆。
- 计划完工时间支持升序 / 降序。
- 生产状态、工序设置着色见对应字典。
- 生产单号有更新时显示警告 tip：「该生产订单有更新」。
- 缺分段同步信息的行底色为浅黄 `#FFF9C4`。
- 生产进度为绿色进度条；悬停可看各工序名称、生产数量、已完成数量、工序进度。整单进度按各有效工序（生产数量 > 0）加权完成比计算，向下取整且不超过 100%；单工序进度 = 已完成数量 ÷ 该工序生产数量。
- 点击数据行可勾选或取消勾选。
- 操作栏按钮显隐：
  - 开工：仅允许开工显示
  - 订单报工：仅进行中显示
  - 工序设置：非已结束显示
  - 查看：始终显示
  - 报工：进行中且工序已配置显示
  - 设备排产：非已结束且工序已配置显示

##### 逻辑

- 数据范围：上游同步的生产订单；本页不以手工新增为主。

#### 删除/批量删除

##### 页面元素

无（确认框）。

##### 交互

- 需先勾选行；未勾选时提示先选择数据。
- 确认后删除所选。

##### 逻辑

- 删除所选订单及其关联工序、报工相关数据。

#### 导出

##### 页面元素

无。

##### 交互

- 未勾选时确认后导出当前条件下全部；已勾选则按所选导出。

##### 逻辑

- 导出当前筛选或勾选范围内的列表字段数据。

#### 开工/批量开工

##### 页面元素

弹窗。

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| 开工时间 | 日期时间 | 必填；打开时默认当前时间 |

##### 交互

- 行「开工」打开本弹窗；上方「批量开工」对已勾选行打开同一弹窗。
- 批量开工：未勾选时提示先选择数据；仅对勾选中「允许开工」且已配置工序的订单生效，其余跳过或提示。

##### 逻辑

- 可执行条件：生产状态为允许开工；已配置工序且存在工序行。
- 执行后：生产状态变为进行中，记下实际开工时间。

#### 工序设置

##### 页面元素

弹窗。上方基础信息只读，下方工序表可编。

**基础信息：**品名、客户、合同号、型号、规格、生产数量（含单位）、颜色、电压、工艺文件、备注。

**工序表列：**

| 列名 | 说明 |
| ---- | ---- |
| # | 序号 |
| 工序名称 | 下拉必选 |
| 工序备注 | 文本，限长 10 |
| 芯倍数 | 正整数 |
| 绞合系数 | 选填 |
| 下线数量 | 数字，必填，最多 4 位小数 |
| 生产部门 | 只读展示 |
| 操作 | 上移、下移、删除 |

**工序表上方按钮：**新增；无工序时可「使用模版」「历史工序」。

##### 交互

- 缺分段同步信息时弹窗顶部红字提示同步异常。
- 已有报工：不可新增工序、不可改工序名称、不可调序、不可删行。
- 单行已排产或已报工：该行工序名称不可改、不可删（提示已排产或已报工不能删除）。
- 选工序后带出工序名称、编码、生产部门。
- 芯倍数、绞合系数变更后，自下而上重算下线数量（末道：芯倍数 × 绞合 × 订单产量；非末道：× 下一道下线量；绞合未填则该行跳过重算）。细则以设计图为准。
- 新增行默认下线数量 = 订单产量，芯倍数 1，绞合 1。
- 使用模版：按模版名检索，单选后套用明细。
- 历史工序：同料品、同生产部门、排除本单；单选后整单工序拷贝。

##### 逻辑

- 可执行条件：生产状态非已结束。
- 提交校验：工序必选、下线数量必填、芯倍数为正；绞合可空。
- 执行后：工序设置变为已配置，回写计划数量等。

#### 报工

##### 页面元素

弹窗。

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| 工序 | 多选 | 必选 |
| 生产人员 | 多选 | 必选 |
| 报工数量 | 数字 | 必填，>0，最多 4 位小数；单位随生产单位 |
| 附加说明 | 文本 | 非必填，限长 255 |
| 已报数量对照 | 只读表 | 各工序已报量 / 下线量 |

##### 交互

- 质检工序，或工序所属部门 ≠ 当前用户部门时，该工序不可选。

##### 逻辑

- 可执行条件：进行中且工序已配置。
- 执行后：生成报工记录（来源为 Web），累加对应工序已完成数量，刷新整单完成量与进度。

#### 订单报工

##### 页面元素

弹窗。

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| 订单报工数量 | 数字 | 必填，>0，最多 4 位小数；单位随生产单位 |
| 生产数量 | 只读 | |
| 已报数量 | 只读 | 当前订单报工累计 |

##### 交互

无

##### 逻辑

- 可执行条件：进行中。
- 执行后：累加订单报工数量（与工序报工并行存在）。

#### 批量报工

##### 页面元素

弹窗。先选工序，再出可报订单表。

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| 工序 | 下拉 | 必选；选定后加载可报订单 |
| 生产单号 | 只读 | 表列 |
| 生产人员 | 多选 | 行内；与开工/完工/报工数量成组 |
| 开工时间 | 日期时间 | 行内 |
| 完工时间 | 日期时间 | 行内；≥ 开工时间 |
| 生产时长 | 只读 | 由开工、完工自动算 |
| 报工数量 | 数字 | 行内，>0，最多 4 位小数 |
| 附加说明 | 文本 | 整单统一，限长 225 |

##### 交互

- 某行若填写任一项，则该行生产人员、开工、完工、报工数量四项均必填。
- 至少一行填写完整才可提交。
- 仅提交已填写完整的行。

##### 逻辑

- 按所选工序批量提交多单工序报工；执行后刷新各单完成量与进度。

#### 设备排产

##### 页面元素

弹窗。上方基础信息只读；按工序 Tab；设备表可编。

**基础信息：**品名、生产数量、规格、颜色、项目号、段长。

**汇总：**当前工序生产数量、已排产、待排产、已报工。

**设备表列：**设备名称、设备编码、实际编号、设备产能、已排总量、报工数量/已排数量、本次生产日期、本次计划数量、备注。

##### 交互

- 本次生产日期不可早于今天；改日期后回填该日已有计划与备注。
- 已排总量可点击，跳转设备排程看板并带入部门、工作中心、设备等条件。
- 超产能时二次确认是否继续。
- 支持「确定并关闭」与「确定」后继续排产。
- 校验：至少一行本次计划数量 >0（或改已有槽）；有计划必须有日期；计划数量最多 10 位整数、4 位小数。

##### 逻辑

- 可执行条件：非已结束且工序已配置。
- 执行后：写入设备排产计划，回写已排产数量。
