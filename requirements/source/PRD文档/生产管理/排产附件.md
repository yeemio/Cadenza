# 排产附件模块 PRD 文档

---

## 1. 基本说明

### 1.1. 业务理解

排产附件（实现上为订单分段）承接国贸合同装箱单经 DC 同步下来的分段主数据与组成数据，供计划员在 Web 查询分段信息、查看组成项目与轴明细，并对同步失败记录发起重试。本页不以手工新增/编辑分段为主。

与生产订单的关联：在需校验的销售订单类型下，若对应销售订单号+行号尚无组成数据，生产订单列表该行底色标黄；打开工序设置时顶部红字提示「排产附件未同步,请联系国贸部做合同装箱单!」。上述列表样式与提示属生产订单页表现，细则见《生产订单》PRD；本文只写排产附件本页能力。

```text
DC 同步分段主表 / 组成表
       ↓
排产附件列表查询、查看
       ├─ 同步失败 → 重试
       ├─ 查看组成项目（弹窗只读分页）
       └─ 查看轴（弹窗只读分页）
```

**两端分工：**

- **Web**：列表查询、查看、重试、查看组成项目、查看轴。
- **PDA**：本模块当前无独立 PDA 端。

##### 交互

- 按创建时间倒序。
- 点击数据行可勾选或取消勾选。
- 同步状态、是否入库、是否贴红码还是托盘着色见对应字典。
- 操作栏按钮显隐：
  - 重试：仅同步失败显示
  - 查看组成项目：始终显示
  - 查看轴：始终显示
  - 查看：始终显示

##### 逻辑

- 数据范围：DC 同步落库的订单分段数据；本页不允许手工新增、编辑、删除。
