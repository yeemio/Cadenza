# 轴码清空模块 PRD 文档

---

## 1. 基本说明

### 1.1. 业务理解

轴码清空用于在生产现场撤销错误或不再使用的产品轴二维码主数据。操作工在 PDA 扫描轴码，勾选需清空的产品轴号后确认；系统删除对应轴码主数据，并写入清空记录（含清空前数量、关联订单/工序/报工等快照）。Web 端仅查询清空历史，不在本页执行清空。

```text
PDA 扫轴码 → 勾选产品轴号 → 确认清空
        ↓
删除轴码主数据 + 写入清空记录（快照）
        ↓
Web「轴码清空」列表可查
```

**两端分工：**

- **Web**：清空记录列表查询（无新增、编辑、删除、清空操作）。
- **PDA**：扫码、勾选、确认清空；成功后回主页。

## 3. PDA 端

### 3.1. 轴码清空页面

**入口：**从主页 → 生产管理 → 轴码清空进入。

#### 列表页面

##### 页面元素

**导航栏标题：**轴码清空

**列表上方的按钮：**无

**卡片展示字段：**

| 字段 | 说明 |
| ---- | ---- |
| 产品轴号 | |
| 料品名称 | 过长省略 |
| 料品编码 | |
| 规格 | |
| 颜色 | |
| 剩余数量（单位） | 标签带单位简称 |

**卡片上的按钮：**无

**页面按钮：**右下角悬浮「扫码」；底部整宽「轴码清空」。

##### 交互

- 本列表一次展示本次扫码结果全部卡片，不做上拉加载。
- 未扫码时页面提示「请点扫码扫描轴码」，不展示卡片。
- 点击卡片可勾选 / 取消勾选；已勾选卡片浅蓝底高亮。
- 扫码仅返回 1 条时自动勾选该卡片；返回多条时默认不勾选，须手工勾选。
- 产品轴号、料品名称、料品编码、颜色、剩余数量无值显示 `-`；规格无值显示 `N/A`。

##### 逻辑

- 数据范围：仅展示本次扫码命中、且码类型为产品轴码的结果；历史清空记录不在本页展示（见 Web）。

#### 扫码

##### 页面元素

无。

##### 交互

- 点右下角悬浮「扫码」完成本次扫码（设计图无侧边硬件键）。
- 扫载具类产品轴码：命中则刷新本页卡片列表。
- 非载具码 / 格式不符：轻提示「请扫描正确的二维码」，清空当前卡片。
- 码存在但不是产品轴码：轻提示「请扫码轴码」，清空当前卡片。

##### 逻辑

无

#### 轴码清空

##### 页面元素

无。

##### 交互

- 点底部「轴码清空」：未扫轴码提示「请扫描轴码」；已扫未勾选提示「请选择产品轴号」；已勾选弹出确认框，标题「轴码清空」，正文「确认执行轴码清空吗？」。
- 确认成功后轻提示「操作成功」，返回主页。

##### 逻辑

- 可执行条件：已扫出有效产品轴号，且至少勾选一条；另须同时满足：
  - 轴码质检已完成（需质检却未完成时不可清空，提示「存在二维码{轴号}质检尚未完成」）。
  - 关联报工已审核（未审核提示「存在二维码{轴号}报工未审核，请先完成报工审核」）。
  - 中转轴上不存在未审核的成品轴信息（否则提示「当前中转轴存在未审核的成品轴信息」）。
  - 已入成品仓在库的码不可清空（提示「存在在仓库中的码的无法进行轴码清空」）。
- 执行后：删除所选「产品轴号 + 料品」对应的轴码主数据；写入清空记录（清空前数量、生产部门、生产/销售单号、行号、物料、所属工序、报工人员与时间、操作人与操作时间等快照），Web 列表可见；并回写库存统计。
