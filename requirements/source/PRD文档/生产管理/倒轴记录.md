# 倒轴记录模块 PRD 文档

---

## 1. 基本说明

### 1.1. 业务理解

倒轴把一根「倒出轴」上的库存按主计量数量拆到一根或多根「倒入轴」。现场在 PDA 扫倒出轴、再扫倒入轴并录入倒入数量后提交；系统扣减倒出轴数量、生成/更新倒入轴码，并留下倒轴主表与倒入明细。Web「倒轴记录」只查结果，不手工新增。

列表将主表与倒入明细展开：同一倒出对应多条倒入则多行，并展示该次倒轴的倒出轴剩余数量（原数量 − 全部倒入合计）。

```text
PDA 倒轴
├─ 扫倒出轴 → 带出料品、数量、生产单号等
├─ 扫倒入轴（可多根）→ 填倒入数量
└─ 完成倒轴 → 写主表+明细，扣减倒出、生成倒入码
        ↓
Web 倒轴记录：按主表+明细展开查询
```

**两端分工：**

- **Web**：倒轴结果列表查询（搜索、分页、多选列）；无新增 / 编辑 / 删除。
- **PDA**：扫码倒轴并提交。

## 3. PDA 端

> 字典见 1.2。
>
> 设计图没有侧边硬件键，需要扫码的页面放「扫码」按钮，点它等同于源码里按一次侧边键。源码「侧扫按钮扫码获取」类文案，设计图写成「点扫码」。设计图不播放扫码提示音。
>
> 本页不是列表页，无下拉刷新、上拉加载。系统返回键（侧滑、物理返回）不生效，只能点导航栏左侧返回。

### 3.1. 倒轴页面

**入口：**主页「生产管理」分类下的「倒轴」。

#### 表单页面

##### 页面元素

**导航栏标题：**倒轴；左侧「返回」。

**倒出轴码区：**蓝色小标题「倒出轴码」+ 红色备注「（请先扫描倒出轴）」；下方白底表单。

| 字段 | 说明 |
| ---- | ---- |
| 产品轴号 | 扫码带出；未扫时显示「点扫码」；有值时右侧红色清除图标 |
| 物料描述 | 料品名称、规格、颜色拼接展示 |
| 数量（单位） | 标签带主计量单位简称；未扫时数量显示 `0` |
| 生产单号 | |
| 销售单号 | |

**倒入轴码区：**蓝色小标题「倒入轴码」+ 红色备注「（可扫多轴）」；下方可多条白底块，每条：

| 字段 | 说明 |
| ---- | ---- |
| 产品轴号 | 扫码带出；右侧红色清除图标 |
| 倒入数量（单位） | 数字输入；单位同倒出轴主计量单位；提示「请输入倒入数量」 |

**页面按钮：**底部贴边整宽「完成倒轴」（有倒出且至少一条倒入时蓝色可点，否则灰色）。右下角圆形悬浮「扫码」。

##### 交互

- 物料描述、生产单号、销售单号无值显示 `-`（物料描述按名称 / 规格 / 颜色分段，空段为 `-`）。
- 点导航栏「返回」：已扫倒出轴时弹窗「退出当前页面将清除所有数据 !」，确认后回主页并清空本页；未扫倒出轴则直接回主页。
- 点倒出轴产品轴号旁清除：确认「确定要清除倒出轴信息吗？」后清空倒出信息与全部倒入行，提示「已清除倒出轴信息」。
- 点倒入轴旁清除：确认「确定要删除该轴码吗？」后删该行，提示「删除成功」。
- 倒入数量：仅数字与一个小数点，小数最多 4 位；失焦格式化为四位小数；失焦后若倒入合计大于倒出数量，提示「倒入数量总和不能大于倒出数量(合计)>(倒出)」。
- 「完成倒轴」：无倒出提示「请先扫描倒出轴」；无倒入提示「请先添加倒入轴码」；数量超限同上；通过后弹窗「确认完成倒轴」。
- 未扫倒出轴时，「完成倒轴」置灰；已扫倒出但尚无倒入行时同样置灰。

##### 逻辑

- 本页数据仅在当前会话有效；提交成功或清除倒出后清空，不落本地进行中单据。

#### 扫码

##### 页面元素

无（使用页面右下角「扫码」）。

##### 交互

- 点「扫码」后按是否已有倒出轴分流：
  - **未扫倒出轴**：本次码作为倒出轴；成功则带出倒出区字段并清空倒入列表；失败提示原因，页面不变。
  - **已扫倒出轴**：之后扫到的载具码一律作为倒入轴；与倒出码相同提示「倒入轴码不能与倒出轴码相同」；已在倒入列表提示「该轴码已存在，请勿重复扫描」；成功则追加一条倒入行（数量空）。要换倒出轴须先清除当前倒出。
- 码格式须为载具码（第 2 位为 E / F / M / P）；不通过提示「请扫描正确的二维码」。

##### 逻辑

- 倒出轴扫码不允许：托码（「倒出码不可扫描托码」）、码不存在（「倒出码不可扫描空码」）、已锁定、质检未完成、报工未审核、异常未处理、已入物流部仓库、一码多物不允许倒轴等（提示以后端返回文案为准）。
- 倒出轴一码对应多条库存记录时，数量按同码合计展示；多料品则按一码多物拒绝。
- 倒入轴扫码仅前端追加，提交时再校验倒入码业务规则。

#### 完成倒轴

##### 页面元素

无（确认框无额外字段）。

##### 交互

- 确认后提交；成功提示「倒轴完成」，清空倒出与倒入；失败提示原因，保留本页已填数据。

##### 逻辑

- 可执行条件：已有倒出轴、至少一条倒入、每条倒入数量已填且大于 0、倒入合计 ≤ 倒出数量、倒入码互不重复且不等于倒出码。
- 倒出轴带客户轴号或段长时：必须全量倒出（合计 = 倒出数量），且倒入轴只能有一条；否则分别提示「拥有客户轴号的必须全量倒出」/「拥有段长的必须全量倒出」，或「拥有客户轴号的倒入轴只能有一个」/「拥有段长的的倒入轴只能有一个」。
- 执行后本模块：生成倒轴主表（倒出轴、原数量、料品、订单等）与倒入明细；记下倒轴人员、倒轴时间。
- 执行后其它模块：按倒入合计扣减倒出轴对应二维码数量（扣完为 0 的码移除）；按倒入码生成或更新倒入侧二维码数量（料品等与倒出一致）；倒入码已有料品且与倒出不一致时失败（「倒入轴」+「现有料品和本次倒入料品不一致」等）。
- Web「倒轴记录」同步出现本次主表 + 明细展开行。
