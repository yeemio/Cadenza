# 设备排程模块 PRD 文档

---

## 1. 基本说明

### 1.1. 业务理解

设备排程以 **工作中心 Tab × 设备行 × 日期列** 看板展示并维护设备维度的排产计划。点击某日单元格打开「添加排产」，按工序筛选候选订单行，填写排产数量后逐条提交。与订单排程、生产订单「设备排产」共用同一套排产槽位与提交能力：同一订单、同一订单工序、同一标准工序、同一设备、同一生产日期至多一条有效排产；将排产数量改为 0 并保存即删除该槽位。看板不展示已结束订单的排产。

```text
进入设备排程（菜单 / 生产订单「已排总量」深链）
├─ 筛选生产部门、设备；按工作中心 Tab 看矩阵
│     日期列 = 今日起连续 30 天 ∪ 矩阵中已有排产日
↓
点击某日格 → 添加排产
├─ 选工序（默认第一条）→ 候选订单（可按生产单号筛）
├─ 填排产数量（可改 0 删已有槽位）
├─ 工序未排上限：强校验，超则禁止保存
└─ 设备日产能：超则二次确认后仍可提交（弱提醒；删槽不弹）
       ↓
   回写工序已排数量/是否排完，及订单排产状态
```

**两端分工：**

- **Web**：看板查询、添加/改/删排产槽位；可接收生产订单「已排总量」跳转带入的部门、工作中心、设备。
- **PDA**：无。

### 1.2. 字典说明

#### 设备状态

| 类型值 / 状态值 | 说明 | 颜色 |
| --------------- | ---- | ---- |
| 正常 | 可新建正数排产槽位。 | 取字典项备注色；未配置默认 `#67C23A` |
| 维修 | 尚无槽位时不允许新建正数排产；已有槽位仍可改正数或改 0 删除。 | 取字典项备注色；未配置默认 `#E6A23C` |

矩阵设备标签文字/边框色、有排产时单元格背景色见本字典备注色（无备注时标签默认 `#909399`）；文字对比度按背景深浅自动切换深字/白字。

## 2. Web 端

### 2.1. 设备排程页面

#### 列表页面

##### 页面元素

**列表上的搜索条件**

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| 生产部门 | 树选 | 精确；不选则工作中心为全部 |
| 设备名称 | 下拉 | 精确；选项随当前生产部门与当前工作中心 Tab 联动；首次进入默认可不选 |

**列表上面的按钮：**无（搜索区自带搜索、重置）

**工作中心 Tab：**每个工作中心一个 Tab，标签为工作中心名称；无工作中心时 Tab 为空（不回退为「全部中心」）。

**矩阵展示字段：**

| 列名 | 说明 |
| ---- | ---- |
| 设备（固定左列） | 设备名称 + 设备状态标签（见字典「设备状态」） |
| 动态日期列 | 表头「月-日 周几」；列集合 = 今日起连续 30 天 ∪ 各行已有排产日期 |

**日期格缩略（有排产时）：**订单数量（当日该设备排产订单个数）、订单产量（当日该设备计划量合计）。

**悬停明细表列：**生产单号、客户、料品描述（型号/规格/颜色拼接）、合同号、交付日期（仅年月日）、排产数量。

**列表操作栏的按钮：**无（点击日期格打开添加排产）

##### 交互

- 首次进入：默认生产部门为当前登录人主部门（可被深链覆盖）；不自动选中设备；加载工作中心 Tab 后默认首个 Tab（深链可指定 Tab），再刷设备下拉与矩阵。
- 深链（自生产订单「已排总量」等带入）：带入生产部门、工作中心、设备；以深链条件为准，不被登录部门异步覆盖；用户改筛选后可去掉深链中的设备参数；离开深链路由后恢复登录部门逻辑。
- 变更生产部门：清空已选设备，立即刷新工作中心、设备下拉与矩阵。
- 仅变更设备下拉：不自动刷新矩阵，需再点「搜索」。
- 点击「搜索」：按当前条件刷新工作中心、设备下拉与矩阵。
- 点击「重置」：清空生产部门与设备，再刷新（未选部门时工作中心为全部）。
- 切换工作中心 Tab：刷新设备下拉与矩阵。
- 设备列固定在左侧，横向滚动时不变。
- 设备状态着色见字典「设备状态」；有排产的日期格背景随设备状态色，无排产不着色。
- 有排产格悬停展示明细表；料品描述、交付日期无值显示 `-`。
- 有排产或空白格均可点击，打开「添加排产」。
- 未选中工作中心 Tab，或行所属工作中心与当前 Tab 不一致时，点格提示并不打开弹窗。

##### 逻辑

- 数据范围：当前工作中心下设备及其排产矩阵；排除已结束订单的排产；本页不手工新增订单或设备。
- 设备下拉：有生产部门则按部门筛；始终按当前 Tab 工作中心筛；当前选中若不在新列表中则清空，不自动选首条。

#### 添加排产

##### 页面元素

弹窗。

**标题：**添加排产——{设备名} 设备产能：{产能}，今日已排产：{当日该设备已排合计}（产能无值显示 `-`；已排合计无则 0）。

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| 排产日期 | 日期 | 只读；由点击的列决定 |
| 排产设备 | 文本 | 只读 |
| 工序 | 下拉 | 有工序选项时必选；选项为当前工作中心下工序；展示名优先「工序名→部门」类拼接，否则工序名（含备注） |
| 生产单号 | 文本 | 非必填；模糊筛候选 |

**筛选行按钮：**搜索、清空（清空生产单号并重拉候选）

**无工序时：**提示「当前工作中心暂无可用工序」，不展示候选表与保存。

**候选表列：**

| 列名 | 说明 |
| ---- | ---- |
| # | 序号 |
| 生产单号 | |
| 客户名称 | |
| 合同号 | |
| 销售订单号 | |
| 型号 | |
| 电压 | |
| 规格 | |
| 颜色 | |
| 下线数量 | |
| 工艺文件 | 固定「—」 |
| 备注 | 优先本槽位备注，否则订单/工序原备注 |
| 排产数量 | 数字输入；≥0；最多 4 位小数；预填优先本设备本日原槽位量，否则矩阵当日预填 |
| 未排产数量 | |

**底部按钮：**取消、保存（无工序时不显示保存）

##### 交互

- 打开后拉工序；有选项则默认选中第一条，并自动拉候选（无需先点搜索）；之后改工序或生产单号后点「搜索」/「清空」再刷新候选。
- 排产数量 > 0 的行底色浅黄 `#fffbe6`。
- 未排产数量无值显示 `-`。
- 保存：筛选「排产数量 > 0」或「原槽位已有计划」的行（含改为 0 删槽）；至少一行，否则提示至少填一行排产数量。
- 单行排产数量不得超过「未排产数量 + 本格原占用」；超过提示对应生产单号超未排；排产数量最多 10 位整数、4 位小数。
- 超设备日产能：设备已配置产能（含配置为 0）时，按整批保存后累计判断；将超则先确认「设备【设备名称】MM-DD 当天的累计排产 XXXX，超过设备产能。确定要继续排产吗？」；整批只弹一次；确认后再逐条提交。产能未配置（空）不比较、不弹。删槽位（改为 0）不计入超产能确认触发条件中的「继续加量」路径，且不单独为删槽弹产能确认。
- 提交时备注固定传空。成功后提示、关弹窗、刷新矩阵；失败留在弹窗。

##### 逻辑

- 可执行条件：已选工作中心；设备归属与当前 Tab 一致；有工序选项时须已选工序。
- 工序强校验：该订单工序下全部槽位计划合计（本槽位按替换旧值计）不得超过该工序下线数量；不通过则禁止保存，且不进入超产能确认。界面侧用「未排产数量 + 本格原占用」作为单行上限。
- 设备状态：本槽位尚无排产且计划量 > 0 时，设备须为正常；已有排产时可改正数；计划量 ≤ 0 删槽不要求设备正常。
- 执行后：写入或删除该槽位；回写工序已排数量与是否排完；按各工序情况回写订单排产状态（未排产 / 部分排产 / 已排产）。
