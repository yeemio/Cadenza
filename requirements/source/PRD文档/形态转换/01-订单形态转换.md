# 订单形态转换模块 PRD 文档

---

## 1. 基本说明

### 1.1. 业务理解

订单形态转换用于把**转换前生产订单**上已在库的库存二维码，按计划数量扫码绑定到**同料品的转换后订单**（销售单号 / 行号 / 项目号不同）。Web 建单并维护转换明细；PDA 按明细扫码、删码并「完成转换」；完成后系统改二维码归属，并异步同步 U9、触发库存统计。

与「库存形态转换」不同：本模块以**生产订单**为转换前后锚点，必须 PDA 扫码完成；库存形态转换以**仓库成品库存轴/托**为锚点，仅 Web 操作。

```text
Web 新增转换单（待转换）
  └─ 选转换前生产订单行 → 填计划数量 → 选转换后订单（同料品）
        ↓
PDA 形态转换列表（待转换 / 已完成）
  └─ 进入明细任务列表 → 逐条明细扫载具码（可删码）
        ↓
PDA「完成转换」（每条明细至少扫过 1 轴）
  └─ 二维码归属改到转换后订单 → 已完成
        ├─ 异步推 U9 形态转换
        └─ 库存统计 MQ
```

**两端分工：**

- **Web**：新增 / 编辑（仅待转换且未扫码）、删除、查看详情与已扫二维码、U9 同步失败时重试。不扫码、不完成转换。
- **PDA**：按转换单扫码、删码、完成转换。不建单。

### 1.2. 字典说明

#### 转换状态

| 类型值 / 状态值 | 说明 | 颜色 |
| --------------- | ---- | ---- |
| 待转换 | Web 已建单，尚未在 PDA 完成转换。 | `#E6A23C` |
| 已完成 | PDA 已完成转换，记下完成人、完成时间。 | `#67C23A` |

Web 列表、PDA 状态 Tab 着色 / 分段见本字典。

#### 同步状态

| 类型值 / 状态值 | 说明 | 颜色 |
| --------------- | ---- | ---- |
| 未同步 | 完成转换后尚未推送 U9 或排队中。 | `#909399` |
| 同步失败 | U9 推送失败，可「重试」。 | `#F56C6C` |
| 已同步 | U9 推送成功。 | `#67C23A` |

##### 交互

- 按创建时间倒序，同时间按 id 倒序。
- 转换状态、同步状态着色见对应字典。
- 操作栏按钮显隐：
  - 编辑：仅待转换且该单尚无任何扫码时显示；已完成或已有扫码不显示
  - 详情：始终显示
  - 重试：仅同步状态为同步失败时显示
  - 删除：仅待转换且尚无扫码时显示
- 点「详情」新开页签进入 2.2。

##### 逻辑

- 数据范围：本模块全部转换单。
- 删除：仅待转换且无扫码可删；删除主单及明细。
- 重试：仅已完成且同步失败时重新推 U9，成功后同步状态变为已同步。

#### 新增 / 编辑

##### 页面元素

大弹窗标题：新增转换 / 编辑转换（可全屏）。

**明细区上方按钮：**新增、批量删除

**明细列表字段：**

| 列名 | 说明 |
| ---- | ---- |
| 勾选列 | 供批量删除 |
| # | 序号 |
| 转换前行号 | 选料带出，只读 |
| 转换前项目号 | 选料带出，只读 |
| 转换后项目号 | 必填；焦点打开「选择转换后订单」 |
| 转换前销售单号 | 选料带出，只读 |
| 转换后销售单号 | 选转换后订单带出，只读 |
| 品名 | 只读 |
| 料号 | 只读 |
| 规格 | 只读 |
| 颜色 | 只读 |
| 数量 | 必填；计划转换数量；精度 4 位，范围 0.0001～999999999.9999 |
| 单位 | 只读 |
| 当前库存 | 转换前订单可用库存，只读 |
| 操作 | 行删除 |

**弹窗底部按钮：**确定、取消

##### 交互

- 点明细「新增」打开「选择转换前料品 / 订单」弹窗（见下）。
- 点「转换后项目号」打开「选择转换后订单」弹窗；须先有转换前订单与料品。
- 同一「销售单号 + 行号」不可重复加入明细。
- 编辑打开时带入原明细；已完成或已有扫码不可进入编辑（见操作栏显隐）。
- 确定提交整单；取消关闭不保存。

##### 逻辑

- 新增：生成转换单号；转换状态=待转换；同步状态=未同步。
- 至少保留 1 条明细方可提交。
- 每条明细须已选转换后订单且数量合法。
- 编辑：仅待转换且无扫码可保存。

#### 选择转换前料品 / 订单（弹窗）

##### 页面元素

两步：先单选料品，再多选该料品下的生产订单行（采购单入口禁用）。

**确认后回传字段：**转换前销售单号、行号、项目号、订单 id、料品信息、当前库存等。

##### 交互

- 未选料品或未选订单行时不可确认。
- 确认后写入新增弹窗明细表。

##### 逻辑

- 仅可选生产订单行；同销售单号+行号去重。

#### 选择转换后订单（弹窗）

##### 页面元素

按当前明细的料品 id、排除转换前订单 id，列出可选生产订单，单选。

##### 交互

- 确认后回写本行转换后项目号、转换后销售单号、转换后订单 id。

##### 逻辑

- 转换后订单须与转换前同料品、且不是转换前同一订单。

| 料名 | |
| 料号 | |
| 实扫数量 / 计划数量 | |
| 已扫轴数 | |

**卡片上的按钮：**无（整卡可点）

**页面底部按钮：**完成转换（仅待转换 Tab 进入时显示）

##### 交互

- 实扫数量 ≥ 计划数量时，卡片为完成样式。
- 点卡片进入 3.3。
- 点「完成转换」弹出确认；确认后提交并返回 3.1。
- 从已完成 Tab 进入时不显示「完成转换」，卡片只读进入 3.3。

##### 逻辑

- 「完成转换」可执行条件：当前为待转换；且每条明细已扫轴数 > 0。
- 执行后：转换状态=已完成；记下完成人、完成时间；二维码归属改为转换后订单；触发 U9 同步与库存统计。
- 轴号 / 虚拟轴号等校验不通过则提示失败，状态不变。

### 3.3. 扫码转换页面

#### 详情页面

##### 页面元素

**导航栏标题：**扫码转换

**展示字段：**

| 字段 | 说明 |
| ---- | ---- |
| 转换前项目号 | |
| 转换前销售单号 | |
| 转换后项目号 | |
| 转换后销售单号 | |
| 物料描述 | 品名等 |
| 实扫数量 / 计划数量 | |
| 库位 | 可多库位展示 |
| 已扫二维码列表 | 轴号、段长、数量 |

**页面底部按钮：**扫码、删除（仅待转换时显示）

##### 交互

- **扫码**：扫描载具码；命中后弹层选择段长或客户轴号（已用项不可再选）；确认后写入本明细并刷新实扫数量、已扫列表。
- **删除**：进入删码模式，再扫已录入的码；确认后解除锁定并回写实扫数量。
- 载具码规则：符合载具编码规范且类型位为 E/F/M/P（不含 R）；删码模式不校验该规则。
- 扫码成功 / 失败播放对应提示音。
- 从已完成进入时无扫码、删除按钮，仅查看。

##### 逻辑

- 扫码提交：锁定二维码，回写明细实扫数量、已扫轴数。
- 删码提交：解锁二维码，重算实扫数量、已扫轴数。
- 码须属于转换前订单对应库存且满足业务校验，否则提示失败不入库。

## 4. 与其他模块的关联

| 关联模块 | 关联说明 |
| -------- | -------- |
| 生产订单 | 选转换前 / 转换后订单行；完成后二维码归属到转换后订单 |
| 料品 | 转换前后须同料品；带出规格、颜色、单位 |
| 二维码 / 库存 | 扫码锁定、删码解锁；完成后改归属；触发库存统计 |
| 订单轴段 | 段长、客户轴号、虚拟轴号校验与占用 |
| U9 | 完成转换后推形态转换；失败可重试 |
| 库存形态转换 | 另一套业务，勿混用菜单与单据 |
