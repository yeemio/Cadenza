# 库存形态转换模块 PRD 文档

---

## 1. 基本说明

### 1.1. 业务理解

库存形态转换用于将**仓库内已有库存的成品**（按产品轴或托盘）转换业务形态：修改销售单号、行号、批次号，并可填写段长、客户轴号；转换后项目号记在转换单上（**不回写二维码项目号**）。提交后先落单，再同步 U9，U9 成功后再做 MES 改码与库存统计。

本模块**仅 Web**，无 PDA。与「订单形态转换」不同：不以生产订单建单、不扫码完成，直接选库存轴/托提交。

```text
列表「新增转换」
  └─ 选择有库存的成品料品
        └─ 左右栏转换弹窗：左侧选库存轴/托 → 右侧填转换后信息 + 段长
              ↓ 校验并提交
        落单（默认转换失败）
              ↓ U9 成功
        同步失败 ──► MES 改码 + 库存统计 ──► 转换成功
              ↓ U9 失败
        保持转换失败（可重新转换）

同步失败单：「重新同步」→ 仅 MES 改码 + 库存统计（不再推 U9）→ 转换成功
```

### 1.2. 字典说明

#### 转换状态

| 类型值 / 状态值 | 说明 | 颜色 |
| --------------- | ---- | ---- |
| 转换失败 | 单据已保存，但 U9 未成功（含首次落单默认态）。可「重新转换」。 | `#F56C6C` |
| 同步失败 | U9 已成功，MES 改码或库存统计未完成。可「重新同步」。 | `#E6A23C` |
| 转换成功 | U9、MES、库存统计均完成。 | `#67C23A` |

Web 列表转换状态着色见本字典。

##### 交互

- 仓库与库位联动：先选仓库再选库位；改仓库清空库位；**未选仓库时库位禁用，左侧库存列表置灰不可勾选**。
- 左侧库存：无托按单轴一行；有托按托汇总一行（产品轴号为 `-`），添加到右侧时拆成子轴多行。
- 已添加到右侧的行在左侧置灰且不可再选。
- 未勾选左侧点「添加到右侧」，提示「请先选择库存明细」。
- 「移除」：勾选右侧行后移除；若为同一托盘，选中任一轴则同托全部移除；移除后左侧可再选。
- 从左侧添加时：有原段长则带出到右侧段长；客户轴号置空。
- 「校验并提交」前校验通过后，二次确认：「确定要提交本次形态转换任务吗？」
- 取消关闭弹窗不保存；重新转换取消不改原单。

##### 逻辑

- 左侧数据：指定料品、在库、仓库类型=仓库、存储状态正常；平行轴 / 多物料托只保留本料品相关轴。
- 提交前：右侧至少 1 条明细；转换后销售单号、行号、批次号必填；每行段长必填。转换后项目号非必填。
- 校验：同一「二维码 + 物料」若存在未转换成功的单据，不可再次添加。
- 锁定中的二维码不可转换。
- 提交链路：
  1. 保存 / 更新单据，状态默认转换失败
  2. 调用 U9 形态转换；失败则保持转换失败并记录失败原因
  3. U9 成功后状态为同步失败，再执行 MES 改码（回写二维码销售单号、行号、批次号、段长、客户轴号，清空虚拟轴号；**不改项目号**）与库存统计
  4. 全部成功后状态为转换成功
- 重新转换：仅转换失败单；带入原料品、原转换后字段、原清单（可改可加减明细），再次走上述提交链路。

## 4. 与其他模块的关联

| 关联模块 | 关联说明 |
| -------- | -------- |
| 料品主数据 | 选择有库存的成品料品；主表冗余名称、编号、规格、颜色、单位 |
| 库存台账 | 选料按库存过滤；左侧按库存统计聚合；成功后触发库存统计 |
| 二维码 | 占用 / 锁定校验；成功后改销售单、行号、批次、段长、客户轴号 |
| 销售订单 | 按原销售单+行号补原项目号及 U9 所需订单信息 |
| 仓库 / 库位 | 仅仓库类型；库位随仓库联动 |
| U9 | 提交 / 重新转换时推形态转换；重新同步不再推 U9 |
| 订单形态转换 | 另一套业务，勿混用 |
