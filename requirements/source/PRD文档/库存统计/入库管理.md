# 入库管理模块 PRD 文档

---

## 1. 基本说明

### 1.1. 业务理解

入库管理承接报工、成品质检后产生的成品码/托码，把「尚未入到物流成品库」的任务做成台账：Web 可查询、导出、手工指定仓库库位入库、刷新同步、查看托码/平行轴明细；PDA「等待入库」只看待入库任务，现场扫码选库位后确认入库。

任务主从表由报工/质检等链路异步写入与更新，**不允许**在本模块手工新增、编辑、删除主数据。确认入库后码落到目标库位，任务变为已入库，并触发库存统计等下游更新。

```text
报工 / 成品质检完成
        ↓
生成/更新入库管理任务（未入库）
        ↓
┌───────┴───────┐
│ Web 入库管理  │ 查询、导出、刷新、选仓入库、看托/轴明细
│ PDA 等待入库  │ 仅未入库列表、扫码选库位确认入库、刷新
└───────┬───────┘
        ↓
码入目标库位；任务→已入库；库存统计异步更新
```

**两端分工：**

- **Web**：未入库 / 已入库均可查；导出；行内刷新、入库；托码/平行轴进详情页。无手工新增、编辑、删除。
- **PDA**：从主页进入。仅展示未入库；查询筛选；扫产品轴号/托码后选库位确认入库；卡片刷新。

### 1.2. 字典说明

#### 入库状态

| 类型值 / 状态值 | 说明 | 颜色 |
| --------------- | ---- | ---- |
| 未入库 | 任务下相关码尚未全部进入物流成品库在库状态。 | |
| 已入库 | 相关码均已在物流成品库在库；记下入库人员、入库时间。 | |

#### 入库库位类型

仅 Web「成品入库」弹窗使用。

| 类型值 / 状态值 | 说明 | 颜色 |
| --------------- | ---- | ---- |
| 仓位 | 按仓位选库位；不展示货架。 | |
| 货架 | 须先选货架，再选该货架下库位。 | |

#### 码类型

| 类型值 / 状态值 | 说明 | 颜色 |
| --------------- | ---- | ---- |
| 单品码 | 单根产品轴号任务；无托盘/轴码详情入口。 | |
| 托码 | 托盘任务；操作「托盘详情」；入库整托上架。 | |
| 平行轴 | 一码多物；操作「轴码详情」。 | |

##### 交互

- 按创建时间倒序。
- 客户轴号（段长）列支持升序 / 降序；取消排序后恢复默认。
- 行可勾选；勾选变化时实时重算上方汇总：各单位数量合计、选中行轴数之和、托盘编码去重个数。
- 操作栏按钮显隐：
  - 刷新：仅未入库显示
  - 托盘详情：码类型为托码时显示
  - 轴码详情：码类型为平行轴时显示

- 点「托盘详情」或「轴码详情」跳转到入库详情页（见 2.2）。
- 从详情返回本页时保留查询条件与分页，并刷新列表。

##### 逻辑

- 数据范围：报工 / 质检等链路写入的入库管理任务；含未入库与已入库。本页不允许手工新增、编辑、删除。
- 勾选汇总仅展示，不触发业务提交。

#### 导出

##### 页面元素

无独立表单；确认框文案「是否导出数据?」。

##### 交互

- 点「导出」弹出确认；确定后按当前搜索条件导出。

##### 逻辑

- 导出范围与当前列表筛选一致。
- 导出列为：托盘号码、产品轴号、生产单号、销售单号、物料描述、入库长度、客户轴号（段长）、轴数、轴具尺寸、轴具类型、入库状态、入库时间、入库人员、完工时间、销售合同号、仓库。

#### 刷新

##### 页面元素

无；确认框文案「确定将选择数据更新?」。

##### 交互

- 仅未入库行显示「刷新」。
- 确认后同步该任务相关码数据并刷新列表。

##### 逻辑

- 可执行条件：入库状态为未入库；已入库不可刷新。
- 执行后：按该任务主码及明细码重跑同步，更新本模块任务数据；列表刷新。

#### 入库

##### 页面元素

弹窗标题「成品入库」，副提示「托盘入库会将整个托盘上的料品进行入库」。可全屏。底部按钮：入库、取消。

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| 仓库 | 下拉 | 必填；成品类物流仓库 |
| 入库库位类型 | 下拉 | 必填；默认仓位；见字典「入库库位类型」 |
| 货架 | 下拉 | 入库库位类型为货架时必填且显示 |
| 库位 | 下拉 | 必填；随仓库 / 货架 / 库位类型联动；仅一条时可自动选中 |

##### 交互

- 仓库、入库库位类型、货架、库位级联；类型为仓位时隐藏货架。
- 所选仓库为逻辑库时，隐藏入库库位类型、货架、库位并清空（细则以设计图为准）。
- 提交中「入库」按钮不可再点。

##### 逻辑

- 可执行条件：当前行为未入库；仓库、库位必填（库位按当前弹窗展示规则校验）。
- 执行后：
  - 非托码：当前任务及明细变为已入库，记下入库人员、入库时间；码入所选仓库库位。
  - 托码：同一托盘编码下所有未入库主表及对应明细一并已入库（整托）。
  - 触发库存统计等下游异步更新。
  - Web 列表刷新后该行（及同托相关行）为已入库。

## 3. PDA 端

> 字典见 1.2。列表默认下拉刷新、上拉加载；没有更多时提示「数据加载完毕！」。
>
> 需要扫码的页面或弹层都有按钮「扫码」，点它完成本次扫码。设计图没有侧边硬件键，也不播放扫码提示音。同一页有多处扫码时，每一处各有一个「扫码」。

##### 逻辑

- 数据范围：仅未入库任务；与当前查询条件一致。
- 汇总轴数与当前筛选条件一致。

无

##### 交互

- 扫产品轴号或托码：命中待入库任务则打开本弹窗并带出明细；格式不符提示「请扫描正确的二维码」；未命中提示「未找到该二维码对应的料品信息」。
- 扫货架码：带出仓库与库位编码，并出现货架层数可选；未选层数点确定提示「请选择货架层数」。
- 点库位编码打开「选择库位」：可按关键字搜库位，切换仓库；选中后写回库位 / 仓名，并关闭货架层数展示（非货架点选）。
- 可先选/扫库位再扫产品，或先扫产品再选库位；再扫产品时保留已选库位信息。
- 确定提交中按钮不可再点。

##### 逻辑

- 可选库位范围：成品类实体仓。
- 货架入库最终库位由货架码与层数拼成。
- 可执行条件：已带出待入库明细；货架模式须已选层数；库位须有效。
- 执行后：对应任务变为已入库，码入目标库位；本列表不再展示该任务；待入库轴数按筛选重算；触发库存统计等下游更新；提示「入库扫码成功」。
- 托码确认入库时，同托相关未入库任务一并完成（与 Web 整托规则一致）。

#### 刷新

##### 页面元素

无

##### 交互

##### 逻辑

- 可执行条件：当前卡片为未入库任务。
- 执行后：按该任务重跑同步，更新任务数据；列表从第一页重载。
