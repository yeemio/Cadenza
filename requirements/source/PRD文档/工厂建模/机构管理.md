# 机构管理模块 PRD 文档

---

## 1. 基本说明

### 1.1. 业务理解

机构管理维护工厂建模下的 **组织机构树**（机构名称、机构类型、机构编码、机构全称、排序、上级机构、工厂编码、备注、公司组织编码），作为部门、车间、厂区等主数据，供设备、工序、工作中心、用户归属等模块引用。数据以本页人工维护为主。

列表为懒加载树：默认展示根级机构，展开节点再加载下级。删除时连带删除其全部下级；若本机构或任一下级已挂用户则禁止删除。机构名称、机构编码全局唯一；上级机构不可选自己或自己的下级。

**两端分工：**

- **Web**：树形列表查询、新增、新增子项、编辑、查看、删除/批量删除。
- **PDA**：无。

## 2. Web 端

### 2.1. 机构管理页面

#### 列表页面

##### 页面元素

**列表上的搜索条件**

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| 机构名称 | 文本 | 模糊 |
| 机构全称 | 文本 | 模糊 |

**列表上面的按钮：**新增、删除。

**列表展示字段：**

| 列名 | 说明 |
| ---- | ---- |
| # | 序号 |
| 机构名称 | |
| 机构类型 | 字典「机构类型」 |
| 机构编码 | |
| 机构全称 | |
| 排序 | |
| 公司组织编码 | |
| 操作 | |

**列表操作栏的按钮：**新增子项、编辑、查看、删除。

##### 交互

- 树形懒加载：默认仅根级；展开某行时加载其直接下级。
- 有搜索条件时，列表改为展示全库匹配结果（扁平），不再按上级分层。
- 按排序升序。
- 点击数据行可勾选或取消勾选。
- 「新增子项」仅管理员角色可见。

##### 逻辑

无

#### 新增/编辑

##### 页面元素

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| 机构名称 | 文本 | 必填；最长 20 |
| 机构类型 | 下拉 | 非必填；可筛选；选项见字典「机构类型」 |
| 机构编码 | 文本 | 必填；最长 20 |
| 机构全称 | 文本 | 必填；最长 30 |
| 排序 | 数字 | 必填 |
| 上级机构 | 树选 | 非必填；不选则为根级 |
| 工厂编码 | 文本 | 必填；最长 10 |
| 备注 | 多行文本 | 非必填；最长 255 |
| 公司组织编码 | 文本 | 非必填；最长 50 |

##### 交互

- 查看与新增/编辑同一表单区域，全部只读。
- 点击操作栏「新增子项」打开新增弹窗：上级机构预填为当前行且不可改。

##### 逻辑

- 机构名称全局不能重复；重复时提示「机构名称不能重复!」。
- 机构编码全局不能重复；重复时提示「机构编码不能重复!」。
- 上级机构不能选择自己；提示「父节点不可选择自身!」。
- 上级机构不能选择自己的下级；提示「父节点,不可以选择子节点」。

#### 删除/批量删除

##### 页面元素

无（确认框）。

##### 交互

- 确认文案：确定将选择数据删除?
- 批量删除需先勾选行；未勾选时提示「请选择至少一条数据」。

##### 逻辑

- 可执行条件：所选机构及其全部下级均未挂用户；存在用户时提示「所选的机构或其子集存在关联用户，无法删除!」。
- 执行后本模块逻辑删除所选机构及其全部下级。
