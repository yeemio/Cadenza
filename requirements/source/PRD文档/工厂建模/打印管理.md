# 打印管理模块 PRD 文档

---

## 1. 基本说明

### 1.1. 业务理解

打印管理维护工厂建模下的 **托盘打印任务**（托盘编码、打印状态、发起时间、发起人员）。现场在 PDA 扫码结果页对托盘登记「需要打印」后，本页供管理端查询任务、打开预览并执行浏览器打印；预览内容按托盘实时组装（生产托盘 / 装箱托盘两种版式），**不**单独落库打印正文。本页 **不**提供手工新增 / 编辑 / 删除任务。

打印完成后任务状态变为已打印；无「仅预览不改状态」「撤回已打印」等单独能力。已打印任务可再次进入预览并再次打印（再次执行仍回写为已打印）。

**两端分工：**

- **Web**：列表查询、行内进入打印详情（预览 + 打印并标记已打印）。
- **PDA**：无任务列表页；扫码结果页（托码场景）可推送打印任务。

### 1.2. 字典说明

#### 打印状态

| 类型值 / 状态值 | 说明 | 颜色 |
| --------------- | ---- | ---- |
| 1 | 未打印 | 橙 |
| 2 | 已打印 | 绿 |

##### 交互

##### 交互

- 进入页按任务 id 拉取预览数据；托盘存在出库打包关联则装箱版式，否则生产版式；同一托盘关联多条出库打包记录时预览失败。
- 生产托盘：按订单+料品+车间聚合；数量求和；轴数=去重二维码数；生产时间取报工结束时间最晚；每页最多 5 条产品块。
- 装箱托盘：按料品名称+颜色+规格+段长+轴具类型+尺寸分组汇总数量与轴数；每页最多 4 条；超出自动分页。
- 「取消」关闭当前页并返回上一页。
- 点击「打印」时若预览区无打印内容，提示「打印内容不存在」。

##### 逻辑

- 打开预览不修改打印状态。
- 预览正文每次实时组装，不落库单独正文表。

#### 打印

##### 页面元素

无（浏览器打印对话框）。

##### 交互

- 点击「打印」将预览内容写入隐藏页并唤起系统打印；随后回写任务状态（不等待用户是否真正出纸）。

##### 逻辑

- 执行后本模块：打印状态变为已打印（不校验原状态）。

## 3. PDA 端

无独立打印管理列表页。

### 3.1. 扫码结果页推送任务

##### 页面元素

**页面按钮：**打印（底栏；仅托码且允许打印时显示）。

##### 交互

- 托码场景且允许打印时显示「打印」；点击后推送打印任务，成功后回首页；无二次确认。
- 有出库打包且全部为待打包时：不显示打印按钮，推送亦拒绝。

##### 逻辑

- 推送校验：托盘码必填、码存在且为托盘类型、托下有码。
- 执行后新建一条打印任务，打印状态=未打印；同一托盘可多次推送产生多条任务。
