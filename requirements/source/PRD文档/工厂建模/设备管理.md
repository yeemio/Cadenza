# 设备管理模块 PRD 文档

---

## 1. 基本说明

### 1.1. 业务理解

设备管理维护工厂建模下的 **设备档案**（所属部门、工作中心、设备名称、设备编码、实际编号、设备型号、设备标准速率、设备状态、设备产能），供订单排产、报工、PDA 日开工等引用。数据以本页人工维护为主。

设备状态可在列表行内直接切换，变更会记入状态变更流水（来源区分 WEB / PDA）。删除前须确认未被订单排产、报工引用；已被排产引用的设备，编辑时不可改工作中心与所属部门。设备二维码内容固定为 `EQU-` + 设备编码（前缀仅大写、区分大小写）。

**两端分工：**

- **Web**：列表查询、新增、编辑、查看、删除/批量删除、行内改状态、二维码（含下载/打印）、状态变更记录。
- **PDA**：主页扫设备码进入设备详情；查看档案信息；设备开工（须二次确认；仅正常状态可开工；允许当日重复开工）。

##### 逻辑

无

#### 新增/编辑

##### 页面元素

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| 所属部门 | 树选 | 必填 |
| 工作中心 | 下拉 | 必填；可筛选 |
| 设备名称 | 文本 | 必填；最长 50 |
| 设备编码 | 文本 | 必填；最长 32 |
| 实际编号 | 文本 | 非必填；最长 50 |
| 设备型号 | 文本 | 非必填；最长 50 |
| 设备标准速率 | 文本 | 非必填；最长 50 |
| 设备状态 | 下拉 | 必填；无默认值，须用户选择 |
| 设备产能 | 文本 | 非必填；非负数字；最多 10 位整数、4 位小数 |

##### 交互

- 所属部门与工作中心联动：
  - 先选所属部门：工作中心下拉仅该部门下；变更所属部门时清空已选工作中心。
  - 先选工作中心：回填所属部门且所属部门不可改；工作中心未配置部门时提示并清空工作中心。
  - 清空工作中心：同步清空所属部门。
- 编辑时若该设备已被订单排产引用：工作中心、所属部门均不可改。
- 查看与新增/编辑同一表单区域，全部只读。

##### 逻辑

- 设备名称全局不能重复；重复时提示「设备名称重复」。
- 设备编码全局不能重复；重复时提示「设备编码重复」。
- 保存时所属部门须与工作中心所属部门一致；工作中心须已配置所属部门。
- 已被订单排产引用的设备，不允许变更工作中心；后端提示「设备已参与排产，无法修改工作中心」。
- 新增成功：记一条状态变更流水（变更前为空、变更后=所选状态、来源=WEB）。
- 编辑保存时若设备状态相对原值发生变化：记下变更前/后状态、变更人、变更时间，来源=WEB。

#### 删除/批量删除

##### 页面元素

无（确认框）。

##### 交互

- 确认文案：确定将选择数据删除?
- 批量删除需先勾选行；未勾选时提示「请选择至少一条数据」。

##### 逻辑

- 可执行条件：未被订单排产、报工引用；已被排产引用时优先提示「存在已经排产的设备无法删除」；已被报工引用时提示「存在已经报工的设备无法删除」。
- 执行后本模块逻辑删除该设备。

#### 行内改状态

##### 页面元素

无（列表「设备状态」列下拉）。

##### 交互

- 列表行内直接切换设备状态；选项与着色见字典「设备状态」。

##### 逻辑

- 新旧状态相同时不记流水。
- 状态变化后：记下变更前/后状态、变更人、变更时间，来源=WEB。

#### 二维码

##### 页面元素

标签展示字段：设备名称（标题）、设备编码、实际编号、设备型号、所属车间（优先所属部门名称，否则工作中心名称）、二维码图（码值=`EQU-`+设备编码）、页脚「华通线缆·固定资产标签」。空字段展示 `-`。

弹窗按钮：下载、打印。

##### 交互

- 点击「下载」下载 PNG，文件名为设备编码（无编码时为 `equipment-label.png`）。
- 点击「打印」打开打印设置弹窗（标签打印设计器）。

##### 逻辑

无

## 3. PDA 端

**入口：**从主页扫码进入（扫码内容前 4 位须为 `EQU-`，仅大写、区分大小写）；命中后进入本页并带入设备码。

**展示字段：**

##### 交互

- 顶栏返回回到主页。

##### 逻辑

无

#### 扫码

##### 页面元素

无（本页枪机扫码）。

##### 交互

- 再次扫描设备码（前 4 位为 `EQU-`）：刷新当前页详情。
- 扫描货架码 / 料品或轴托码：按主页同规则跳转对应信息页。
- 非上述码：轻提示「请扫描正确的二维码」。
- 同一码 600ms 内重复扫描忽略。

##### 逻辑

- 设备码业务编码为去掉前缀 `EQU-` 后的字符串；未找到设备时提示失败。

#### 设备开工

##### 页面元素

无（确认框）。

##### 交互

- 无设备信息时不可打开确认框，轻提示「未获取到设备信息，无法开工」。
- 确认框文案：确定执行开工操作吗？
- 确认成功后轻提示「开工成功」，并回到主页。

##### 逻辑

- 可执行条件：设备存在且设备状态为「正常」；非正常时提示「当前设备状态不允许开工」。
- 允许当日重复开工：当日已有开工记录则更新开工时间，否则新建当日开工记录。
