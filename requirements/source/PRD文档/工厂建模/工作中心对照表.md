# 工作中心对照表模块 PRD 文档

---

## 1. 基本说明

### 1.1. 业务理解

工作中心对照表维护 **ERP/U9 工作中心** 与 **MES 工作中心** 的对应关系（所属部门、ERP 工作中心名称/编码、组织编码、MES 工作中心名称/编码）。工艺、订单工序等按 **ERP 工作中心编码 + 组织编码** 解析到 MES 工作中心。数据以本页人工维护为主。

本模块无启用/停用等业务状态流转，增删改后即生效。同一 ERP 工作中心编码在同一组织编码下不可重复。删除无额外占用校验，逻辑删除即可。

**新增**保存成功后：异步按本次 ERP 工作中心编码 + 组织编码，将 **订单工序**、**工艺工序** 中尚未绑定 MES 工作中心的记录，写入本次所选 MES 工作中心。**编辑**不触发该回写。

**两端分工：**

- **Web**：列表查询、新增、编辑、查看、删除/批量删除。
- **PDA**：无。

## 2. Web 端

### 2.1. 工作中心对照表页面

#### 列表页面

##### 页面元素

**列表上的搜索条件**

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| 所属部门 | 树选 | 精确 |
| ERP工作中心名称 | 文本 | 模糊 |
| ERP工作中心编码 | 文本 | 模糊 |
| MES工作中心名称 | 下拉 | 精确；选项为全部 MES 工作中心（不按部门过滤） |
| MES工作中心编码 | 文本 | 模糊 |

**列表上面的按钮：**新增、删除。

| 列名 | 说明 |

| # | 序号 |

| MES工作中心编码 | |

**列表操作栏的按钮：**编辑、查看、删除。

##### 交互

- 点击数据行可勾选或取消勾选。

##### 逻辑

无

#### 新增/编辑

##### 页面元素

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| 所属部门 | 树选 | 必填 |
| ERP工作中心名称 | 文本 | 必填；最长 50 |
| ERP工作中心编码 | 文本 | 必填；最长 50 |
| 组织编码 | 文本 | 必填；最长 20 |
| MES工作中心名称 | 下拉 | 必填；选项随所属部门：已选部门时仅该部门下；未选部门时为全部 |
| MES工作中心编码 | 文本 | 只读；随 MES 工作中心带出 |

##### 交互

- 所属部门与 MES 工作中心联动：变更所属部门后，MES 工作中心下拉仅该部门下，并清空已选 MES 工作中心及编码。
- 选择 MES 工作中心后，自动带出 MES 工作中心编码；清空选择时同步清空编码。
- 查看与新增/编辑同一表单区域，全部只读。

##### 逻辑

- 同一 ERP 工作中心编码 + 组织编码不能重复；重复时提示「该ERP工作中心下已存在所填的组织编码」。
- 仅新增：保存成功后异步回写订单工序、工艺工序中尚未绑定 MES 工作中心且匹配本次 ERP 工作中心编码 + 组织编码的记录；编辑不触发该回写。

#### 删除/批量删除

##### 页面元素

无（确认框）。

##### 交互

- 确认文案：确定将选择数据删除?
- 批量删除需先勾选行；未勾选时提示「请选择至少一条数据」。

##### 逻辑

- 执行后本模块逻辑删除该对照记录。
