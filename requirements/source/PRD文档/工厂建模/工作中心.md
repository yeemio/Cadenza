# 工作中心模块 PRD 文档

---

## 1. 基本说明

### 1.1. 业务理解

工作中心维护工厂建模下的 **工作中心主数据**（名称、编码、所属部门），供设备管理、工序管理、订单排产/报工等业务引用。数据以本页人工维护为主。

本模块无启用/停用等业务状态流转，增删改后即生效。删除为逻辑删除；删除前须确认未被设备、工序、订单工序引用（不校验工作中心对照表是否仍引用）。

**两端分工：**

- **Web**：列表查询、新增、编辑、查看、删除/批量删除。
- **PDA**：无。

## 2. Web 端

### 2.1. 工作中心页面

#### 列表页面

##### 页面元素

**列表上的搜索条件**

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| 名称 | 文本 | 模糊 |
| 编码 | 文本 | 模糊 |
| 所属部门 | 树选 | 精确 |

**列表上面的按钮：**新增、删除。

**列表展示字段：**

| 列名 | 说明 |
| ---- | ---- |
| # | 序号 |
| 名称 | |
| 编码 | |
| 所属部门 | |
| 操作 | |

**列表操作栏的按钮：**编辑、查看、删除。

##### 交互

- 按创建时间倒序，相同时按 id。
- 点击数据行可勾选或取消勾选。

##### 逻辑

无

#### 新增/编辑

##### 页面元素

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| 名称 | 文本 | 必填；最长 50 |
| 编码 | 文本 | 必填；最长 50 |
| 所属部门 | 树选 | 必填 |

##### 交互

- 查看与新增/编辑同一表单区域，全部只读。

##### 逻辑

- 编码全局不能重复；重复时提示「工作中心编码重复」。
- 同一所属部门下名称不能重复；重复时提示「工作中心名称在同一个部门中重复」。

#### 删除/批量删除

##### 页面元素

无（确认框）。

##### 交互

- 确认文案：确定将选择数据删除?
- 批量删除需先勾选行；未勾选时提示「请选择至少一条数据」。

##### 逻辑

- 可执行条件：未被设备、工序、订单工序引用；校验顺序为设备 → 工序 → 订单工序；已被设备引用时提示「存在已经在设备中使用的工作中心无法删除」；已被工序引用时提示「存在已经在工序中使用的工作中心无法删除」；已被订单工序引用时提示「存在已经在订单工序中使用的工作中心无法删除」。
- 执行后本模块逻辑删除该工作中心。
